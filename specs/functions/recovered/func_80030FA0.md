# func_80030FA0

## Boundary
VRAM 0x80030FA0-0x80030FF8 (88 bytes), ROM 0x31BA0. Frame 0x20, return
sequence with an empty delay slot. One direct caller.

## Callers / callees

## Behavior
A fixed-parameter setup routine that takes no arguments and returns nothing.
It performs two configuration calls with entirely constant arguments. The
first passes a small negative selector, three zeroes, and a fifth value of
255. The second passes two identifiers, 0x3E4 and 0x3E8, followed by four
values of 255 each — the shape of a fully opaque, fully saturated colour
setting applied to a pair of screen elements.

## Status
