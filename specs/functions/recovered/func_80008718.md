# func_80008718

## Boundary and control flow

- USA VRAM `0x80008718` through `0x8000874F`, ROM `0x9318`, 56 bytes.
- The analyzer's labels at `0x80008734` and `0x80008748` are internal branch
  targets, not callable functions. Both lack direct callers, and control can
  fall or branch into them from the entry body.
- The body has three returns. The first two put the result value in the return
  delay slot; the final return has an empty delay slot. All three slots are
  included in the boundary.

## References

The two direct USA calls are at `0x800087EC` and `0x8000887C`. Both pass the
caller's first integer argument unchanged and test the returned word as a
boolean. The function is a leaf and accesses no globals.

Japan and Europe retain the same entry address and identical 56-byte body. The
LRG USA revision also uses the USA address and bytes. These versions support
the corrected parent boundary; the USA retail image remains the canonical
matching target.

## Behavior

Returns true when the signed input is either the isolated value 34 or lies in
the half-open interval from 142 through 157. All other values return false.

The independently written C uses explicit tests and returns rather than a
combined Boolean expression. That form preserves the original's shared
out-of-range test and its three distinct return paths.

## Status

Byte-matching C. IDO 5.3 with the accepted `ido53_o2` profile reproduces all
56 USA bytes exactly. The comparison also proves the corrected extent and all
three return delay slots. LRG inherits the same unit and is verified separately
by its own matching report and full-ROM round trip.
