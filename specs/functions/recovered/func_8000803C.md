# func_8000803C

## Boundary

- USA VRAM `0x8000803C` through `0x8000808F`, ROM `0x8C3C`, 84 bytes.
- The analyzer's `0x80008084` label is the shared false-result block inside
  this function. The true path returns at `0x8000807C` with one in its delay
  slot; the false path returns at `0x80008088` with an empty delay slot.
- The next independent prologue begins at `0x80008090`.

## References

The sole direct USA call is at `0x80008278`. It passes an object pointer and
an integer index, then tests the returned word. The function is a leaf, uses no
globals, and accesses only memory reachable from the first argument. Japan and
Europe have the same entry address and a uniquely matching initial window;
LRG retains the complete USA body.

## Behavior

Loads a table at object offset `0x40`, selects its 48-byte entry, and follows
the pointer at entry offset `0x08`. A null pointer returns false. Otherwise the
pointed-to record supplies a two-word count array at offset `0x38` and an
unsigned limit at offset `0x54`. The function returns true when the unsigned
sum of the two counts is below the limit, and false otherwise.

The C writes the commutative sum in reverse source order to preserve the
original load order; this does not change the specified behavior.

## Status

Byte-matching C. IDO 5.3 with `ido53_o2` reproduces all 84 bytes exactly for
USA retail and the LRG USA revision.
