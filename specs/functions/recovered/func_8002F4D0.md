# func_8002F4D0

## Boundary
USA VRAM 0x8002F4D0-0x8002F550, ROM 0x300D0, size 128 bytes. Ends with the
return instruction followed by an empty delay slot. Boundary confirmed correct;
the address immediately after is the entry of func_8002F550, which this
function passes as a callback.

## Callers / callees
One caller. Calls func_8008B580 (no arguments), func_80088150 (one integer),
func_800183C0 (no arguments), func_8008B810 (six arguments, the last two passed
on the stack) and func_8008B960 (one address).

## Globals
- D_800D6960 — an object whose eighth 32-bit word is read, bit 0x40 set, and
  written back.
- D_800D7750 — an object passed by address twice.
- D_800D7A00 — an object passed by address.
- func_8002F550 — passed by address as a callback.

## Regional addresses
- jp 0x8002FF30 (ROM 0x30B30); every symbol relocated.
- eu: the corresponding body (0x80032A70) is structurally different — it stores
  an extra 32-bit constant to a global before the second call — so it is a
  different source and is deliberately not claimed here.
- lrg_rev1 shares the USA addresses.

## Behavior
A subsystem start-up sequence. It resets one subsystem, selects configuration
identifier 0x5622 in a second, and initialises a third. It then sets a flag bit
(value 0x40) in the eighth word of a shared control block. Finally it registers
a worker: the first control object, mode 1, the callback that immediately
follows this function, a zero parameter, a second control object, and a size or
priority of 10; and then starts that worker by handing back the first control
object. Returns nothing.

## Status
exact in USA, Japan and lrg_rev1; Europe differs structurally and is excluded.
