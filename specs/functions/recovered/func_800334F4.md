# func_800334F4 — damped approach of a stored angle toward a clamped target

## Boundary

- USA VRAM range 0x800334F4 .. 0x80033583 inclusive, 144 bytes (0x90).
- Terminates with the return jump whose delay slot performs the final store
  through the first argument. No branch leaves the range and no branch from the
  preceding function enters it.
- Boundary as assigned is correct; no correction needed.

## Callers

One direct caller in the USA build, inside the module beginning at ROM 0x66898
(call site at VRAM 0x80067BBC). It passes a pointer to a field of the object it
is working on plus four single-precision values read out of that same object,
the last of which is one of two constants (70 or 300) chosen by a flag bit.

## Callees

None. The function is a leaf.

## Globals and access widths

- `D_80120BF0` — read once as a 64-bit double-precision constant.

No other global is touched. The only other memory the function touches is the
single-precision word addressed by argument 1, read once and written once.

## Signature

`void func_800334F4(f32 *slot, f32 numerator, f32 unused, f32 denominator, f32 scale)`

Arguments 2..5 are single-precision floats. Because argument 1 is a pointer,
arguments 2..4 arrive in the integer argument registers and argument 5 arrives
in the first stack argument slot. Argument 3 is never read; the compiler still
emits the home-slot store that the calling convention reserves for it, which is
how we know it is a declared but unused float parameter rather than absent.

## Recovered behaviour

The function maintains one stored single-precision quantity — the value in the
word the first argument points at — and moves it a fraction of the way toward a
freshly computed target every time it is called.

The target is the negated ratio of the second argument to the fourth, scaled by
the fifth. Because the negation is applied to the quotient rather than to the
numerator, the sign of the target follows the sign of the whole ratio.

The target is then clamped into the closed range from -80 to +80: anything
above 80 becomes exactly 80, and anything below -80 becomes exactly -80. The
two clamps are applied in that order, upper bound first.

Finally the stored value is advanced toward the clamped target. The gap between
target and stored value is widened by a factor of five and then by the global
double constant, and that product is added to the stored value. The whole
correction term and the addition are evaluated in double precision — the
constant five is a double literal, so the single-precision gap is promoted —
and only the final sum is narrowed back to single precision before being stored
back through the pointer. The global constant therefore acts as a per-frame
time step: it converts "five times the remaining error" into "how much of that
error to remove this frame".

The result is a first-order exponential approach toward a clamped steering-like
target, with a rate of five per unit of the global time step.

## Status

Exact. Byte-identical in usa, japan, europe and lrg_rev1.
