# func_8008F950

## Boundary and references

- USA VRAM `0x8008F950` through `0x8008F97F`, ROM `0x90550`, 48 bytes.
- The return at `0x8008F978` has a zero-result delay slot; the next prologue is
  at `0x8008F980`.
- The direct USA call is at `0x80088A04`. `func_8008D5A8` also registers this
  entry as a three-argument callback.
- It has no callees or globals. LRG retains the USA address and bytes;
  non-USA builds were not needed for the recovery.

## Behavior

This callback has the same observed record layout and operation as
`func_8008DD50`: mode two appends the third argument to the pointer table at
offset `0x1C`, advances the index at `0x14`, and returns zero. Other mode values
only return zero.

## Status

Byte-matching C. IDO 5.3 with `ido53_o2` reproduces all 48 bytes exactly for
USA retail and the LRG USA revision.
