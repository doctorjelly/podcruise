# func_8003043C

## Boundary
USA VRAM 0x8003043C-0x800304AB (0x70 = 112 bytes), ROM 0x3103C.
0x18-byte frame holding only the return link. Ends with a return and an empty
delay slot. The preceding function returns at 0x80030434; nothing branches past
it. One direct call site.

## Callers / callees
One caller. Calls `func_80011D60` once - a three-argument transfer helper taking
a source address in cartridge space, a destination in RAM and a byte count.

## Globals
- `D_102ABB0` - address in the cartridge address space (0x0102ABB0); referenced
  as a symbol, not as an integer literal, which is what produces the
  high/low relocation pair rather than a load-upper/or pair.
- `D_800D9E00` - array of 1700 signed words (0x1A90 bytes).
- `D_800DB890` - a single signed word placed immediately after that array; it is
  both the transfer destination and the loop's end sentinel, because the array
  end address and this symbol's address coincide.

## Regional addresses
- JP 0x80030E9C, ROM 0x31A9C; cartridge source 0x0102DE00, array 0x800DD070,
  count word 0x800DEB00, helper unchanged.
- EU 0x800339FC, ROM 0x345FC; cartridge source 0x01033850, array 0x800E2AA0,
  count word 0x800E4530, helper relocated to 0x800121F0.
- lrg_rev1 shares the USA addresses.
Both regional bodies were read; the array-to-sentinel span is 0x1A90 in every
version, confirming the same 1700-word capacity.

## Recovered behavior
Four bytes are fetched from a fixed cartridge address into a single word of RAM,
giving the number of records the following table will hold. If that number
exceeds the table's capacity of 1700 the routine deliberately hangs in an empty
endless loop - a hard consistency stop, not an error return. Otherwise the whole
1700-word table is cleared to zero.

## Notes on shape
The literal bound of 1700 lets IDO unroll the clear four ways and drive it off a
pointer compared against the end of the array, which is exactly the original.
The cartridge source must be an `extern` symbol; an integer constant of the same
value compiles to a different two-instruction sequence.

## Status
exact - USA, JP, EU and lrg_rev1 all verified byte-identical.
