# func_8000FF54 — populate one slot of the forty-entry registry

## Boundary

- USA VRAM range `0x8000FF54` .. `0x8000FFB7` inclusive; size 100 bytes
  (25 instructions).
- The body ends with the standard return instruction and a no-operation delay
  slot; the early-out branch taken when the index is out of range jumps to that
  same return.
- The previous function returns before this label and the single direct call
  site targets `0x8000FF54`, so the assigned boundary is correct.

## Callers

One direct call site in the USA build, at `0x8005EEB8`. Two arguments: a signed
integer slot index, and a pointer to three consecutive single-precision floats.
No return value.

## Callees

None; leaf function, no stack frame.

## Globals and access widths

| symbol | role | width |
| --- | --- | --- |
| `D_800D5C60` | forty entries of three single-precision floats (twelve bytes per entry) | 32-bit float loads/stores |
| `D_800D60A0` | forty signed words, one per slot | 32-bit store |
| `D_800D5C38` | forty flag bytes, one per slot | 8-bit store |

The slot stride of twelve bytes is formed by the usual multiply-by-twelve
sequence, confirming a three-float element rather than a padded four-float one.

## Recovered behaviour

The routine fills in one slot of the registry that `func_8000FEF0` clears.

1. The slot index is compared as a signed value against forty. If it is forty
   or greater the routine does nothing at all; negative indices are not
   rejected, so the caller is responsible for the lower bound.
2. Otherwise the three floats the caller points at are copied, in order, into
   the three-float entry for that slot.
3. The per-slot signed word is set to negative one thousand. Given how the
   neighbouring code compares that table against a rounded value, this reads as
   an initial countdown or "far below any real value" seed.
4. The per-slot flag byte is set to one, marking the slot occupied.

## Status

Exact. Byte-identical in USA, Japan, Europe and `lrg_rev1`.
