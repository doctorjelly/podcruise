# func_80009B8C

## Boundary
VRAM 0x80009B8C-0x80009C0C, ROM 0xA78C, 128 bytes. Ends with the standard
epilogue and an empty delay slot. One direct caller. Boundary as assigned is
correct.

## Callers / callees
One caller. Calls func_8003F7B8 with a fixed four-character tag value, and
func_80051FF4 with no arguments.

## Globals and access widths
- D_8009AF24: 32-bit float, written as zero.
- D_8009AF08: array of 16-bit signed values, one element read.
- D_8009AEF0: 32-bit signed, written with the sign-extended element.
- D_800A822C: 32-bit float, read once.
- D_8009AF20: 32-bit float, written with the value just read.
- The single argument is an unsigned integer used as an index.

## Regional addresses
jp and eu both place this function at 0x80009B8C / ROM 0xA78C, unchanged.

## Recovered behavior
Applies a stored preference, unless a debug override says otherwise. It first
asks a lookup routine about a fixed four-character tag. If that lookup reports a
positive result it consults a second predicate; only when that predicate also
reports zero does the routine return without changing anything. In every other
case — the tag lookup not positive, or the predicate non-zero — it applies the
settings: one float global is cleared to zero, a signed 16-bit table is indexed
by the argument reduced modulo twelve and the selected entry is published as a
32-bit global, and a second float global is copied from a third.

## Status
behavior. The unit is an -O1 region; compiled at -O1 the body reproduces
everything except three instructions: the original keeps the argument in a
caller-saved register across the two calls, loading it in each branch delay slot
and spilling it back to its own home slot before the second call, whereas every
source shape tried defers the load to the point of use. Result is 132 of 128
bytes. Six shapes were tried (both short-circuit spellings, nested ifs, an
early-return form, an explicit local copy, statement reordering, pointer vs.
array indexing) plus -O2, which additionally turns both branches into the
branch-likely forms the original does not use.
