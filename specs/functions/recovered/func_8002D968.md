# func_8002D968 — gated three-byte equality test

## Boundary — corrected

- USA VRAM range: `0x8002D968` .. `0x8002D9CF` (inclusive), **104 bytes**.
- ROM offset `0x2E568`, translation unit `main_18B28.s`.
- The body ends with a return whose delay slot is empty, at
  `0x8002D9C8`/`0x8002D9CC`; there is an earlier return at
  `0x8002D97C`/`0x8002D980` whose delay slot produces the zero result.
- **The assigned extent (56 bytes) was wrong and was corrected to 104.** As with
  the other entries in this ROM range, the generated inventory double-counts
  instructions because two translation units cover the range, so the assigned
  size is twice the size of the *first fragment* only. On top of that, the
  heuristic labelling cut the function at its first return and presented the
  remainder as a separate routine at `0x8002D984`. That address has no call
  sites; it is the fall-through half of a likely-branch pair whose taken target
  is `0x8002D988` inside the same block, and it is unreachable dead code left
  behind by the compiler's duplication of the first instruction of the loop head
  into the branch delay slot. The function runs to `0x8002D9D0`, where the next
  function begins with its own argument sign-extension prologue.
- The 104-byte extent is confirmed by construction: the recovered C compiles to
  exactly these 104 bytes at this address.

## Callers

Twelve distinct direct call sites: `0x8001DBD8`, `0x8001E55C`, `0x800279BC`,
`0x8002DD08`, `0x8002DD20`, `0x8002DD38`, `0x8002DD50`, `0x8002DDF8`,
`0x8004C798`, `0x8004C7C8`, `0x8004D610`, `0x8004D64C`. Each passes two
addresses and branches on the result being zero or non-zero, so the routine
takes two pointers and returns a 32-bit boolean.

The cluster at `0x8002DD08` onward is especially informative: it walks four
consecutive 44-byte records (`0x80113694`, `0x801136C0`, `0x801136EC`,
`0x80113718`) and compares each against a distinct three-byte constant in the
read-only data area, aborting as soon as one comparison fails. That both fixes
the argument width at three bytes and corroborates the 44-byte record stride
used by `func_80029A3C`.

## Recovered behaviour

The routine first consults the global flag word. If flag bit `0x4000` is clear
it answers "not equal" immediately, without touching either pointer — so when
the mode is off the comparison is treated as always failing.

When the bit is set it compares the two three-byte buffers the arguments point
at, one unsigned byte at a time from the first byte forward, and stops at the
first pair that differs. It returns one when all three bytes are equal and zero
otherwise. Neither buffer is modified and no other memory is touched.

The short-circuit is observable: when the first or second byte differs, the
third (and, for a first-byte mismatch, the second) byte is never read.
