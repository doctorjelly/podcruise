# func_80089790

## Boundary
- USA VRAM 0x80089790 - 0x800897F3 inclusive, ROM 0x8A390, size 100 bytes
  (25 instructions).
- Two padding instructions sit between the previous function's end label and
  this entry, so the split is aligned and nothing executable precedes the
  prologue. The body ends with the return instruction plus an empty delay
  slot, and the single direct call site targets 0x80089790. Boundary as
  assigned is correct.

## Callers
1 direct call site in the USA build.

## Callees
- `func_8008FC3C` (0x8008FC3C) - takes a channel address, the address of a
  16-byte request block and a 32-bit flag word. Its own body copies exactly
  16 bytes out of the request block, which fixes the block's size.

## Globals and access widths
None.

## Structure evidence
- The single argument is the address of an owning object. A signed 32-bit
  index lives at offset 0x3C and the address of a table of fixed-size records
  lives at offset 0x40. Records are 0x30 bytes apart; the index is scaled by
  that stride with an unsigned multiply.
- Offset 0x28 inside the selected record is a 32-bit busy indicator.
- Offset 0x14 inside the owning object is the channel structure handed to the
  callee.
- The request block built on the stack is 16 bytes: a 16-bit field at offset 0
  that is cleared, and a pointer field at offset 4 that receives the address
  of the selected record. The remaining eight bytes are left as they were.

## Recovered behavior
The routine starts the next queued record for an owning object, but only when
that record is not already in flight. It reads the record table address and
the current index out of the object, steps to the record the index selects,
and checks that record's busy indicator. A non-zero indicator means the record
is already being serviced, and the routine returns without doing anything.

When the indicator is clear it fills in a small request block on the stack:
the leading 16-bit field is cleared, and the pointer field is pointed at the
same selected record. It then hands the object's embedded channel, the request
block and a flag word of zero to the dispatch routine, which copies the block
away for its own use. Because the request block is a stack local, only the two
fields the dispatcher needs are written here.

Two details of the original source shape are worth recording for anyone
revisiting this: the record table address is read once into a local and reused
on both sides of the test, while the index is re-read from the object for the
second record address, and the first record address is formed by pointer
addition rather than by subscripting.

Exact in usa, japan, europe and lrg_rev1 under the accepted `ido53_o2`
profile; no per-unit compiler flags were needed.
