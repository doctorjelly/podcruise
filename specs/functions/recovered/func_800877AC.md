# func_800877AC

## Boundary
* USA VRAM 0x800877AC - 0x80087813 (104 bytes, 26 instructions), ROM 0x883AC.
* Frame of 0x28 bytes; four callee-saved registers plus the return address are
  saved and restored. The body ends with a return whose delay slot releases the
  frame, so nothing is shared with the following function.
* Three direct callers target 0x800877AC. Boundary confirmed, not corrected.

## Callers / callees
* Callers: 3.
* Callees: `func_8001811C`, called once per array element.

## Parameters and globals
Two integer-width arguments, both simply forwarded to the callee; this function
never inspects them.

| symbol      | USA address | use |
| ----------- | ----------- | --- |
| D_80120DF0  | 0x80120DF0  | base of an array of four records, 0x170 bytes each |
| D_801213B0  | 0x801213B0  | first address past that array (base + 0x5C0) |

The end symbol is not read as data: it only bounds the walk, and writing the
loop as an index over a four-element array of 0x170-byte records reproduces the
original bound exactly.

## Recovered behaviour
This is a broadcast helper. A global table holds four fixed-size records (each
0x170 bytes). The function walks the table from the first record to the last and,
for every record, calls the per-record setter with the record address, the
selector value it was given, and the payload value it was given. It returns
nothing and keeps no state of its own; the effect is "apply this one setting to
all four records".

## Status
Exact. USA, Japan, Europe and lrg_rev1 all verified byte-identical under the
accepted `ido53_o2` profile.
