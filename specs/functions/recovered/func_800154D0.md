# func_800154D0

## Boundary
- USA VRAM 0x800154D0 - 0x80015537 inclusive, ROM 0x160D0, size 104 bytes
  (26 instructions).
- Terminates with the return instruction plus an empty delay slot; the
  preceding function ends with its own return two instructions earlier, and no
  branch from it crosses into this label. Every direct call site targets
  0x800154D0. Boundary as assigned is correct.

## Callers
253 direct call sites in the USA build; this is one of the most heavily used
helpers in the game.

## Callees
- `func_800153C0` (0x800153C0) - returns the Euclidean length of the three
  floats at the supplied address.

## Globals and access widths
- `D_800A87F4` - read once as a 32-bit float. It is the minimum length below
  which the vector is left untouched.

## Regional addresses
| version   | entry      | ROM     | length helper | threshold  |
|-----------|------------|---------|---------------|------------|
| usa       | 0x800154D0 | 0x160D0 | 0x800153C0    | 0x800A87F4 |
| japan     | 0x80015600 | 0x16200 | 0x800154F0    | 0x800AB654 |
| europe    | 0x80015960 | 0x16560 | 0x80015850    | 0x800ADBD4 |
| lrg_rev1  | 0x800154D0 | 0x160D0 | 0x800153C0    | 0x800A87F4 |

All three regional bodies were read independently and are instruction-for-
instruction the same shape as the USA body, differing only in the two
relocated addresses.

## Recovered behavior
The routine takes the address of a three-component single-precision vector.
It first asks the length helper for the magnitude of that vector and keeps the
answer. If the magnitude is at least as large as the stored threshold, each of
the three components is divided by the magnitude in place, turning the vector
into a unit vector pointing the same way. If the magnitude is below the
threshold the vector is left exactly as it was, which avoids dividing by a
value close to zero. In both cases the routine hands back the magnitude it
measured before any scaling, so a caller can normalise and learn the original
length in a single step.

Note that the comparison is written with the threshold on the left, so a
magnitude that is not a number fails the test and the vector is left alone.

## Status
Exact in usa, japan, europe and lrg_rev1 under the accepted `ido53_o2`
profile; no per-unit compiler flags were needed.
