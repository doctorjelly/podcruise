# func_800880E0

## Boundary

- VRAM 0x800880E0 .. 0x8008810C (exclusive), ROM 0x88CE0, size 44 bytes.
- Leaf, no frame. The return instruction's delay slot carries the last of the
  six stores.
- A padding word follows before func_80088110. Nineteen direct call sites all
  target 0x800880E0. Boundary confirmed.

## Callers and callees

- Nineteen direct call sites. Leaf.
- Three arguments: the container to initialise, a pointer that is stored
  verbatim (call sites pass the address of a static data block), and a small
  32-bit count (0x14, 0x32, 0x01 and 0x04 observed).

## Globals and access widths

- `D_800A7BB0` — a terminator record whose address, not contents, is used. It
  is referenced only by this routine anywhere in the image.
- Container fields written, all 32-bit: 0x00 and 0x04 receive the terminator
  address, 0x08 and 0x0C are zeroed, 0x10 receives the third argument and 0x14
  receives the second.

All four bodies were read and differ only in the relocated terminator address
and in the routine's own address. In every version both references resolve to
the same address.

## Recovered behavior

Initialises an empty container.

1. Both chain endpoints are set to the address of the shared terminator
   record, which is the state an empty chain has.
2. The two counters at 0x08 and 0x0C are cleared.
3. The caller's capacity value is stored at 0x10 and the caller's data pointer
   at 0x14.

Nothing is read back and nothing else in memory is touched.

## Source-shape note (important, needs an orchestrator decision)

The original materialises the terminator address twice, with two independent
address-forming pairs that the scheduler interleaves. IDO shares a single
address computation whenever the same declaration is named twice, and it does
so through every disguise tried: a cast to a different pointer type, a
different declared field type on the two sides, array-versus-element syntax,
a struct member at offset zero, a union member at offset zero, an integer
literal address, and the 7.1 compiler as a cross-check. Nine variations were
tried; all produced a 36-byte body with one address computation. Referring to
two separately declared symbols that the link step resolves to the same
address reproduces the original 44 bytes exactly.

The recovered source therefore declares a second name, `D_800A7BB0_2`, for
the same address. To keep the host link and the rebuild working, the
orchestrator needs an absolute symbol per version:

- usa and lrg_rev1: `D_800A7BB0_2 = 0x800A7BB0;`
- japan: `D_800AAA00_2 = 0x800AAA00;`
- europe: `D_800ACEB0_2 = 0x800ACEB0;`

with the regional unit remapping `D_800A7BB0` and `D_800A7BB0_2` onto the
regional pair. The finding itself is a fact about the original translation
unit: it reached the terminator through two distinct declarations.

## Status

Exact in usa, japan, europe and lrg_rev1, conditional on the second absolute
symbol above being declared.
