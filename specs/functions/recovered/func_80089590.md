## Recovered behavior

Releases one entry of an object's 48-byte entry table. The caller supplies the
object and a signed 16-bit entry index. The routine loads the table base from
offset 0x40 of the object and inspects the 32-bit word at offset 0x28 of the
indexed entry, which acts as a busy/owner marker: if it is non-zero the entry is
still in use and nothing happens.

Otherwise the 32-bit field at offset 0x1C of that entry is cleared, and if the
entry being released is also the object's currently selected entry (the 32-bit
field at offset 0x3C), that selection is invalidated by storing -1.

The original computes the entry address twice - once for the busy test and once for
the clear - because the two accesses sit in different basic blocks and are written
with different subscript forms (index-plus-pointer for the test, pointer-subscript
for the clear). Writing both the same way collapses them into one address and comes
out four bytes short.
