# func_8008BC30

## Boundary and evidence

USA is VRAM `0x8008BC30`, ROM `0x08C830`, 400 bytes through the next symbol at
`0x8008BDC0`. The return is `jr $ra` at `0x8008BDB4`; its delay slot restores
the 80-byte stack frame, and one padding `nop` follows. The routine is installed
by `func_8008BAB0`. Its unique equivalents are Japan `0x8008C920` / ROM
`0x08D520` and Europe `0x80091180` / ROM `0x091D80`.

## Behavior

Initialize a shared pending-message count from the current schedule, forcing a
minimum of one, then receive messages forever. Message 13 acknowledges one
scheduled item, runs the schedule callback when the count reaches zero, resets
the count, increments the event total, and accumulates elapsed timer ticks.
Message 14 invokes the alternate service routine. Other message identifiers
are ignored.

## Status

Behavior recovered only; the current IDO 5.3 `-O2` comparison does not match
the USA bytes.
