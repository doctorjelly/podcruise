# func_80039828

## Boundary
USA VRAM 0x80039828-0x80039890, 104 bytes, ROM 0x3A428. Ends with the return
jump plus an empty delay slot. One direct caller.

## Callers
One call site in the USA build.

## Callees
- func_800396E0 (one integer argument, returns a non-zero handle on success)
- func_80039768 (one integer argument)
- func_8003960C (no arguments)
- func_8003964C (no arguments)

## Globals
None.

## Regional addresses
- jp 0x8003A1CC (ROM 0x3ADCC); the four callees appear at 0x8003A084,
  0x8003A10C, 0x80039FB0 and 0x80039FF0. No Europe address was assigned.
- lrg_rev1 shares the USA addresses.

## Behavior
The routine tries to acquire a resource with selector zero. If that first
attempt yields nothing it retries with selector 0x400, and when the retry
succeeds it performs a follow-up initialisation step for selector zero. Finally
it reports the outcome: if a resource was obtained by either attempt it runs
the success path, otherwise it runs the failure path. The acquired handle
itself is not returned.

## Status
Exact in USA, Japan and lrg_rev1.
