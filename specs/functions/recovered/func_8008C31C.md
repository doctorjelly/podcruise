## Recovered behavior

Measures the length of a zero-terminated byte string. One argument: the address
of the first byte. The routine keeps a cursor that starts at that address. If
the first byte is already zero the length is zero and it returns immediately.
Otherwise it advances the cursor one byte at a time, inspecting the byte that
follows the cursor's new position, and stops as soon as that byte is zero. The
result is the number of bytes between the starting address and the cursor, that
is, the count of non-zero bytes preceding the terminator. The terminator itself
is not counted, and the string contents are never modified.

## Access widths

Bytes are read with an unsigned byte load, so the element type is an unsigned
8-bit quantity; using a plain (signed) char produces a signed byte load and a
mismatch at offset 0x0. The result is a 32-bit difference of two addresses.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1 under the accepted
profile `ido53_o2`.
