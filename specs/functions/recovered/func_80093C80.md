# func_80093C80

## Boundary
USA VRAM 0x80093C80..0x80093CCB inclusive (76 bytes, 19 instructions), ROM
0x94880. The body ends with the return jump and an empty delay slot; both
direct call sites target 0x80093C80 and no instruction precedes the frame
adjustment, so the assigned boundary is correct.

## Callers
Two call sites, both at 0x8008B5FC and 0x8008B61C, which pass the fixed
physical address 0x1FC007FC (the serial peripheral command word) as the first
argument and a value derived from a stack variable as the second, then test the
returned status for zero.

## Callees
`func_80097950`, already recovered elsewhere in the project, takes no arguments
and reports whether the serial device is busy.

## Globals and access widths
No named global. The routine forms an uncached address by setting the high
address bits of its first argument and performs one 32-bit store through it.

## Regional addresses
* JP 0x80094970 (ROM 0x95570); busy check at 0x80098640.
* EU 0x800991D0 (ROM 0x99DD0); busy check at 0x8009CEA0.
* lrg_rev1 shares the USA addresses.
Both regional bodies were read directly and match the USA shape apart from the
relocated call target.

## Recovered behavior
This is the raw single-word write half of the serial interface pair whose read
half is `func_80093C30`. It first asks whether the device is busy; if it is,
the routine gives up immediately and reports failure as -1. Otherwise it
converts the caller-supplied physical address into its uncached form, stores
the caller's 32-bit value there, and reports success as 0.

## Compiler profile
The surrounding low-level library region was built at a lower optimisation
level. At -O2 the compiler fills the conditional branch's delay slot with one
of the two reloads, producing a body four bytes short. With -O1 (flags
`-G 0 -O1 -mips2 -non_shared -Xcpluscomm -signed -Wab,-r4300_mul`) the body is
byte-identical, which is the same per-unit override already recorded for the
neighbouring `func_80097950`.

## Status
Exact on USA, JP, EU and lrg_rev1 under the -O1 per-unit flag override.
