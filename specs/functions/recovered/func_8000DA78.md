# func_8000DA78

## USA boundary and behavior

The controller-pak slot browser body occupies VRAM `0x8000DA78` through
`0x8000E67B` (ROM `0xE678`, 3,076 bytes). Its `jr ra` at `0x8000E674`
restores the 992-byte frame in the delay slot; the following word is
padding. It handles slot navigation, browser drawing, and controller-pak
state. The ROM and current linked C each have 36 direct calls with the
same ordered targets.

## Compiler status

Behavior-recovered C is still assembly-backed in USA. The linked IDO 5.3
body is 3,048 bytes against the ROM's 3,076, with 716 differing overlap
words and seven missing words. Changing the terminal `index != 0x18`
condition to `index < 0x18` compiled identically and was reverted. No
byte-matching C is claimed; the remaining mismatch is broad.
