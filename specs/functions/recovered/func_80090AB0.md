# func_80090AB0

## Boundary

- USA VRAM range: 0x80090AB0 .. 0x80090B20 inclusive (0x74 = 116 bytes, 29 instructions).
- USA ROM offset: 0x916B0.
- Terminates with a return whose delay slot moves the truncated result into the
  return register, so that move is part of the function.
- The assigned size of 116 was correct; no boundary correction was needed.

## Callers and callees

- Three direct call sites in the USA build.
- No callees; leaf function.

## Globals and access widths

- None. The function touches only its two parameters.

## Regional addresses

The body is instruction-for-instruction identical in every version and contains
no relocations at all, so the same object matches everywhere.

| version   | VRAM       | ROM     |
|-----------|------------|---------|
| us        | 0x80090AB0 | 0x916B0 |
| jp        | 0x800917A0 | 0x923A0 |
| eu        | 0x80096000 | 0x96C00 |
| lrg_rev1  | 0x80090AB0 | 0x916B0 |

## Recovered behaviour

An additive checksum. The first parameter is the address of a byte array, the
second is a signed length.

1. A 32-bit running total starts at zero and a cursor starts at the first byte.
2. For each of the *length* bytes, the byte is zero-extended and added to the
   total, and the cursor advances by one. A length of zero or less adds
   nothing, so the total stays zero.
3. The total is reduced to its low sixteen bits and returned as a 16-bit value.

The masking appears twice in the original: once as an explicit reduction of the
running total and once as the conversion required by the 16-bit return type.
Writing only one of the two collapses the tail into a single instruction and
loses eight bytes, so the recovered source keeps both — the returned expression
masks with 0xFFFF and the function's return type is `u16`.

The cursor must be a local pointer that is incremented, not an index into the
parameter: indexing makes the compiler rebuild the address from the base
pointer inside the unrolled loop and changes which registers are used.

## Status

Exact. Verified byte-identical against USA, Japan, Europe and lrg_rev1.
