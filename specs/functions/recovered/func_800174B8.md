# func_800174B8 — build a 4x4 transform from a position and three angles

Proposed merged specification document: `specs/functions/matrix_from_euler.md`.

## Boundary

- USA VRAM `0x800174B8` .. `0x8001751F` (inclusive), ROM `0x180B8`, size 104
  (0x68) bytes.
- Terminates with a return instruction whose delay slot is empty; the following
  label `func_80017520` begins the scale-matrix constructor.
  `boundary_corrected: false`.

## Recovered behavior

Argument 1 addresses a sixteen-element single-precision matrix stored row by
row. Argument 2 addresses six consecutive single-precision values: a position
followed by three angles. The function copies the position into the matrix's
last row, clears the last element of each of the first three rows, sets the
bottom-right element to one, and then hands the matrix and the three angles to
`func_8001723C`, which fills the upper-left three-by-three block. The net effect
is a complete transform that rotates by the three angles and translates to the
supplied position.

Together with `func_8001745C` this fixes the matrix convention used throughout
the island: sixteen floats, row by row, translation in the last row — the same
convention as the scale and translation constructors that follow at
`func_80017520` and `func_80017580`.

## Status

Exact. Byte-identical to the USA image, and to the Japanese, European and
LRG rev1 images at their own addresses.
