# func_80031B70

## Boundary
VRAM 0x80031B70-0x80031BBC, ROM 0x32770, size 76 bytes. Ends with the return
and an empty delay slot; the following function begins a new frame at
0x80031BBC. 7 direct callers target the entry.

## Callers / callees
7 callers. Calls either func_800319F4 or func_80031BBC, never both.

## Globals
None. Reads two fields of the object passed in: a 32-bit flag word at offset
0x64 and a pointer at offset 0x1E70, then an unsigned byte at offset 0x10 of
the pointed-to object.

## Regional addresses
jp 0x800325D0 (ROM 0x331D0), eu 0x80035130 (ROM 0x35D30), lrg_rev1 shares the
USA address. Regional bodies are structurally identical; jp resolves the two
callees at 0x80032454 / 0x8003261C, eu at 0x80034FB4 / 0x8003517C.

## Behavior
Takes an object pointer and a second value that is only forwarded. Tests bit
26 of the 32-bit flag word at offset 0x64 of the object. It then reads the
sub-object pointer at offset 0x1E70 and fetches the unsigned byte at offset
0x10 of that sub-object as an identifier. If the flag bit is set the identifier
and the forwarded value are handed to func_80031BBC; otherwise they are handed
to func_800319F4. Nothing is returned.

## Status
exact (USA, JP, EU, lrg_rev1 all byte-identical). The second parameter is
required for the match: it is passed straight through in place, which is why
the object pointer is copied to a later argument register.
