## Recovered behavior
The routine runs a preparation step and then queries a descriptor for a status
code. Unless that code is 1 or 2 it simply performs the follow-up step and
returns.

When the code is 1 or 2 it performs the same follow-up step and then works on a
buffer: an initialisation pass over the whole buffer, then two transfers of
0x3F0 bytes, the first from offset 0 and the second from offset 0x400, and
finally a completion step.
