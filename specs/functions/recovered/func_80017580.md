# func_80017580

## Boundary

- USA VRAM range 0x80017580 - 0x800175DF (inclusive), size 96 bytes, ROM 0x18180.
- Body ends with the return instruction plus a filled delay slot; the delay slot
  performs the store of the third translation component.
- The preceding function (func_80017520) returns immediately before this label
  with its own delay slot filled, and none of its branches reach this address,
  so 0x80017580 is a genuine entry point.
- Direct calls in the USA build target exactly this address.
- No stack frame is created.
- Boundary as assigned is correct.

## Callers

Fifteen direct call sites in the USA build. The sampled sites build a
stack-local 64-byte scratch area, load three consecutive 32-bit words from a
nearby stack structure as the three arguments, and then immediately concatenate
that scratch area into another matrix, confirming the destination layout.

## Callees

None. This is a leaf routine.

## Globals

None referenced.

## Recovered behavior

The routine fills a 4x4 single-precision matrix, laid out as sixteen
consecutive floats in row-major order with translation in the last row, with a
pure translation transform. The four diagonal entries are set to one; the nine
off-diagonal entries outside the last row are set to zero; and the three
entries of the last row receive arguments two, three and four in order. The
destination is written unconditionally; nothing is read back and nothing is
returned.

Structurally this is the same routine as the scaling constructor at
func_80017520 with the roles of the constant one and the arguments exchanged,
which is why the two have identical size.

## Argument evidence

Argument one is the destination address. Arguments two, three and four arrive
in the integer argument registers and are transferred into floating point
registers before being stored as 32-bit floats, so all three are `f32`.

## Regional addresses

- Japan: VRAM 0x800176B0, ROM 0x182B0, size 96. Body read independently; same
  store sequence in the same order.
- Europe: VRAM 0x80017A10, ROM 0x18610, size 96. Body read independently; same
  store sequence in the same order.
- lrg_rev1 shares the USA addresses.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1 from a single source
file.
