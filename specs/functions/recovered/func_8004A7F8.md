# func_8004A7F8 — teardown of a holder's two attached resources

## Boundary
- USA VRAM 0x8004A7F8 .. 0x8004A87F (136 bytes, ROM 0x4B3F8).
- Ends with the return instruction whose delay slot is empty filler; the stack
  frame of 40 bytes is released in the instruction before it.
- Boundary confirmed: seven direct call sites all target 0x8004A7F8, no branch
  from the preceding function reaches into this range, and the prologue
  (frame adjustment) is the first executed instruction. Not corrected.

## Callers
Seven direct call sites, all inside one large dispatcher near 0x8004AA00 -
0x8004AC30 that selects a per-kind shutdown routine. Every site passes a single
pointer and ignores the result, so the function returns nothing.

## Callees
- `func_800181BC` — a five-argument routine (pointer, selector, flag word,
  mask, mode) shared by many subsystems. Its return value is discarded here.

## Globals and access widths
- `D_800A4BC0` — 16-bit signed counter/state word, read once with a halfword
  load and cleared with a halfword store.

All three regional bodies were read independently and are instruction-for-
instruction the same shape as the USA one, differing only in the relocated
callee and global addresses.

## Recovered behavior
The argument is a pointer to a control block that owns up to two attached
resources, stored at byte offsets 0x28 and 0x30 of the block.

1. The first attached resource is fetched. If it is present, the shared
   five-argument routine is invoked on it with selector 2, flag word 3, mask
   0x10 and mode 2 — the release form of that call.
2. The second attached resource is fetched from the block afresh (the block
   pointer is re-read from its incoming home slot) and, if present, released
   with exactly the same four constants.
3. Finally the shared 16-bit state word is examined: if it currently holds the
   value 5, it is reset to 0. Any other value is left untouched.

Nothing is returned.

The first fetched resource is held in a genuine stack-resident local, which is
why it is written to the frame even though it is only used as a call argument;
the second is used directly out of the block.

## Status
Exact. Byte-identical to the original in us, jp, eu and lrg_rev1 under the
accepted `ido53_o2` profile. No per-unit flags needed.
