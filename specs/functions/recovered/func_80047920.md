# func_80047920 — refresh the highlight state of every listed entry

## Boundary

* USA VRAM `0x80047920` .. `0x800479A3` (132 bytes, 33 instructions), ROM `0x48520`.
* Ends with the return instruction at `0x8004799C` followed by an empty delay
  slot; the preceding function ends with its own return at `0x8004791C`.
* Four direct callers reach the entry address; no branch from the previous
  function crosses into it. The assigned boundary is correct.
* One instruction inside the body (`0x80047978`) is unreachable: it is the
  stranded copy of the first instruction of the following block, left behind
  when the branch-likely conditional took that instruction into its delay slot.
  It is not a separate basic block and does not extend the function.

## Callers and callees

* Callers: 4 call sites (two distinct regions of the same module).
* Callees: none — this is a leaf.

## Globals and access widths

| symbol | width | use |
| --- | --- | --- |
| `D_8011A26C` | 32-bit signed | number of listed entries; re-read on every pass |
| `D_8011A508` | 32-bit pointers | table of entry handles; this function reads the pointer array that begins 0x238 bytes into the object, indexed by the loop counter |
| `D_800A4BE8` | 32-bit signed | index of the entry that is currently selected |

Each entry handle points at a record whose first word is the address of the
object to be updated. Within that object this function touches a 16-bit field
at offset 0x0E and a 32-bit flag word at offset 0x10.

## Recovered behaviour

Walk the list of entries from the first to the last, where the number of
entries is read from the shared counter. For each position, take the entry
handle stored in the table and follow it to the object it names. Entries whose
object is absent are skipped.

For every present object the function records whether that entry is the
selected one: the 16-bit field is set to zero for the position that matches the
currently selected index and to one for every other position. In both cases the
object's flag word gains the "needs redraw" bit (value 4).

Because the counter is a shared global and the flag stores may alias it, the
counter is read again after each object is written, so a change made elsewhere
during the pass is observed on the next iteration; positions that were skipped
do not re-read it.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.

Note for the source shape: writing the "no object" case as an early skip
(`continue`) rather than wrapping the body in a conditional is what places the
counter re-read on the shared path instead of duplicating it into both arms of
the selected/not-selected test; the wrapped form is eight bytes longer.
