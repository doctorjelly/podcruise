# func_8003F300

## Boundary

- USA VRAM `0x8003F300`..`0x8003F387` (136 bytes, 34 instructions), ROM `0x3FF00`.
- Ends with the return instruction followed by an empty delay slot.
- Boundary confirmed correct: the two internal labels are the inner-loop head
  and the outer-loop tail, both reached only by backward or forward branches
  from inside this range, and the two direct call sites target `0x8003F300`.

## Callers and callees

- 2 direct call sites in the USA build.
- No callees; leaf function.

## Globals and access widths

| Symbol | Access | Meaning |
| --- | --- | --- |
| `D_800A2170` | 32-bit read of the variable itself | pointer to a null-terminated table of pointers to descriptor records |

Descriptor record fields used (all 32-bit reads): `+0x00` identifier,
`+0x04` a second identifier-like word, `+0x08` element count, `+0x0C` element
stride in bytes, `+0x10` pointer to the first element.

Element fields written: `+0x00` 32-bit, `+0x04` 16-bit, `+0x06` 16-bit.

## Recovered behavior

The routine (re)initialises every element of the descriptor whose identifier
matches the argument.

It walks the null-terminated table of descriptor records. For each record whose
first identifier word equals the argument, it walks that record's element array
using the record's own stride, and for each element writes three fields: the
record's identifier into the element's first 32-bit field, the element's own
zero-based position into the first 16-bit field, and the record's second
identifier word (narrowed to 16 bits) into the second 16-bit field. The
position counter is a 16-bit signed value, so the loop bound is compared after
narrowing. A record whose element count is zero or negative contributes
nothing.

The scan does not stop at the first match; it continues to the end of the
table. Nothing is returned.

## Compiler notes

The record pointer is a source-level local assigned from the dereferenced table
slot inside the loop body, not an assignment folded into the loop condition;
writing it in the condition costs two fewer instructions and does not match.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
