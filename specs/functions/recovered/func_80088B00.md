# func_80088B00

## Boundary

- USA VRAM `0x80088B00` .. `0x80088B13`, ROM `0x89700`, 20 bytes (5 instructions).
- Terminates with `jr $ra` whose delay slot performs the single word store, so the
  body ends exactly at the reported size.
- All seven direct callers `jal` the entry address; nothing before the entry falls
  through into it, and there are no internal branch targets.
- Boundary as assigned: correct.

## Callers / callees

- 7 direct callers, all in the early main-loop objects; several pair this call with
  `func_80088B20` on the same object.
- No callees (leaf).

## Globals

- None.

identical to the USA body (no data relocations are involved).

## Recovered behavior

Takes an object pointer and a signed 16-bit selector value. Sign-extends the
selector to 32 bits and stores it into the 32-bit field at offset 0x3C of the
object, which is that object's "currently selected entry" index. Returns nothing.
The second parameter is genuinely 16-bit: the compiler both sign-extends it and
spills it to its argument home slot, which is the reliable width tell.

## Status

`exact` in usa, japan, europe and lrg_rev1.
