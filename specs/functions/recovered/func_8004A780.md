# func_8004A780

## Boundary
USA VRAM 0x8004A780-0x8004A7F8 (120 bytes, 30 instructions). The return's
delay slot restores the stack pointer. Boundary confirmed against the single
caller; not corrected.

## Callers
One direct caller.

## Callees
func_800181BC, taking five arguments; the fifth travels in the outgoing
argument area.

## Globals
D_8011A508: a table of 151 pointers, read one word at a time. The word past
its end (D_8011A764) serves only as the loop's end address.

## Regional addresses
- Japan: function 0x8004B3C0 (ROM 0x04BFC0); table at 0x8011D778; callee at
  0x800182EC.
- Europe: function 0x8004F2A0 (ROM 0x04FEA0); table at 0x801231A8; callee at
  0x8001864C.
- lrg_rev1: shares the USA addresses.

## Recovered behavior
The routine takes one argument, stores it in its frame and never reads it
again; the argument is nevertheless part of the real signature. It then walks
all 151 entries of the table. For each entry that is a non-null pointer it
reads the first word of the object pointed at; when that word is also non-zero
it is passed to func_800181BC as the first argument, together with the fixed
values two, minus four, sixteen and three. The first word is tested twice in
succession, which is what the original source did — the guard appears both at
the outer level and again immediately inside it. Null entries and objects
whose first word is zero are skipped. The routine returns nothing.

## Status
exact. USA, Japan, Europe and lrg_rev1 all verified byte-identical.
