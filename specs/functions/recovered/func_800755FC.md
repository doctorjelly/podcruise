# func_800755FC

## Boundary
VRAM 0x800755FC-0x80075648, ROM 0x761FC, size 76 bytes. Ends with the return
and an empty delay slot. 2 direct callers target the entry.

## Callers / callees
2 callers. Calls func_8007531C unconditionally and func_80075490 conditionally.

## Globals
D_8011C8D8 (32-bit signed counter, written and read) and D_8011C8DC (32-bit,
written only).

## Regional addresses
jp 0x8007622C (ROM 0x76E2C), eu 0x8007AADC (ROM 0x7B6DC), lrg_rev1 shares the
USA address. Regional bodies are structurally identical (jp globals
D_8011FB48/D_8011FB4C, callees func_80075F4C/func_800760C0; eu globals
D_80125578/D_8012557C, callees func_8007A7FC/func_8007A970).

## Behavior
Takes two pointer arguments. Clears both global counters to zero, then runs the
gathering pass func_8007531C over the second argument, which is what fills the
first counter in. If that counter came back positive, the collected result is
consumed by calling func_80075490 with the first argument, which had been kept
across the call. Nothing is returned.

## Status
exact (USA, JP, EU, lrg_rev1 all byte-identical).
