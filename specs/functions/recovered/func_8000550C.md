# func_8000550C

## Boundary

- USA VRAM range: 0x8000550C .. 0x80005568 inclusive (0x60 = 96 bytes, 24 instructions).
- USA ROM offset: 0x610C.
- Terminates with a return whose delay slot performs the final float store to
  offset 0x38 of the global matrix, so the last store is part of the function.
- Assigned size 96 was correct; no boundary correction.

## Callers and callees

- Three direct call sites in the USA build; takes no arguments and returns nothing.
- No callees (leaf function).

## Globals and access widths

- `D_8009A29C` — 32-bit integer word, written once with zero.
  Already treated as `s32` by the existing recovered `func_80005AFC`.
- `D_800AEC80` — sixteen consecutive 32-bit floats, written at offsets
  0x00..0x3C. The write pattern (1.0 at 0x00/0x14/0x28/0x3C, 0.0 elsewhere)
  identifies it as a row-major 4x4 float matrix.

## Regional addresses

Body is instruction-for-instruction identical in every version; only the two
global addresses move.

| version  | VRAM       | ROM     | counter global | matrix global |
|----------|------------|---------|----------------|---------------|
| us       | 0x8000550C | 0x610C  | D_8009A29C     | D_800AEC80    |
| jp       | 0x8000550C | 0x610C  | D_8009AF8C     | D_800B1ED0    |
| eu       | 0x8000550C | 0x610C  | D_8009F7EC     | D_800B7920    |

## Recovered behavior

Resets the module's shared transform state. It clears the integer counter to
zero and then loads the shared 4x4 float matrix with the identity: the four
diagonal cells receive 1.0 and the twelve off-diagonal cells receive 0.0.

The emitted store order is a fingerprint of the original source shape. The four
diagonal cells are written from the highest to the lowest, which is what the
compiler produces for four ordinary assignments written in descending row
order; the twelve zero cells are then written in ascending address order, which
is what it produces for twelve ordinary assignments written in normal reading
order. Writing the diagonal as a single chained assignment instead makes the
compiler round-trip the constant through memory, adding one reload instruction,
so the recovered source uses separate statements.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
