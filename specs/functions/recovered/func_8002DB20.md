# func_8002DB20

## Boundary

- USA VRAM 0x8002DB20..0x8002DBD8, ROM 0x2E720, size 184 bytes (0xB8).
- Ends with the return instruction plus its delay slot popping the 0x30-byte
  frame; five callee-saved registers are saved and restored.
- Ten direct call sites target 0x8002DB20, so the assigned boundary is correct
  (the assignment lists five, but the label is unambiguous either way).

## Callers

Callers pass an object pointer and a signed count, and test the returned value
against a sentinel, so the result is a signed index or -1.

## Callees

- func_8002DAD0(object, kind, slot) - predicate returning zero or one; the
  second argument is a signed byte and the third an unsigned byte.

## Globals and access widths

- D_800A21B4: array of unsigned bytes indexed by the object's signed byte kind
  field; each element is the number of slots that kind has. Read once per loop
  iteration, from an address whose base stays in a register across the call.

## Recovered behavior

Given an object and an ordinal, the function finds the ordinal-th slot of that
object which passes the predicate.

1. Read the object's kind byte and look up how many slots that kind has.
2. Walk the slots from zero upwards, asking the predicate about each one. The
   kind byte and the slot count are re-read from memory on every iteration, so
   a predicate that changes them changes the walk.
3. Count the passing slots, starting the counter at -1 so that the first pass
   makes it zero. As soon as the counter equals the requested ordinal, return
   that slot's index.
4. If the walk finishes without reaching the requested ordinal - including the
   case where the kind has no slots at all - return -1.

## Compiler notes

The kind field must be typed as a signed byte and the predicate's second
parameter as a signed byte too; the third parameter is an unsigned byte, which
is what narrows the loop counter at the call.

## Status

Exact in USA, Japan, Europe and lrg_rev1 under the accepted ido53_o2 profile;
no per-unit compiler flags needed.
