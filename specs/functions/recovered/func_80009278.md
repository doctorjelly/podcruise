## Recovered behaviour

The routine records one value in a three-slot circular history. It reads the
current write cursor, stores the low sixteen bits of the argument into that slot
of the history array, then advances the cursor by one and wraps it back to zero
after the third slot by taking the remainder on division by three. The cursor is
read once and the updated value written back as a halfword.

The remainder is a signed remainder of a signed cursor, so a cursor that had
somehow gone negative would stay negative; in normal operation the cursor only
ever holds 0, 1 or 2.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
