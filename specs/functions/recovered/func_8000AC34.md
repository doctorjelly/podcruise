# func_8000AC34 — object slot flag set

## Boundary

- USA VRAM range: `0x8000AC34` .. `0x8000AC5F`, **size 44 bytes**,
  11 instructions, ROM `0xB834`.
- Single return point at `0x8000AC58`; its delay slot holds the word store
  that commits the updated flag field, so the store is part of the function.
- Boundary confirmed correct: 62 direct call sites target `0x8000AC34`, the
  preceding function ends with its own return, and no branch from outside
  enters this range. The next label `func_8000AC60` (13 direct callers) starts
  immediately after the delay slot.

## Callers

62 direct call sites. Two arguments: a selector in argument one and a value in
argument two.

## Callees

None; leaf, no stack frame (only the argument home slot for the first,
narrow-typed argument is written).

## Globals and access widths

| symbol | access | note |
|---|---|---|
| `D_800D2190` | element stride 32 bytes; one 32-bit read-modify-write at element offset +0x14 | table of 32-byte object slots |

Argument one is spilled to its incoming home slot, which is the compiler's
signature for a sub-word (16-bit) parameter type; it is sign-extended from 16
bits before use. Argument two is used at full 32-bit width and is not spilled,
so it is a full-width value.

Each regional body was read independently; all are identical to the USA body
except for the high/low halves of the table address.

## Recovered behaviour

Given a signed 16-bit slot index and a 32-bit bit mask, the routine turns on
every bit of the mask in the 32-bit flag word stored at offset 0x14 of that
slot in the object table. The existing value of the flag word is read, the
mask is OR-ed into it, and the result is written straight back. No bounds
check of any kind is performed — a negative index reads and writes before the
start of the table. Nothing is returned.

## Status

Exact. Byte-identical against USA, Japan, Europe and lrg_rev1 at 44 bytes,
first attempt.
