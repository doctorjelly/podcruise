# func_800547EC — update race-map display objects

## Verified boundary

- USA VRAM `[0x800547EC, 0x80055AEC)`, ROM `[0x553EC, 0x566EC)`,
  4,864 bytes.
- The return is at `0x80055AE4`; its delay slot restores the `0x730`-byte
  frame at `0x80055AE8`.
- The recovered `func_8005C36C` is the sole direct USA caller. It invokes this
  routine during the per-frame race-display update outside one session mode.

## Inputs and dependencies

The argument is the active session. Fields used here select the display mode,
provide the course graph and craft pose, describe two session flags, and give
the number of 0x88-byte racer records in `D_8011B1B8`. `D_8011B1BC` identifies
the local racer and `D_8011B1C0` a second specially displayed racer.

The 44 static calls comprise `func_8000A920` (4), `func_8000AA04` (4),
`func_8000AAC0` (5), `func_8000AB24` (4), `func_800154D0` (1),
`func_8003E54C` (5), `func_8003EC40` (7), `func_80052134` (1),
`func_8007EE40` (1), `func_8008035C` (4), `func_80080DB4` (1), and
`func_8008A6B4` (7). They obtain progress and scale, sample nearby graph
points, normalize a direction, configure display objects, enqueue markers,
format placement labels, and enqueue text. The globals provide map dimensions,
format strings, camera state, display controls, and frame duration.

## Behavior

When the map system is disabled, the routine changes nothing. Otherwise it
coerces the session's display mode when the global detail level crosses its
two-state threshold, then updates one of four presentations:

- Mode 0 draws a vertical course-progress strip. It locates the active racer
  tagged `Locl`, wraps every active racer's relative progress to half a lap in
  either direction, and places visible racer icons between rows 74 and 164.
  The local icon is larger and more opaque. Positive placements receive a
  colored text label.
- Mode 1 maps normalized progress onto the perimeter of a rectangle spanning
  x coordinates 20 through 280 and y coordinates 15 through 215. Each active
  racer receives an icon, and multi-racer sessions add placement labels.
- Modes 2 and 3 form a camera-relative overhead map. Up to 170 sampled course
  points are projected around `(264, 82)`, followed by four markers along the
  craft axis, visible remote racers, and the local racer. Mode 2 uses the
  configured range and mode 3 uses a 500-unit range; a controller flag mirrors
  the horizontal projection.
- Modes 5 and 7 lay racer icons along horizontal progress rows. The local and
  second special racer occupy their own rows and icon slots; the latter can be
  tinted red. Positive placements are drawn in local, special, or neutral
  colors.

The overhead-map opacity rises toward one only in modes 2 and 3. In every
other handled mode it falls toward zero, with both changes scaled by twice the
frame duration.

## Status

Behavior-recovered C, not byte-matching. The exact isolated comparison starts
at the canonical address but first differs at byte `0x2`: IDO 5.3 emits 4,328
bytes and IDO 7.1 emits 4,272 bytes against the 4,864-byte body. The IDO 5.3
object retains the canonical sequence of all 44 static calls, including the
same per-callee counts; that structural check does not make it an exact match.
