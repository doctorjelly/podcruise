# func_8008D420

## Boundary

- USA VRAM range: 0x8008D420 .. 0x8008D44C inclusive (0x30 = 48 bytes, 12 instructions).
- USA ROM offset: 0x8E020.
- Terminates with a return whose delay slot releases the eight-byte frame the
  entry sequence reserved, so both words belong to the function.
- Assigned size 48 was correct; no boundary correction.

## Callers and callees

- One direct call site in the USA build, at 0x8008830C, whose caller branches on
  the returned flag immediately afterwards.
- No callees (leaf function).

## Globals and access widths

- A memory-mapped hardware register at physical-uncached address 0xA450000C
  (the audio interface status word), read once as a single 32-bit quantity.
  The original source addressed it as a literal absolute address rather than as
  a named symbol: a named external forces the address into the same register
  the loaded value ends up in, whereas the literal keeps the address in a
  separate scratch register, which is what the ROM image does.

## Regional addresses

The body is bit-for-bit identical in all four images; nothing relocates,
because the only address referenced is the fixed hardware register.

| version  | VRAM       | ROM     |
|----------|------------|---------|
| us       | 0x8008D420 | 0x8E020 |
| jp       | 0x8008E110 | 0x8ED10 |
| eu       | 0x80092970 | 0x93570 |
| lrg_rev1 | 0x8008D420 | 0x8E020 |

## Recovered behavior

Takes no arguments and reports whether the audio hardware is currently busy.
It reads the audio interface status word once and tests the most significant
bit. If that bit is set the function answers 1, otherwise it answers 0. The
answer is a plain flag, not the register contents.

## Compiler note (important for the whole translation unit)

This body cannot be produced at the project's accepted `-O2` setting. At `-O2`
the compiler collapses the mask against the sign bit into a sign test and drops
the frame entirely, yielding 36-40 bytes. At `-O1` it keeps the explicit mask,
keeps the eight-byte frame, and keeps the split return paths, matching the ROM
exactly. The status word must also be held in a variable declared `register`,
otherwise the compiler spills it into the frame in the branch delay slot.

Accepted flag set for this unit:
`-G 0 -O1 -mips2 -non_shared -Xcpluscomm -signed -Wab,-r4300_mul`

`tools/verify_c_matches.py` already supports a per-unit `flags` key that
overrides the profile flags, and the unit verifies byte-exact through the
normal `ido53_o2` profile when that key is present.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
