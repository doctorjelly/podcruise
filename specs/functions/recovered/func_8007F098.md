# func_8007F098

## Verified facts

- The USA function spans VRAM `0x8007F098` through `0x8007F22B`, ROM
  `0x7FC98`, and is 404 bytes. Its `jr $ra` is at `0x8007F224`; the delay slot
  is `nop`.
- `func_800801B8` passes it as a callback to `func_8007F560`. The callback has
  four arguments: a track-like record, a float scale, a search-space pointer,
  and a signed-halfword sample table.
- It calls `func_8003B02C`, `func_80000520`, `func_80005134`,
  `func_8003A568`, `func_800183A8`, and `func_800183B0`.
- It reads the track float at offset `0x08`, an object's signed halfword at
  offset `0x3C`, and an item's flag halfword at offset `0x00`. It updates
  `D_8011DCF8`, and reads `D_800ADC50` and the address of `D_800A6708`.
- The Japan and Europe equivalents are `func_8007FD38` at ROM `0x80938` and
  `func_80084578` at ROM `0x85178`. Their instruction and branch structure is
  identical after symbol relocation.

## Behavior

Build a downward probe at the track transform's translation and search the
provided space while the global query mode is enabled. If that misses, reverse
the probe direction and retry. Store the resulting object in a table indexed
by the track lane and scaled position. A newly encountered object records that
index. If an existing index maps to a different sample value, attach the
default item when absent or set bit 3 in the existing item's flags.

## Status

Behavior recovered from the USA binary and independently expressed in C. IDO
5.3 `-O2` emits the target length of 404 bytes, but the first byte difference
is at offset `0x9F`; equal length is not an exact match. This is therefore not
claimed as byte-matching.
