# func_800116E8

## Boundary
VRAM 0x800116E8-0x80011764 (124 bytes, ROM 0x122E8). Ends with a return whose
delay slot restores the stack pointer. Two direct callers.

## Callers / callees
2 callers. Calls func_8000A920.

## Globals and access widths
- D_800D6140: array of 80 signed words (identifiers, -1 meaning "unused")
- D_800D68C0: array of 80 bytes, written a byte at a time
- D_800D6910: the address one past the end of the byte array; the loop bound

## Regional addresses
- jp 0x800116E8, globals relocated to D_800D9390 / D_800D9B10 / D_800D9B60
- eu 0x80011B78 (ROM 0x12778), globals D_800DEDE0 / D_800DF560 / D_800DF5B0
- lrg_rev1 0x800116E8, identical to USA

## Behavior
Releases every entry of an 80-slot table. For each slot, if the stored
identifier is not the "unused" marker of -1, it is passed, narrowed to a signed
16-bit value, to the release routine together with a second argument of zero.
Every slot's companion status byte is cleared, whether or not a release
occurred. Nothing is returned.

## Status
exact in USA, Japan, Europe and lrg_rev1.
