# func_80093A60

## Boundary

VRAM 0x80093A60..0x80093A8B (44 bytes, USA ROM 0x94660). The body ends with a
return whose delay slot releases the frame, and the next function starts
immediately at 0x80093A8C region boundary. The two interior labels are the arms
of the single conditional, neither of which is called directly. Boundary as
assigned; no correction.

## Callers

Five direct call sites in USA: 0x8008B0CC, 0x8008B0DC, 0x8008B154, 0x8008B164
and 0x800939E4.

## Callees

None. Leaf function.

## Globals and access widths

One 32-bit read of the signal-processor status register at physical 0x04040010
(uncached 0xA4040010). The address is a literal in the source so that its low
half folds into the load displacement.

## Regional addresses

- Japan: 0x80094750, ROM 0x095350
- Europe: 0x80098FB0, ROM 0x099BB0
- lrg_rev1: 0x80093A60, ROM 0x94660 (same as USA)

All regional bodies were read independently and are word-for-word identical to
the USA body; nothing relocates.

## Recovered behavior

Reports whether the signal processor's transfer engine is currently occupied.
It reads the status word and tests the three-bit group covering "transfer in
progress", "transfer queue full" and "register queue full" (mask 0x1C). If any
of those is set it returns one, otherwise zero. Callers use it as a spin
condition before programming a new transfer.

## Compiler notes

Same as func_80093990: this unit was built at optimization level 1, which is
what produces the unused eight-byte frame, the status word living in an
argument register, and the single shared epilogue reached by a branch from the
first exit. At level 2 the same source compiles to 40 bytes with two separate
returns and no frame.

## Status

Exact in USA, Japan, Europe and lrg_rev1 with the unit compiled at optimization
level 1 (flags: -G 0 -O1 -mips2 -non_shared -Xcpluscomm -signed
-Wab,-r4300_mul), recorded as a per-unit flag override.
