# func_8001F464 — report whether option bit 1 of the global settings word is set

## Boundary — corrected

- USA VRAM range: `0x8001F464` .. `0x8001F48B` (inclusive), **40 bytes**.
- ROM offset `0x20064`, translation unit `main_18B28.s`.
- The final instruction pair is a return with an empty delay slot at
  `0x8001F484`/`0x8001F488`; there is an earlier return with a value-producing
  delay slot at `0x8001F47C`/`0x8001F480`. Two return sites, one function.
- **The assigned extent (64 bytes) was wrong in two ways and both were
  corrected.** The generated inventory covers this ROM range in two overlapping
  translation units, so its instruction counts (and therefore its byte sizes)
  are doubled for functions in that range; the real instruction count here is
  ten, not sixteen. Independently, the heuristic labelling split the function at
  `0x8001F484` and presented that address as its own routine. It is not one: it
  has no call sites at all, it is reached only by a forward conditional branch
  from `0x8001F474` inside this body, and it is the `else` tail of this
  function's single test. Including it, the function is 40 bytes and ends
  immediately before the true next function at `0x8001F48C`, which begins with
  a stack-frame prologue.
- The 40-byte extent is confirmed by construction: the recovered C compiles to
  exactly these 40 bytes at this address.

## Callers

One direct call site, at `0x8000F3CC`. No argument registers are set up, and the
caller immediately branches on the result being non-zero, so the routine takes
no arguments and returns a 32-bit integer used as a boolean.

## Callees

None (leaf).

## Recovered behaviour

The routine reads the global settings word and answers a single question: is
option bit 1 set? It returns one when the bit is set and zero when it is clear.
Nothing else is read, nothing is written, and the answer does not depend on any
argument. The single caller uses it to skip a block of work when the option is
enabled.

## Status

Exact in USA, Japan, Europe and lrg_rev1. Boundary corrected from 64 bytes to
40 bytes.
