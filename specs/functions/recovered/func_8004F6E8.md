# func_8004F6E8 — build the default entry-order table

## Boundary

* USA VRAM `0x8004F6E8` .. `0x8004F78F` (168 bytes, 42 instructions), ROM `0x502E8`.
* Ends with the return instruction at `0x8004F788` and an empty delay slot.
* One direct caller targets the entry; no branch from the previous function
  crosses into it. The assigned boundary is correct.

## Callers and callees

* Callers: 1.
* Callees: none — leaf.

## Globals and access widths

| symbol | shape | use |
| --- | --- | --- |
| `D_800A4B7C` | four 32-bit words | the order table this function fills |
| `D_800A4B8C` | — | not a value: this is the address one past the end of the table, produced by the compiler as the limit of the clearing loop |

The single argument is a pointer to a record; the function reads one **signed
8-bit** field at offset 0x70 of that record and uses it as a count.

| version | entry | ROM | table |
| --- | --- | --- | --- |
| usa | `0x8004F6E8` | `0x502E8` | `D_800A4B7C` |
| japan | `0x80050354` | `0x50F54` | `D_800A78EC` |
| europe | `0x80054390` | `0x54F90` | `D_800A9E7C` |
| lrg_rev1 | `0x8004F6E8` | `0x502E8` | same as usa |

Each regional body was read independently and all are the same shape as USA;
in every version the loop limit symbol is the table symbol plus 16 bytes, which
confirms the four-entry table size.

## Recovered behaviour

Take the count of participating entries from the caller's record (a small
signed byte). First mark all four table positions as empty by writing all-ones
into each. Then, for as many entries as the count says, write the identity
ordering: position zero gets entry zero, position one gets entry one, and so
on. A count of zero or less leaves the table fully cleared.

Two separate running values are kept while filling — the position being written
and the entry number being written into it — even though they advance together;
that separation is visible in the original, which increments both in the
remainder pass of the unrolled loop and derives the table address from the
position counter alone.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
