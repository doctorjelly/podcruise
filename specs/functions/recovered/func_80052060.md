## Behavior
The routine asks a lookup service for the resource identified by the four
character code "Test", passing zero as the second selector. If the lookup
reports failure it answers with minus one. Otherwise it consults a single
global pointer; when that pointer is null it again answers minus one. When the
pointer is present the routine reads the pointer stored 0x84 bytes into that
object, advances it by 0xAC bytes, and returns whatever single-precision value
the second service produces for that address.

## Status
