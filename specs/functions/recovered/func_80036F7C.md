## Recovered behavior

A two-line reset of a write cursor over a fixed buffer.

1. Point the cursor word `D_800A3D30` at the start of the buffer `D_800DB930`.
   Only the address is taken; nothing in the buffer is read or written here.
2. Clear the companion counter `D_800A3D38` to zero.

Nothing is returned. The gap between the two globals (eight bytes apart, with an
untouched word between them) confirms they are separate scalars rather than
neighbouring fields written as a pair.
