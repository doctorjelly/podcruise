# func_80088360

## Boundary
VRAM 0x80088360-0x800883DC, ROM 0x88F60, 124 bytes. Returns through the normal
epilogue with an empty delay slot. 36 direct callers, all targeting 0x80088360.
Boundary as assigned is correct.

## Callers / callees
36 direct callers. Calls func_8008D450 as a tail fallback (its result is the
routine's result).

## Globals and access widths
None. One 32-bit argument, homed in the incoming argument slot and re-read from
there on every use.

## Regional addresses
- jp 0x80089050 (ROM 0x89C50); fallback func_8008E140
- eu 0x8008D8B0 (ROM 0x8E4B0); fallback func_800929A0
- lrg_rev1 shares the USA addresses.

## Recovered behavior
Translates a CPU-visible address into a bus address. If the address lies in the
first cached kernel window (0x80000000 up to but not including 0xA0000000) the
result is the address with its top three bits cleared. If it lies in the
uncached kernel window (0xA0000000 up to but not including 0xC0000000) the same
masking applies. Any other address is not a simple window mapping, so the
routine defers to a helper that performs the general translation and returns
whatever the helper returns.

## Notes on the build
The unit is one of the project's -O1 regions: every use of the argument is a
fresh reload of its stack home slot. Compiled at -O1 the body is byte identical;
at -O2 it is twelve bytes shorter.

## Status
exact in USA, Japan, Europe and lrg_rev1 (compiled -O1).
