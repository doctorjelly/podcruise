# func_80088500

## Boundary

- USA VRAM range: 0x80088500 .. 0x8008852F inclusive (0x30 = 48 bytes, 12 instructions).
- USA ROM offset: 0x89100.
- One internal forward branch target sits at 0x80088528, four instructions from
  the end; it has no direct call sites of its own and is the join point of the
  single conditional, not a separate function.
- Terminates with a return whose delay slot copies the result register.
- Assigned size 48 was correct; no boundary correction.

## Callers and callees

- Nine direct call sites in the USA build, all in the audio-buffer scheduling
  code around 0x8008FFxx-0x800900xx. Several call it, test the result against
  zero, and only proceed when a node came back.
- No callees (leaf function).

## Globals and access widths

- `D_800A6990` — a 32-bit pointer word holding the address of the audio
  manager block; read once, as a word. Same global as `func_800884E8`.
- Offset 0x2C of that block is a 32-bit pointer: the head of the same singly
  linked free list.
- Offset 0x00 of a node is its 32-bit link field.

## Regional addresses

The body is instruction-for-instruction identical in every version; only the
manager pointer relocates.

| version  | VRAM       | ROM     | manager pointer |
|----------|------------|---------|-----------------|
| us       | 0x80088500 | 0x89100 | D_800A6990      |
| jp       | 0x800891F0 | 0x89DF0 | D_800A97E0      |
| eu       | 0x8008DA50 | 0x8E650 | D_800ABC90      |
| lrg_rev1 | 0x80088500 | 0x89100 | D_800A6990      |

## Recovered behavior

Takes one node off the manager's free list, the exact inverse of
`func_800884E8`. It reads the list head; if the list is empty it returns
nothing. Otherwise the head advances to the taken node's successor, the taken
node's link field is cleared so the detached node carries no stale pointer, and
the taken node is returned. Takes no arguments.

Two source-shape facts are pinned by the emitted code. The result is a single
variable initialised to nothing before the test and assigned inside the taken
branch, rather than two separate return statements: the zero is materialised
into its own register before the list head is even loaded, which is what a
pre-initialised result variable produces. The manager pointer is cached in a
local first, for the same aliasing reason as in `func_800884E8`; that also
fixes which registers the pointer and the taken node land in.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
