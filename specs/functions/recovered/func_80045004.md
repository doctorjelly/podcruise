# `func_80045004` USA compiler audit

The current C source is behavior-recovered but not exact. The isolated linked
comparison is 232/320 bytes, 56 differing comparable words and 22 missing
words; the first byte difference is `0x03`.

The USA ROM loads `session->unk_B7C[i]` at `800450AC`, compares it with zero,
and uses a branch-likely at `800450B8` whose two paths each increment the loop
index. The current C omits this otherwise redundant predicate. Three bounded
source variants restored it: an empty `>= 0.0f` branch after the helper, a
`< 0.0f` `continue` after the helper, and an empty `< 0.0f` branch inside
the nonzero-slot block. They compiled to 240 bytes and 57, 57, and 58
differing comparable words respectively; none matched. All edits were
reverted, and the parent reran the 232/320 baseline verifier.

The ROM also saves six floating-point register pairs and materializes
`10.0f` and `30.0f` before the loop; those operations remain unexplained by
the current source. Do not repeat the predicate-only variants without new
evidence about the floating-point register use or source-unit shape.
