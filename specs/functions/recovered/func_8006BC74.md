# `func_8006BC74`

## Verified facts

The canonical USA function occupies VRAM `0x8006BC74` through
`0x8006C0D3`, ROM `0x06C874` through `0x06CCD3`, for 1,120 bytes. Its
return is at `0x8006C0CC`; the delay slot restores the 352-byte stack frame.
The next established entry begins at `0x8006C0D4`.

The sole direct USA caller is at `0x8006C174` in `func_8006C0D4`; its call
delay slot writes the caller's updated word at actor offset `0x64`. The body
directly calls `func_8001514C`, `func_80015170`, `func_80015190`,
`func_800151C0`, `func_800151E0`, `func_8003FDCC`, `func_8006A3EC`,
`func_8006B9C8`, and `func_8006BB50`. It contains no indirect call.

The addressed global values are `D_800AD5EC` and `D_80120BF0`. The compiler
folds `10.0f * 10.0f` into a file-local `100.0f` literal stored at
`0x800AD5F0`; placing the unit's constant pool there accounts for the only two
instructions that previously differed.

Japan carries the same-size function at VRAM `0x8006C7E4`, ROM `0x06D3E4`,
and Europe at VRAM `0x80071154`, ROM `0x071D54`. Their return and stack-restore
delay slots have the same relative offsets, and their next entries begin at
offset `0x460`. The USA LRG revision retains the USA address and bytes.

## Behavioral specification

Reject an actor that has either excluded flag combination, then query up to
four nearby actors and consider the first result. Reject that result under the
same flag rules. Compute the two actors' projected paths and closest points;
continue only when the returned time is nonnegative, the horizontal separation
is inside a ten-unit radius, and the time reaches the shared threshold.

Form a shared midpoint adjusted by both actors' weighted path directions.
Evaluate both paths slightly before the reported time, normalize their
horizontal separation, and place the actors on opposite sides of the shared
point by half the collision radius. Update each actor's current position,
travel magnitude, response direction, response helpers, and accumulated
half-displacement.

Calling this a two-body collision response is an inference from the geometric
tests and paired state updates. The control flow, constants, field offsets,
calls, and writes are facts recovered from the binary.

## Status

text bytes exactly for USA retail and the USA LRG revision when the local
constant pool is linked at `0x800AD5F0`. Existing region-specific exact
comparisons also reproduce the Japan and Europe bodies; those versions serve
