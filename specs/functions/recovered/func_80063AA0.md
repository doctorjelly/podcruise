# func_80063AA0

## Boundary
VRAM 0x80063AA0-0x80063AE0 (64 bytes), ROM 0x646A0. Ends with the return
instruction and an empty delay slot; sixteen direct callers target the entry.
The conditional branch inside the body lands on the epilogue, not past it.
Boundary confirmed as assigned.

## Recovered behavior
Takes two pointers. Looks something up by the fixed four-character tag
0x456C6D6F, passing the first pointer as the lookup's context. If the lookup
returns a null result the routine does nothing further; otherwise it passes the
found object together with the second incoming pointer to the action routine.
Returns nothing.
