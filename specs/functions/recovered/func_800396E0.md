# func_800396E0

## Boundary
USA VRAM 0x800396E0-0x80039767 (136 bytes), ROM 0x3A2E0. Ends with a return
whose delay slot is empty. Two direct callers target the entry. Boundary as
assigned is correct.

## Callees
func_80039340 (three arguments), func_8003931C (no arguments).

## Globals
D_80113680: a record whose first word is read as a signed word and whose byte
at offset four is read unsigned. Its address is passed to func_80039340 with a
length of 0x3F0.

## Regional addresses
Japan 0x8003A084 (ROM 0x03AC84); Europe 0x8003DF94 (ROM 0x03EB94). Not probed
because the USA form is not yet byte-exact.

## Behavior
The routine validates a saved record supplied by the caller. A result flag
starts out set.

It first asks a loader to read 0x3F0 bytes into the shared record from the
caller's source. If that loader reports a non-zero failure code the result is
cleared. Otherwise the byte at offset four of the record must equal one; if it
does not, the result is cleared. Otherwise a checksum routine is run and its
value compared with the record's first word; a mismatch clears the result.

The routine returns the flag: one when the record loaded, carried the expected
tag byte and matched its checksum, zero otherwise.

## Status
Behavior recovered. The compiled form differs from the original by one
instruction: the original materialises the record's address into a register and
then reads the tag byte at offset four from it, while the recovered source
folds the offset into the load. Every other instruction, the frame size and the
control flow agree. An eight-byte unused local is required to reproduce the
original frame size.
