## Recovered behavior

The function builds a 256-entry lookup table for a bit-at-a-time,
most-significant-bit-first cyclic redundancy check that uses the standard
32-bit polynomial 0x04C11DB7.

For every index from 0 to 255 the index is shifted left by 24 bits so that it
occupies the top byte of a 32-bit accumulator. That accumulator is then
advanced eight times. Each advance inspects the top bit of the accumulator: if
the top bit is set the accumulator is shifted left one place and combined with
the polynomial by exclusive-or; if the top bit is clear the accumulator is
simply shifted left one place. After the eight steps the accumulator is stored
as the table entry for that index.

The eight-step inner loop is written as a countdown; the compiler unrolled it
four steps at a time, giving two passes of four steps each with the counter
decreasing by four, which is why the emitted counter starts at eight and is
tested against zero.

Nothing is returned. The function has no early exit and always writes all 256
entries.
