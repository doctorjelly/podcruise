# func_800315D8

## Boundary

- USA VRAM range 0x800315D8 - 0x8003163F inclusive (0x68 = 104 bytes).
- Terminates with the standard return instruction whose delay slot releases the
  0x20-byte stack frame.
- Five call sites; two are external (0x80051CAC and one nearby) and three are
  the routine calling itself, all targeting 0x800315D8. Entry confirmed.

## Callers

External caller in the reset path around 0x80051CA4; otherwise self-recursive.

## Callees

Itself only.

## Globals

- `D_800DB8AC` - base of a table whose records are 28 bytes apart. The field
  written here is a 32-bit word at the start of each record, so the table is
  modelled as `s32 D_800DB8AC[][7]` and only column zero is touched.

## Parameters

One signed integer selector. -1 is a sentinel meaning "all". Nothing is
returned.

## Recovered behaviour

Clears the first word of one record of a four-entry table. When the selector is
the sentinel -1 the routine recurses over selectors 0 through 3 so that every
record is cleared; otherwise it zeroes the addressed record's leading word
directly.

Source-shape notes:

- The recursion loop's bound is an inequality against four, matching the
  register-held count in the original.
- The record stride has to be expressed as a two-dimensional array subscript
  (`table[selector][0]`). Writing it as a flat index scaled by seven produces
  the same arithmetic but allocates one extra temporary register, which is a
  two-instruction mismatch.

## Status

Exact in USA, and byte-identical in Japan, Europe and lrg_rev1 from the same
source.
