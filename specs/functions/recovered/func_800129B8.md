# func_800129B8

The canonical USA body starts at VRAM `0x800129B8`, ROM `0x135B8`, and
contains 44 bytes through the return delay slot at `0x800129E0`. The older
assembly scan split the initial index shift from the prologue at `129BC`;
these are one function, since the shift supplies the table offset.

The wrapper selects a font pointer from `D_800D6940`, measures the supplied
text with `func_800129E4`, and returns the width unchanged. The call at
`129CC` is followed only by frame restoration and return, preserving `$v0`.
The callee places the accumulated glyph widths into `$v0` at `12B58`.
For example, the caller at `func_8001F5AC` consumes this width when centering
an underline; this is an observed return contract, not an inference from an
unused register value.

The previous `void` declaration accidentally preserved the register on IDO
but omitted this behavior from C. The corrected return and typed font/text
pointers retain the exact 44-byte USA body. `text_metrics.h` shares the
contract with the callee; its font tag change leaves its compiled text
unchanged at 376 bytes (still nonmatching).

`tests/test_text_metrics.c` invokes both production functions with two small
fonts. It checks empty text, selected-font widths, lowercase mapping, and
the `~n` terminator. The old wrapper fails this typed return-value regression.
