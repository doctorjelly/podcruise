# func_8008A2F0

## Boundary
USA VRAM 0x8008A2F0-0x8008A357, ROM 0x8AEF0, size 104 bytes (26 instructions).
Ends with a return whose delay slot is empty. Three direct call sites; the
prologue is the first instruction of the body. Boundary confirmed, not corrected.

## Callers / callees
Three direct callers. Calls func_8008CA80 on entry and func_8008CAA0 on exit —
the acquire/release pair used throughout this module.

## Globals and access widths
`D_800A7F54` is a 32-bit pointer to a control block. Through it the routine
writes a 16-bit field at offset 0, a pointer field at offset 8, and a 32-bit
field at offset 0xC. The block referenced by offset 8 is read at its offset 4
as a 32-bit value.

## Regional addresses
- Japan: 0x8008AFE0 / ROM 0x08BBE0, block pointer at 0x800AADA4, pair
  func_8008D770 / func_8008D790.
- Europe: 0x8008F840 / ROM 0x090440, block pointer at 0x800AD254, pair
  func_80091FD0 / func_80091FF0.
- lrg_rev1: identical to USA addresses.

## Behavior
The routine takes one pointer argument. It first acquires the module's
exclusion token. It then installs the argument as the control block's current
record pointer, marks the block's 16-bit status field as busy (value 1), and
copies the second word of the newly installed record into the block's
0xC field, so the block caches that value alongside the record. Finally it
releases the token it acquired. No value is returned.

The control block pointer is re-read from memory before each of the three
accesses, because the stores through it may alias the pointer itself.

## Compilation notes
This translation unit is an optimisation-level-1 region: every local is held in
a stack slot, arguments are spilled to their caller-provided home slots and
reloaded, and the global's address is re-formed for each access. The exclusion
token is the one value the original kept in a callee-saved register, which a
`register` storage class on the local reproduces.

## Status
Exact in USA, Japan, Europe and lrg_rev1.
