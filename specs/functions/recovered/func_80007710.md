# func_80007710

## Verified facts

- The USA function spans VRAM `0x80007710` through `0x80007727`, ROM
  `0x8310`, 24 bytes. Its `jr ra` is at `0x80007720`; the delay slot completes
  the returned function address with the low half of `func_80007594`.
- It has no direct calls or global reads. It stores the address of
  `D_800AFAC0` through its pointer argument and returns the address of
  `func_80007594`.
- `func_80007218` installs this routine by address in a subsystem boot record.
  The returned routine manages the lists anchored at `D_800AFAC0`, confirming
  the relationship between both returned addresses.
- Japan and Europe use the same VRAM and ROM addresses and contain the same six
  words.

## Behavior

Publish the shared list anchor through the caller's output pointer and return
the associated buffer-management callback. This supplies both pieces of a
small callback interface without invoking either target.

## Status

Japan and Europe contain the same six words at the same addresses; only USA is
integrated here.
