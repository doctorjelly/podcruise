# func_80093A90

## Boundary

USA VRAM 0x80093A90-0x80093B5F (208 bytes, ROM 0x94690). Ends with the return
and a register move in its delay slot. Three direct call sites target
0x80093A90. The assigned boundary is correct.

## Callers

Three. Two of them mask their argument to sixteen bits at the call site, which
confirms the parameter is a sixteen-bit unsigned quantity; all three combine the
returned value with other bits using bitwise or, so the result is used as a
small integer field.

## Callees

None. Leaf function, no frame adjustment; the argument home slot store is the
only stack traffic.

## Globals

None.

## Recovered behavior

The function computes a five-bit cyclic redundancy check over an eleven-bit
message, using the generator whose low bits are 1, 0, 1, 0, 1.

The single argument is an unsigned sixteen-bit value; only its low eleven bits
take part. The remainder starts at zero. The function walks a single-bit mask
downwards from the eleventh bit to the first, and for each position shifts the
remainder left by one and then folds in two things: the message bit at that
position, contributed as a one in the remainder's lowest bit, and the generator,
exclusive-ored in whenever the shift pushed a one out past the five-bit window.
The two cases are fused in the compiled body - when the message bit is set and
the window overflowed, the constant folded in is the generator with its low bit
already flipped.

After the eleven message bits are consumed the function runs five more
shift-and-fold passes with no further message input, which is the usual way of
appending the check field's own width to the message. The low five bits of the
remainder are the result.

## Source shape notes

Three details decide the byte match. The parameter is a sixteen-bit unsigned
type, which is what produces the otherwise dead argument home-slot store. The
message is copied into a full-width unsigned local before the loop, which is
what turns the parameter's zero-extension into a value written back into the
argument register rather than into a fresh one. And the mask must be an unsigned
type so that its downward walk uses a logical rather than an arithmetic shift.
The result is assigned to a sixteen-bit local before being returned, which is
what produces the copy-mask-copy sequence in the epilogue rather than a single
mask.

The five trailing passes are written as a counted loop over a literal bound and
are fully unrolled by the compiler; the eleven message passes are written as a
mask walk and are not unrolled.
