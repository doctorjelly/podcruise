## Behavior

Run a fixed sequence of subsystem initializers, accumulating whether any of
four checks reports a state change. If none does, repeatedly service input,
objects, timing, presentation, and display work. One pair of global flag bits
raises a shared word flag; the loop clears that word before the display update.
Two additional services are skipped only on the first pass. A later state
change exits this phase.

After one final cleanup sequence, load the current floating-point time budget
and enter a permanent service loop. Each iteration updates timing. A positive
budget is reduced by the double-precision frame interval and triggers a display
service; a nonpositive budget is clamped to zero. The callback never returns.

## Status

Behavior recovered, not byte-matching. An exact linked IDO 5.3 `-O2`
comparison reproduces the first 608 bytes, covering every reachable
instruction. The isolated compiler emits three dead padding words before the
unreachable epilogue and a 640-byte body; USA has seven such words and a
656-byte body. The first difference is therefore offset `0x260`, and no exact
claim is made.
