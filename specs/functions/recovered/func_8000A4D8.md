# func_8000A4D8

## Boundary
- USA VRAM 0x8000A4D8 - 0x8000A53B inclusive, ROM 0xB0D8, size 100 bytes
  (25 instructions).
- The body is the first thing in its split unit, so nothing precedes it, and
  it ends with the return instruction whose delay slot performs the frame
  release. All direct call sites target 0x8000A4D8. Boundary as assigned is
  correct.

## Callers
14 direct call sites in the USA build.

## Callees
- `func_8000A44C` (0x8000A44C) - takes a 16-bit index and a 32-bit mode word.

## Globals and access widths
- `D_8009B770` - a signed 32-bit counter. Read for the loop-entry test, read
  again at the bottom of every iteration, and cleared to zero on the way out.

body was read independently and matches the USA shape exactly.

## Recovered behavior
This is a drain routine for a pending-work counter. It walks a running index
from zero upward for as long as the index is still below the current value of
the shared counter, and for each index it calls the worker routine with that
index narrowed to a 16-bit value and a mode of zero. Because the counter is
re-read from memory at the end of every pass rather than cached, work that the
callee appends during the walk is picked up by the same walk. When the index
finally reaches the counter, the counter is reset to zero so the next caller
starts from an empty queue. If the counter is zero or negative on entry the
loop body never runs and the routine simply clears the counter.

## Status
Exact in usa, japan, europe and lrg_rev1 under the accepted `ido53_o2`
profile; no per-unit compiler flags were needed.
