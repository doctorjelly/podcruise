# func_80006FE4

## Boundary
VRAM 0x80006FE4-0x80007034, ROM 0x7BE4, size 80 bytes. Ends with a return whose
delay slot is empty. Five direct callers target the entry; boundary confirmed,
no correction needed.

## Callers / callees
5 callers. Calls func_80087FC0 (five arguments) and func_80006FD4 (no arguments).

## Globals
None.

## Regional addresses

eu 0x80006FE4 / ROM 0x007BE4 (calls func_8008D510);

## Behavior
Takes four word-sized arguments. The first is accepted but never read. The
routine forwards the remaining three to a five-argument service routine,
supplying two leading zeros ahead of them, and keeps that routine's result.
It then invokes a second, argument-less routine, and finally returns the result
it had kept from the first call.

## Status
exact (USA, Japan, Europe, lrg_rev1).
