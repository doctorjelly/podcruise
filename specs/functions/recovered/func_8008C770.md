# func_8008C770

## Boundary
VRAM 0x8008C770-0x8008C7B0 (64 bytes, 16 instructions). The final instruction is
the frame release in the return's delay slot. Two direct call sites target the
entry. Not corrected.

## Callers
Two direct call sites.

## Callees
func_8008CA80 (produces a handle), func_8008CAA0 (consumes the handle).

## Globals
D_800A7F50, read as a whole word: it holds a pointer to a record, and the word
at offset 4 of that record is read.

## Regional addresses
- jp 0x8008D460 (rom 0x08E060)
- eu 0x80091CC0 (rom 0x0928C0)

## Recovered behavior
Obtains a handle from func_8008CA80, then follows the global pointer
D_800A7F50 and reads the second word of the record it designates, keeping that
value aside. It then releases the handle through func_8008CAA0 and returns the
value it kept. The read of the record deliberately happens before the release
call, so the reported value reflects the state observed while the handle was
still held.

## Status
Behavior recovered, not byte-exact. Frame size, global access and the deferred
return value all reproduce; the remaining difference is that the original keeps
the handle in a callee-saved register and copies it into the argument register
as a separate step, whereas the accepted profile forwards the call result
straight into the argument register, leaving the body one instruction short.
Source variations (pointer versus integer handle, declaration order, a local for
the global pointer, statement grouping onto one line) and flag variations (-O1,
-O3, the IDO 7.1 profile) did not change that choice. func_8008A710, in the same
address region, shows the identical discrepancy.

## Status update (retry pass)

Exact. The translation unit was built at optimisation level 1, and the value the
body holds across the inner call was declared with the `register` storage class
so it stays in a callee-saved register instead of spilling to the frame. Japan,
Europe and lrg_rev1 all verify exact from the same source with name remapping
only; the regional bodies were read independently and are structurally identical.
