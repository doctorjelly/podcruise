# func_80097D20

## Boundary
VRAM 0x80097D20-0x80097D6C, ROM 0x98920, size 76 bytes. Ends with the return
and an empty delay slot. 1 direct caller, which passes a single constant.

## Callers / callees
1 caller (inside the routine at 0x80094A14, passing 0x00100C01). Calls
func_8008CA80 on entry and func_8008CAA0 on exit; both are coprocessor-0
status-register helpers, i.e. an interrupt-disable / interrupt-restore pair.

## Globals
D_800A7B50: a 32-bit word, read and written once (bitwise accumulation).

## Regional addresses
jp 0x80098A10 (ROM 0x99610), eu 0x8009D270 (ROM 0x9DE70). Not probed, since the
USA form is not yet byte-exact.

## Behavior
Takes one 32-bit bit-mask argument and returns nothing. Enters a critical
section by disabling interrupts, remembering the previous enable state. While
interrupts are off it merges the argument's bits into the global accumulator
word with a bitwise OR, so the request is recorded atomically with respect to
interrupt handlers. It then leaves the critical section by restoring the
previously saved state, and returns.

## Status
behavior. The recovered logic is certainly right (three-statement critical
section) but the byte form is not reproduced at -O2: the original keeps the
saved state in a callee-saved register, reserves eight extra bytes of frame,
and does not common-subexpression the two accesses to the global into a shared
base register. Compiling the same source at -O2 -g1 with the saved state
declared `register` reproduces the original's exact instruction sequence,
frame size and register assignment, differing only in delay-slot filling (the
-g1 build leaves the two slots empty and branches to the epilogue). The unit
this function lives in was therefore very likely built with a debug-level flag;
identifying the exact flag combination is the remaining step.

## Status update (retry pass)

Exact. The translation unit was built at optimisation level 1, and the value the
body holds across the inner call was declared with the `register` storage class
so it stays in a callee-saved register instead of spilling to the frame. Japan,
Europe and lrg_rev1 all verify exact from the same source with name remapping
only; the regional bodies were read independently and are structurally identical.
