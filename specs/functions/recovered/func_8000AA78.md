# func_8000AA78

## Boundary

- USA VRAM range: `0x8000AA78` .. `0x8000AABF` inclusive (72 bytes / 18 words).
- USA ROM offset: `0xB678`.
- Ends with a return at `0x8000AAB8` whose delay slot is empty.
- The single conditional branch targets the return inside the range.
- One direct call site targets `0x8000AA78`; the preceding block
  (`func_8000AA04`, see its own note) reaches its own return at `0x8000AA70`
  and does not cross into this address.
- Boundary as assigned is correct.

## Callers / callees

- Callers: 1 direct call site (from the `main_D138` region, around
  `0x8000E7D8`).
- Callees: none. This is a leaf.

## Globals and access widths

- `D_800D2190` — base of the array of 32-byte records. Two 16-bit fields at
  record offsets `0x04` and `0x06` are written.

## Recovered behaviour

Sets the second 16-bit coordinate pair of a record.

Parameters: a 16-bit signed record index and two 16-bit signed values.

If the index is negative the routine returns without touching anything.
Otherwise the two values are written into the record's fields at offsets `0x04`
and `0x06`, in that order.

Together with `func_8000AA04` (which writes offsets `0x00` and `0x02`) this
gives each record two independent 16-bit pairs — the layout of a source and
destination rectangle, or a position and a size.

Unlike `func_8000AA04` there is no sentinel index here, and unlike
`func_8000A44C` there is no upper bound check; only the negative case is
guarded.

The routine returns nothing.

## Status

Exact. USA, Japan, Europe and `lrg_rev1` verified byte-identical.
