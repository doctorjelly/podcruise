# func_8000787C

## Boundary

- USA VRAM range: 0x8000787C .. 0x800078B0 inclusive (0x38 = 56 bytes, 14 instructions).
- USA ROM offset: 0x847C.
- Ends with a return whose delay slot is empty; the conditional body branches
  forward to that return.
- Assigned size 56 was correct; no boundary correction.

## Callers and callees

- One direct call site in the USA build. The caller hands over a single float
  computed in floating point immediately before the call, so argument 1 is an
  `f32`. Nothing is returned.
- No callees (leaf function).

## Globals and access widths

- `D_8009A2B8` — 32-bit integer word, read as an enable flag.
- `D_8009A328` — 32-bit integer word, written with the converted value.

## Regional addresses

Body is instruction-for-instruction identical in every version; only the two
global addresses move.

| version  | VRAM       | ROM    | flag global | result global |
|----------|------------|--------|-------------|---------------|
| us       | 0x8000787C | 0x847C | D_8009A2B8  | D_8009A328    |
| jp       | 0x8000787C | 0x847C | D_8009AFA8  | D_8009B018    |
| eu       | 0x8000787C | 0x847C | D_8009F808  | D_8009F878    |
| lrg_rev1 | 0x8000787C | 0x847C | D_8009A2B8  | D_8009A328    |

## Recovered behavior

Publishes a normalized level as a scaled integer, but only while the module is
enabled. If the enable word is zero the function does nothing at all. Otherwise
it multiplies the incoming float by 32000.0 and stores the result, truncated
toward zero, into the integer result word. The literal 32000 is the full-scale
amplitude of a signed 16-bit audio sample, so the parameter is a 0..1 style
gain and the stored word is that gain expressed on the sample scale.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
