# func_80034374

## Boundary

- USA VRAM range: 0x80034374 .. 0x800344C4 inclusive (0x154 = 340 bytes, 85 instructions).
- USA ROM offset: 0x34F74.
- Ends with a return whose delay slot performs the last float store, so that
  store is part of the function. Assigned size 340 was correct; no boundary
  correction.

## Callers and callees

- Three direct call sites in the USA build. One argument: a pointer to a
  sixty-four byte destination buffer (one caller passes a stack slot of exactly
  that size). No return value.
- Leaf function; no callees.

## Globals and access widths

- `D_800A3FF0` — one 32-bit integer word, read as an index. It is re-read before
  every single element copy, twelve times in total.
- `D_80112EA0` — an array of records forty-eight bytes apart; within the
  selected record twelve consecutive 32-bit floats are read at offsets 0x00
  through 0x2C.

## Regional addresses

Body is instruction-for-instruction identical in every version; only the two
globals move.

## Recovered behavior

Expands the currently selected twelve-float record into a full four-by-four
float matrix in the caller's buffer.

The global index selects one record from the global table. The twelve floats of
that record are copied in order into the first three columns of the four rows of
the destination. The remaining fourth column is filled in with constants: zero
for the first three rows and one for the last. The result is the ordinary
homogeneous form of a three-column affine transform.

Source-shape notes established by matching:

- The full indexed expression is written out at every one of the twelve copies
  rather than being hoisted into a pointer local. The compiler keeps the record
  stride and the table base in registers but genuinely re-reads the index word
  each time, because a store through the caller's pointer might have changed it.
- The four constant stores are written after the twelve copies. The compiler's
  scheduler then hoists three of them above the final copy's store, which is why
  the constant stores appear before the last data store in the emitted order.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
