# func_8003FA24

## Boundary

USA VRAM 0x8003FA24 - 0x8003FB34 (exclusive), ROM 0x40624, size 272 bytes.
The body ends with the return jump whose delay slot restores the stack
pointer, and every direct call site targets 0x8003FA24, so the assigned
boundary is correct. No boundary correction was needed.

## Callers

24 direct call sites, spread across the main code segment. Each one loads a
four-character ASCII literal into the first argument ("Load", "Scen", "Hang",
"Stop", "Wake", "All!", ...) and passes the address of a small stack buffer,
whose first word is another four-character literal, as the second argument.
The result register is never consumed by a caller, so the function is void.

## Callees

None statically. The function performs one indirect call through a function
pointer read out of the traversed records.

## Globals and access widths

- `D_800A2170` - a 32-bit word holding a pointer to a null-terminated array of
  record pointers. JP: `D_800A4EE0`. EU: `D_800A76C0`. lrg_rev1: same as USA.

Record fields touched (all 32-bit words):
- +0x00 four-character identifier
- +0x08 element count (signed)
- +0x0C element stride in bytes (signed)
- +0x10 pointer to the first element
- +0x24 handler function pointer

Element field touched:
- +0x06 signed 16-bit flag word, tested against bit 0x100

## Recovered behavior

The routine broadcasts a message to registered record groups. It walks the
null-terminated array of group records reachable through the global pointer.

For each group it decides whether the group is addressed: either the caller's
identifier equals the group's own identifier, or the caller passed the
wildcard identifier `'All!'` (0x416C6C21).

An addressed group is serviced only if it carries a handler. When it does, the
routine walks the group's elements, stepping by the group's stride and
re-reading the element count from the record on every pass, so a handler that
grows or shrinks the group is observed immediately. An element whose flag word
has bit 0x100 set is skipped. Otherwise the handler is invoked with the
element and the caller's message pointer passed twice. A handler that returns
2 aborts the whole broadcast immediately.

After a group has been serviced, a non-wildcard broadcast stops - only the one
addressed group is ever visited. A wildcard broadcast continues to the next
group. Groups that are not addressed are stepped over without any work.

## Status

Exact on USA, Japan, Europe and lrg_rev1.
