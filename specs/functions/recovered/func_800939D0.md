# func_800939D0

## Boundary
VRAM 0x800939D0-0x80093A5B (140 bytes), ROM 0x945D0. Ends with the return
instruction followed by an empty delay slot. Four direct callers.

## Callers / callees
Four callers. Calls func_80093A60 (no arguments, returns a busy indicator) and
func_80088360 (one argument, returns an address).

## Globals
Four memory-mapped device words at 0xA4040000, 0xA4040004, 0xA4040008 and
0xA404000C, each accessed as a full word write.

## Regional addresses
- jp: func_800946C0 @ ROM 0x952C0
- eu: func_80098F20 @ ROM 0x99B20
- lrg_rev1: same addresses as USA

## Behavior
Starts one DMA transfer on the audio-interface-adjacent device block. It first
asks whether the device is busy and returns -1 without touching anything if it
is. Otherwise it programs the device-side address from the second argument, the
host-side address obtained by translating the third argument, and then the
length, minus one, into either the read-length or the write-length register
depending on whether the first argument is zero. It returns 0 on success.

## Compilation note
This unit is built at -O1: every value is reloaded from its stack slot, the
device addresses are materialised from literal constants rather than from a
linker symbol, and branch delay slots are left empty.

## Status
exact in USA, Japan, Europe and lrg_rev1.
