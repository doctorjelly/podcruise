# func_800281F0

## Boundary

USA VRAM 0x800281F0 - 0x8002831F inclusive, ROM 0x28DF0, size 304 bytes
(76 instructions). The body ends with the return instruction at 0x80028318
whose delay slot at 0x8002831C performs the final global store. Three direct
callers (0x8001AF74, 0x8001BD90, 0x8001BDDC) all target 0x800281F0. Every
internal label is a branch target from within the range. Boundary confirmed,
not corrected.

## Callers

Three, from the 0x8001A000-0x8001C000 region.

## Callees

None; leaf function, no stack frame.

## Globals and access widths

| symbol      | use                                                            |
|-------------|----------------------------------------------------------------|
| D_80113E74  | table of 44-byte records; word zero of the selected record read |
| D_800D6CD8  | 23 records of 8 bytes: word at +0, byte at +4, byte at +5       |
| D_800D6D90  | not a distinct datum - it is the address one past D_800D6CD8    |
| D_8011A26C  | word, written once with the produced count                      |

The record size of D_800D6CD8 is fixed by the array end: 0x800D6D90 minus
0x800D6CD8 is 184, which is 23 times 8. The stride of D_80113E74 is built by
the shift-and-subtract chain that multiplies the index by 44.

## Argument

One argument, a pointer. Only one field is read: a signed byte at offset 0x6F,
used as the index into D_80113E74.

## Recovered behaviour

The routine rebuilds a 23-entry selection list from a bitmask.

It reads the signed byte at offset 0x6F of its argument, uses it to pick a
record out of the 44-byte-strided table, and takes the first word of that
record as an availability mask. The constant 0x00022E01 is then merged into
that mask with a bitwise or, so bits 0, 9, 10, 11, 13 and 17 are always
treated as available regardless of the table contents.

It then walks bit positions 0 through 22 in ascending order. For every bit that
is set in the merged mask it appends one entry to the front of the destination
list: the entry's word is set to the bit position, the byte at +4 is set to
255, and the byte at +5 is cleared. Entries are appended densely, so the list
is a compacted, ascending list of the set bit positions.

Every remaining entry of the 23-slot list, from the number appended through
slot 22, is filled with the empty marker: word set to -1, byte at +4 set to
255, byte at +5 cleared.

Finally the number of appended entries is stored in the standalone count word.

## Notes on shape

- The two loops are written the same way in the source, but only the second is
  unrolled by the compiler; the conditional body of the first suppresses
  unrolling. The remainder-first prologue and the pointer-compared-against-the
  -array-end terminator of the second loop are the compiler's own strength
  reduction, not source structure.
- The count and the mask must be introduced in that order (count first). With
  the mask declared and assigned first the two ended up in the opposite pair of
  registers and the body differed in five instructions with no other change.
- `s8` does not exist in the project's type header, so the argument is spelled
  `signed char *`.

## Status

Exact in all four versions (usa, japan, europe, lrg_rev1).
