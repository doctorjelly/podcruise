# func_80090170

## Boundary

- USA VRAM `0x80090170`..`0x800901F4`, ROM `0x90D70`, size 132 bytes (33 instructions).
- Ends with a return whose delay slot is empty. The two labels inside the range
  are the merge points of the two early exits and have no direct callers.
  Boundary confirmed, not changed.
- Frame is 24 bytes: saved return address only. The three argument home slots
  live above the frame, in the caller's outgoing-argument area.

## Callers

Two direct call sites.

## Callees

- `func_80088500` — an argument-less allocator that pops one record off a free
  list and returns it, or returns null when the list is empty.
- One indirect call through a function pointer stored inside the target object.

## Globals and access widths

None. All state is reached through the two pointer arguments.

Field accesses:

| object | offset | width | use |
| --- | --- | --- | --- |
| argument 1 | `0x1C` | 32-bit word | a base value, added to a per-stream value |
| argument 2 | `0x08` | 32-bit pointer | the stream; null means "do nothing" |
| stream | `0x0C` | 32-bit pointer | the receiver object |
| stream | `0xD8` | 32-bit word | per-stream offset added to the base |
| receiver | `0x08` | 32-bit function pointer | the entry point invoked |
| record | `0x00` | 32-bit word | cleared |
| record | `0x04` | 32-bit word | the computed sum |
| record | `0x08` | 16-bit halfword | the constant kind code 12 |
| record | `0x0C` | 32-bit word | the third argument, zero-extended from a byte |

Argument 3 is one byte wide: it is homed as a word and then re-read as an
unsigned byte from the low end of its own home slot, which is the reliable
signal for an unsigned `char` parameter, and it is widened to a full word when
stored into the record.

## Recovered behavior

Posts one event of kind 12 to the stream owned by the second argument.

If that object currently has no stream attached, the function returns
immediately. Otherwise it asks the shared allocator for a free event record; if
the allocator is exhausted the function returns without reporting an error.

With a record in hand it fills it in: the timestamp field is the caller's
current clock value (offset `0x1C` of the first argument) advanced by the
stream's own accumulated offset (offset `0xD8` of the stream), the kind field
is set to 12, the payload word is the byte-sized third argument, and the link
or status word at offset zero is cleared last. It then dispatches the record by
calling the handler function stored in the receiver object hanging off the
stream, passing that receiver as the first argument, a fixed selector of 3, and
the record.

The source order of the four record stores is load-bearing for the match: the
clear of offset zero must be written last. Any of the six orders that write it
first produce the same four stores in a different schedule.

The paired function `func_800902A0` is the identical routine for kind 7 with a
single-precision float payload.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1 under the accepted
`ido53_o2` profile. No per-unit flags needed.
