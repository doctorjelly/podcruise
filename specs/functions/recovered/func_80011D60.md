# func_80011D60

## Boundary
VRAM 0x80011D60-0x80011DE4, size 132 bytes. Ends with the return jump whose
delay slot restores the stack pointer. 14 direct callers all target 0x80011D60;
the single internal label is the loop head, reached only by the body's own
backward branch. Boundary as assigned is correct.

## Callers / callees
14 callers. Calls func_80008F28 (no arguments, no result used) and
func_80011BDC (two pointers and a length).

## Globals
None.

## Regional addresses
Not listed in the assignment; the lrg_rev1 build shares the USA address and
verified byte-identical there.

## Behavior
Takes two byte pointers and a signed length. It performs one service call, then
while the remaining length is positive it transfers at most 0x800 bytes per
pass: the pass length is the whole remainder when that is 0x800 or less, and
0x800 otherwise. Each pass hands the current pair of pointers and the pass
length to the transfer routine, then advances both pointers by the pass length,
reduces the remainder by it, and repeats the service call. Nothing is returned.

## Status
exact (USA and lrg_rev1).
