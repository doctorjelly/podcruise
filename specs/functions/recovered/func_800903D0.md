# func_800903D0

## Boundary
VRAM 0x800903D0-0x80090448 (120 bytes, ROM 0x90FD0). Ends with a return whose
delay slot is empty. Two direct callers.

## Callers / callees
2 callers. Calls func_80088500 and one indirect target taken from a dispatch
table.

## Globals and access widths
None. Reads a word at 0x1C of the first argument, a word at 0x8 of the second,
a word at 0xD8 and a word at 0xC of the object that reaches, and a function
pointer at 0x8 of that. Writes a word at 0x0, a word at 0x4 and a halfword at
0x8 of the freshly obtained record.

## Regional addresses
- jp 0x800910C0 (ROM 0x91CC0)
- eu 0x80095920 (ROM 0x96520)

## Behavior
Does nothing unless the second argument carries an attached context. When it
does, it asks the allocator for a fresh record; if none is available it returns
immediately. The record is tagged with kind 15, its first word cleared, and its
second word set to the sum of a value held by the first argument and a value
held by the context. The record is then delivered to the context's handler,
which is invoked with itself, a code of 3, the record, and the second argument.
Nothing is returned.

## Status
behavior-recovered. Correct length (120 bytes) and instruction-for-instruction
identical except for the choice of scratch registers from offset 0x35 onward:
the original keeps the allocated record in the call-return register while the
reproduction keeps it in the copy made for the outgoing argument. Eight source
shapes were tried; the flip did not move.

## Note for the orchestrator
func_80088500 takes exactly one argument here: passing the second argument to
it inserts an extra register copy in the prologue, and dropping it makes the
prologue byte-identical.
