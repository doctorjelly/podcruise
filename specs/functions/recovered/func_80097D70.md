# func_80097D70

## Boundary
VRAM 0x80097D70-0x80097DBC, ROM 0x98970, size 76 bytes. Ends with a return whose
delay slot is empty. One direct caller; boundary confirmed, no correction needed.

## Callers / callees
1 caller. Calls func_8008CA80 (no arguments, returns a value), func_8008D12C
(one argument) and func_8008CAA0 (one argument).

## Globals
D_800A7BB8, used only by address as the argument of the middle call.
D_800A7BC0, read as a word pointer; the halfword 0x10 bytes into the object it
points at is set to 2.

## Regional addresses
jp 0x80098A60 / ROM 0x099660; eu 0x8009D2C0 / ROM 0x09DEC0. Not verified,
because the USA form is not yet byte-exact.

## Behavior
Opens or acquires a resource through a first routine and remembers the handle it
returns. It then sets a small halfword field, sixteen bytes into the object that
one global pointer refers to, to the value 2, and submits a second fixed global
object to a processing routine. Finally it releases or closes the remembered
handle through a third routine. Nothing is returned.

## Status
behavior. The recovered C is behaviourally complete and produces the same
instruction sequence apart from where the remembered handle lives: the original
keeps it in a callee-saved register (and reserves eight further bytes of frame),
while every source shape tried spills it to a stack slot. Ruled out: pointer vs
integer handle type, returning the handle, statement grouping onto one line,
a pointer local for the halfword store, -O1/-O3, and -mips1/-mips3/unsigned-char
flag variants. Giving the handle a second use does move it into a callee-saved
register, which suggests the original had one more use of it than is visible, but
no behaviour-preserving second use exists.

## Status update (retry pass)

Exact. The translation unit was built at optimisation level 1, and the value the
body holds across the inner call was declared with the `register` storage class
so it stays in a callee-saved register instead of spilling to the frame. Japan,
Europe and lrg_rev1 all verify exact from the same source with name remapping
only; the regional bodies were read independently and are structurally identical.
