# func_8008AE30

## Boundary
USA VRAM 0x8008AE30-0x8008AE97, ROM 0x8BA30, size 104 bytes (26 instructions).
Ends with a return with an empty delay slot. Seven direct callers target the
prologue. Boundary confirmed, not corrected.

## Callers / callees
Seven direct callers. Calls func_8008CA80 on entry and func_8008CAA0 on exit,
the same acquire/release pair as func_8008A2F0.

## Globals and access widths
`D_80149D00` is a table of eight-byte records, each holding two 32-bit words.
The routine writes both words of one record; nothing else is touched.

## Regional addresses
- Japan: 0x8008BB20 / ROM 0x08C720, table at 0x8014CF70, pair func_8008D770 /
  func_8008D790.
- Europe: 0x80090380 / ROM 0x090F80, table at 0x801529A0, pair func_80091FD0 /
  func_80091FF0.
- lrg_rev1: identical to USA addresses.

## Behavior
The routine takes an index and two 32-bit values. It acquires the module's
exclusion token, forms the address of the table record selected by the index,
stores the first value in the record's first word and the second value in its
second word, and then releases the token. No bounds check is performed and no
value is returned.

## Compilation notes
Same optimisation-level-1 region as func_8008A2F0: all three arguments are
spilled to their home slots and reloaded, and the computed record address is
itself written to a stack slot and read back before the second store. The
exclusion token is held in a callee-saved register, reproduced by giving the
local `register` storage class.

## Status
Exact in USA, Japan, Europe and lrg_rev1.
