## Recovered behavior

Programs the processor's periodic-interrupt deadline. The single argument is
written verbatim into the system coprocessor's timer comparison register, the
register that the hardware continuously compares against the free-running cycle
counter and that raises a timer interrupt when the two become equal. Writing it
also clears any timer interrupt that is currently pending, which is why the
first caller uses an argument of zero as a disarm-and-acknowledge, while the
second caller writes a freshly computed future deadline to re-arm the timer.

The routine does nothing else: no frame is established, no register is
preserved, and nothing is returned.

## Status

Skipped, and it should stay in hand-written assembly.

The entire body is a move to a system-coprocessor control register. That is not
something a compiler will emit from portable source: the source language has no
expression whose value lives in a coprocessor control register, and the
compiler in use offers no intrinsic for the operation. The only ways to produce
these bytes are an assembly source file or an inline-assembly statement, and
the project rules forbid inline assembly in recovered C.

The disassembly tooling independently classifies the function as hand-written
in all four ROMs, which agrees with that assessment. No C file was produced.
Recommendation for the orchestrator: keep this symbol in a hand-written
assembly unit permanently rather than leaving it on the decompilation queue,
and consider auditing the surrounding region for the sibling coprocessor
accessors that normally accompany it.
