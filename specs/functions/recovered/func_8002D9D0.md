# func_8002D9D0

## Boundary

- USA VRAM range 0x8002D9D0 .. 0x8002DA0B inclusive, ROM 0x2E5D0, **60 bytes**
  (15 instructions).
- The assignment file gave 96 bytes. **Boundary corrected**: the generated
  inventory merged this function with the one that follows. The real body ends
  with the return instruction at 0x8002DA04 and its delay slot at 0x8002DA08;
  the next function begins at 0x8002DA0C with a fresh prologue that reloads
  its own first argument.
- Two of the heuristic labels inside the assignment range (0x8002DA00 and
  0x8002DA04) are internal branch targets of this function, not separate
  functions: the early exit path branches to the first and falls through to
  the second.
- There is a second, earlier return point at 0x8002D9F8 (with the value
  materialised in its delay slot); the final return at 0x8002DA04 has an
  empty delay slot.
- No stack frame: the function never adjusts the stack pointer.

## Callers and callees

- Six direct call sites in the USA build. Callees: none (leaf).
- Call sites load argument 1 with a signed byte load and pass argument 2 either
  as an unsigned byte load or masked to eight bits, which fixes the parameter
  widths and signedness.

## Globals and access widths

None. The function touches no static data.

## Arguments and result

- Argument 1: signed 8-bit value (sign extended on entry).
- Argument 2: unsigned 8-bit value (zero extended on entry).
- Result: 32-bit integer, always 3 or 4.
- Both arguments are written to the caller-provided argument home slots on
  entry. That is IDO's standard treatment of sub-word parameters and is dead
  code here; it reproduces automatically from `signed char` / `u8` parameter
  types and must not be modelled as a local variable.

## Recovered behavior

The function classifies a pair of small codes. If the first code is less than
three *and* the second code is less than six, it answers four. In every other
case - the first code being three or more, or the second code being six or
more - it answers three. The second code is only examined when the first test
passes, so the test is a short-circuit conjunction.

## Regional forms

- Japan: 0x8002E434, ROM 0x2F034, 60 bytes - identical instruction sequence.
- Europe: 0x80030F74, ROM 0x31B74, 60 bytes - identical instruction sequence.
- lrg_rev1 shares the USA addresses and matches there too.
- No symbol relocation is needed for any region because the function references
  no external symbol.

## Status
