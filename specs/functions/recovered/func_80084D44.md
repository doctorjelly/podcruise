# `func_80084D44`

## Boundary

- The USA function occupies VRAM `0x80084D44` through `0x80084EB7`, ROM
  `0x085944`, for 372 bytes. It returns with `jr $ra` at `0x80084EB0`; the
  `nop` at `0x80084EB4` is its delay slot.
- The only direct USA caller is `func_80085D44`, at `0x80085DF8`.
- Europe relocates the structurally equivalent 372-byte body to `0x8008A224`
  (ROM `0x08AE24`). Japan relocates its equivalent to `0x80085A24` (ROM
  `0x086624`) and expands it to 392 bytes. These bodies were used only to
  confirm the control-flow structure and relocations.

## Behavior

Append a full-sync command and an end-of-list command to the active display
list, then flush the data cache. Measure the list in commands. If any of four
state flags is set, clear all four and obtain a fresh measurement. Store the
corresponding byte length in the active task descriptor, flush again, and fill
the descriptor for the requested signed 16-bit mode.

When the second argument is nonzero, first service pending control messages and
ensure both task-state words are enabled if either was disabled. Submit the
prepared task. For the same nonzero case, run the two post-submit helpers, then
finish with another cache flush.

## Recovery status

The C is independently expressed and behavior-recovered; it is not
byte-matching. The verified USA IDO 5.3 `-O2` comparison reports its first
difference at byte offset `0x1`. The compiler emits a 356-byte function (368
bytes after isolated-section padding), while the ROM body is 372 bytes.

The central difference is verified: after the flag tests the ROM reloads both
display-list pointers before recomputing the count, whereas IDO common-subexpression
eliminates the repeated source expression. Explicit common-path labels and
reordering the clears did not prevent that optimization. Volatile or absolute
address forms, and distinct-symbol aliases modeled on a neighboring exact
function, retained the reload but produced 384- or 416-byte bodies and
branch-likely delay slots absent from the ROM. Those experiments were reverted;
no exact match is claimed.
