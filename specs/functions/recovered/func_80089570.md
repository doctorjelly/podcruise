## Recovered behavior

Reads the object's currently selected entry index from the 32-bit field at offset
0x3C, indexes the entry table whose base pointer lives at offset 0x40, and returns
the 32-bit word at offset 0x28 of the selected entry. Entries are 48 (0x30) bytes
apart, which the compiler forms as `index * 4 - index` shifted left by four rather
than a multiply.

The address is formed as "scaled index plus table base" rather than the usual
"table base plus scaled index"; expressing the subscript that way (adding the index
to the pointer rather than subscripting the pointer) is what reproduces the operand
order, and holding the table base in a local is what reproduces the register choice.
