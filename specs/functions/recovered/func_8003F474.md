# func_8003F474 — run the second per-element pass over every enabled registry group

## Boundary

* USA VRAM `0x8003F474` .. `0x8003F55F` inclusive, ROM `0x40074`, size 236 (0xEC).
* The body ends with the return instruction; its delay slot releases the stack
  frame.
* The recorded direct call sites target `0x8003F474` itself, and every conditional
  branch inside the body lands inside the range. The assigned boundary is
  correct.

## Callers

One distinct caller, which invokes this function from a fixed sequence of
per-frame passes with no arguments and ignores any return value. Nothing in the
body reads an incoming argument register before overwriting it, so the function
takes no parameters and returns nothing.

## Callees

* `func_80008F28` — called once per element with no arguments.
* The group's own handler, an indirect call taking a single element pointer.

## Globals and access widths

* `D_800A2170` — read as a 32-bit word holding a pointer to a null-terminated
  table of group-descriptor pointers.
* `D_800A4AA0` — read as a signed 16-bit halfword and used as a suppression
  mask.
* Group descriptor fields used, all 32-bit words: a flag word at +0x04, a signed
  element count at +0x08, an element stride in bytes at +0x0C, the first-element
  pointer at +0x10, and the pass handler at `+0x18`.
* Element field used: a signed 16-bit status halfword at +0x06, read only.

Europe addresses above were located by matching the surrounding split listing
line for line and then confirmed instruction by instruction before probing.
Japan renames the registry pointer to `D_800A4EE0` and the suppression mask to
`D_800A7810`; Europe renames them to `D_800A76C0` and `D_800A9DA0`.
`func_80008F28` keeps its address in every build.

## Recovered behavior

The function walks the global registry table from its first entry until the
terminating null pointer, and considers only groups that publish a handler for
this pass at `+0x18`. A group is skipped when any bit of its flag word also
appears in the global suppression mask, which is re-read from memory for every
group so a handler can disable later groups.

For a group that survives both tests, the elements are visited in order starting
at the group's element pointer, each following element sitting the group's stride
further along in memory. An element whose status halfword has either bit 0x100 or
bit 0x1000 set is passed over without invoking the handler; every other element
is handed to the handler. Regardless of whether the handler ran, the element
pointer is then advanced and the shared per-element service routine is called
once.

The stride is read before that service call and the element count is re-read
after it, so both can change during the pass. The visit counter is a signed
16-bit quantity compared against the signed 32-bit count, so a count of zero or
below skips the group's elements entirely. Every qualifying group in the table
is processed; the walk does not stop at the first one.

## Status

Byte-exact in usa, japan, europe and lrg_rev1 under the accepted `ido53_o2`
profile. No per-unit compiler flags were required.
