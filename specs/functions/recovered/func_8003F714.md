## Recovered behavior

The routine looks up one element by identifier and position and returns a
pointer to it.

It walks the same null-terminated descriptor table used by the initialiser.
For each record whose identifier equals the first argument, it walks the
record's element array with the record's stride. An element whose flag word has
bit 8 set is skipped as unavailable. Otherwise the element's 16-bit position
field is compared with the second argument, and on the first equality the
address of that element is returned immediately.

If no record matches, or no live element in a matching record carries the
requested position, the routine returns a null pointer. A record with a
non-positive element count is skipped and the scan continues with the next
record.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
