## Recovered behavior

The function fills one slot of a twelve-entry lighting record table.

Argument one selects the slot. If it is negative, or twelve or greater, the
function does nothing at all and returns; the range test is signed.

Otherwise the selected 40-byte record is written as follows.

Three colour components are taken from the buffer named by argument two. Each
component is read as a single byte located at odd byte offsets 1, 3 and 5 of
that buffer, i.e. the low half of each of three consecutive 16-bit values.
Component one is stored into record bytes 0 and 4, component two into record
bytes 1 and 5, component three into record bytes 2 and 6 - each value written
twice, into two parallel colour triples eight bytes apart in layout terms.

The same is done for the buffer named by argument three: its bytes at offsets
1, 3 and 5 are stored into record bytes 8 and 12, 9 and 13, and 10 and 14.

Finally three signed 16-bit values are read from the buffer named by argument
four, at its offsets 0, 2 and 4. Each is arithmetically negated and the low
byte of the negated result is stored into record bytes 16, 17 and 18. The
negation is done at 32-bit width before the byte is taken, so a source value
of zero stores zero and a source value of 1 stores 0xFF.

Nothing is returned.

## Status

Exact in USA, Japan, Europe and lrg_rev1.
