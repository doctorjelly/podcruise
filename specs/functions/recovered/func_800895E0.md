## Recovered behavior

Stores a small unsigned attribute into one entry of an object's 48-byte entry
table. Arguments are the object, a signed 16-bit entry index, and an unsigned
8-bit value. The table base is read from offset 0x40 of the object; the value is
truncated to eight bits and written as a 16-bit field at offset 0x20 of the
selected entry.

Both trailing arguments are sub-word, which the compiler reveals by spilling each
one to its argument home slot even though the function keeps no frame: the index
is sign-extended from 16 bits and the value is masked to 8 bits before the store.

## Status
