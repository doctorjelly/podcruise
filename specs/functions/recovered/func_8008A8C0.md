# func_8008A8C0

## Boundary — CORRECTED

The assignment gave 120 bytes (0x8008A8C0 .. 0x8008A934). That is only the first
block. Two conditional branches in that block jump *past* its return, to
0x8008A940 and to 0x8008A938, and the block reached at 0x8008A940 branches on to
0x8008AA58 and 0x8008AA3C, which in turn falls into 0x8008AA74. None of those
five labels has a single direct call site; every one of them is an internal
branch target. The real function is:

- USA VRAM range: 0x8008A8C0 .. 0x8008AA7C inclusive (0x1C0 = 448 bytes,
  112 instructions), USA ROM offset 0x8B4C0.
- Followed by padding words before the next code, confirming the end.
- The heuristic labels absorbed by this body: func_8008A938, func_8008A940,
  func_8008AA3C, func_8008AA58, func_8008AA74. They must not be recovered
  separately.

## Callers and callees

- One direct call site (0x80014D00). Leaf function.
- One argument, a 32-bit float arriving in the float argument register; returns
  a 32-bit float.

## Globals and access widths

- `D_800ADE20` — an array of 64-bit floats. Elements 1..4 are read as
  polynomial coefficients; the base address is materialised once and the four
  elements are reached as base+8, +0x10, +0x18, +0x20, which is the compiler's
  form for indexing one array with constant indices. Element 0 is not touched
  here.
- `D_800ADE48`, `D_800ADE50`, `D_800ADE58` — three separate 64-bit float
  constants, each addressed on its own rather than through the array base, so
  they are separate objects in the original even though they sit just past the
  array. The first scales the argument; the other two are the high and low
  halves of a split constant subtracted from the argument.
- `D_800ADE60` — a 32-bit float returned for out-of-range but finite inputs.
- `D_800AE110` — a 32-bit float returned for a not-a-number input.

The 0.5 used in the rounding step is materialised inline from an immediate, not
loaded from memory, so it is a literal in the source.

## Recovered behavior

A single-precision periodic-wave routine (the odd trigonometric one: the result
is an odd function of the argument, the reduction is by half a period, and every
odd multiple flips the sign).

The argument's bit pattern is read as an integer and reduced to a nine-bit
magnitude class: the eight exponent bits together with the top mantissa bit.
That class drives three ranges.

1. Class below 0xE6 — the argument is tiny (below about 2^-12 in magnitude). The
   argument is returned unchanged, because the series would give back exactly it.
2. Class below 0xFF — the argument is already inside the principal interval
   (magnitude below 1.5). It is widened to 64 bits and fed straight to the
   series: a fourth-order polynomial in the square of the argument, evaluated by
   nested multiply-add from the highest coefficient down, then multiplied by the
   argument and its square and added back to the argument. The 64-bit result is
   narrowed to 32 bits and returned.
3. Class below 0x136 — the argument needs reduction (magnitude below 2^28). It
   is scaled by the reciprocal of the half period and rounded to the nearest
   whole number by adding or subtracting a half depending on sign and truncating.
   That whole number times the two halves of the split half-period constant is
   subtracted from the argument in two steps, which keeps the reduced argument
   accurate. The same series is then evaluated on the reduced argument. If the
   whole number is even the narrowed result is returned as is; if it is odd the
   narrowed result is negated, which is the half-period sign flip.
4. Anything larger — significance is entirely lost. A not-a-number argument
   (detected by comparing the argument with itself) yields the stored
   not-a-number constant; any other huge argument yields the stored range
   constant.

Shape notes needed for byte equality: the bit pattern must be held in its own
integer variable (folding the punned load into the class expression moves the
class into a different register); the widening of the argument to 64 bits belongs
to the outer range test, not to the inner one; the polynomial must be written as
plain nested multiply-add with the coefficient added on the right at every step;
and the sign flip must be written as an even-case early return with the negating
case last, so the negating block is laid out at the end.

## Status

Exact, after boundary correction from 120 to 448 bytes. Byte-identical in USA,
Japan, Europe and the large-cartridge revision.
