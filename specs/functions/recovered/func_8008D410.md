# func_8008D410

## Boundary

- USA VRAM range: 0x8008D410 .. 0x8008D414 inclusive (8 bytes, 2 instructions).
- USA ROM offset: 0x8E010.
- The whole body is a return plus its delay slot; the delay slot holds the only
  useful instruction, a word store of zero through the first argument.
- The assigned size 8 is correct. The eight bytes that follow are alignment
  padding for the next function, not part of this one.
- Checked the two instructions ahead of the entry: they are padding after the
  previous function's return, so the label is a genuine entry point.

## Callers and callees

- One direct call site in the USA build (inside func_8008807C, which clears an
  adjacent global immediately afterwards).
- Leaf: no callees.

## Globals and access widths

- None. The only memory touched is the caller-supplied address, written as one
  32-bit word.

## Regional addresses

| version  | VRAM       | ROM     |

| us       | 0x8008D410 | 0x8E010 |
| jp       | 0x8008E100 | 0x8ED00 |
| eu       | 0x80092960 | 0x93560 |
| lrg_rev1 | 0x8008D410 | 0x8E010 |

Every regional body was read independently and is the identical two-instruction
sequence.

## Recovered behavior

Takes one argument, the address of a list head cell, and empties it by writing
a null pointer into the first word. Nothing is returned and no other memory is
touched. This is the "reset this list to empty" primitive that pairs with the
insert and remove routines nearby.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
