# func_800938F0

## Boundary

VRAM 0x800938F0..0x800938FB (12 bytes, USA ROM 0x944F0). Three instructions:
an address setup, the return, and the value load sitting in the return's delay
slot. The word after the body is padding, and the previous function ends with
its own return three words earlier, so the boundary given in the assignment is
correct. No boundary correction.

## Callers

One direct call site in USA, at 0x8008ADB8 (inside the routine at 0x8008AD90).

## Callees

None. Leaf function.

## Globals and access widths

Reads one 32-bit word from the memory-mapped signal-processor status register
at physical 0x04040010, addressed through the uncached window at 0xA4040010.
The address is a literal in the source rather than a named object: a named
extern makes the compiler add the relocated low half as a separate instruction
and produces a four-instruction body, while the literal lets the low half fold
into the load displacement, which is what the original does.

## Regional addresses

- Japan: 0x800945E0, ROM 0x0951E0
- Europe: 0x80098E40, ROM 0x099A40
- lrg_rev1: 0x800938F0, ROM 0x944F0 (same as USA)

All three regional bodies were read independently and are word-for-word
identical to the USA body; nothing in this function relocates, so only the
function's own name changes between versions.

## Recovered behavior

Reads the current signal-processor status word and returns it to the caller
unchanged. It has no arguments, touches nothing else, and has no side effect
beyond the hardware read itself.

## Status

Exact in USA, Japan, Europe and lrg_rev1, at the accepted optimization-level-2
profile and also at the level-1 profile that the neighbouring functions in this
translation unit require.
