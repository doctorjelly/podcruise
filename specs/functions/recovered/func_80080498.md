# func_80080498

## Verified facts

- The USA function spans VRAM `0x80080498` through `0x800807DF`, ROM
  `0x81098`, for 840 bytes. Its final `jr ra` is at `0x800807D8`; the stack
  restore at `0x800807DC` is its delay slot. `func_800807E0` starts next.
- Direct USA callers are `func_800807E0` and `func_80080BEC`. The function
  calls `func_8003B02C` and `func_800153C0`, and uses `D_800ADC64`,
  `D_800ADC68`, and `D_80120BF0`.
- The Japan equivalent starts at `0x80081138` and the Europe equivalent at
  `0x80085978`. Both retain the 840-byte size, final return, and stack-restore
  delay slot while relocating references.

## Behavior

The function clears both result flags, saves the object's state word, builds a
transform frame from its subrecord, and measures the vector between its current
and reference positions. It repeatedly projects those positions and the frame
translation onto one frame axis. When the translation lies below the current
position, it either reports an interpolated fraction or advances the object's
parameter by `D_800ADC64`, rebuilds the frame, and tries again. This path sets
the first result flag.

If that flag remains clear and the object's stop field is clear, a second loop
backs the parameter up in `D_800ADC68` steps until the projected current
position no longer lies below the frame translation, setting the second result
flag when it crosses that condition. Unless stopped, it restores one step and
rebuilds the frame before returning.

## Status

Independently expressed C is byte-matching for canonical USA and the LRG USA
revision. IDO 5.3 `-O2`, MIPS II, with `-Wab,-r4300_mul` emits the exact
840-byte function in both builds. The redundant object test is behavior-neutral
after the preceding dereference and is retained solely to reproduce the
original compiler's register allocation. Japan and Europe are structural
evidence only; no byte match is claimed for them.
