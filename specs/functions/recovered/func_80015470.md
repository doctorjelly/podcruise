# func_80015470 — distance between two 3-component vectors

## Boundary

- USA VRAM range: `0x80015470` .. `0x800154CC` inclusive, 96 bytes
  (24 instructions).
- ROM offset `0x16070`.
- Ends with a return whose delay slot holds the square-root operation, so the
  returned value is produced in the delay slot.
- The preceding function ends with its own return plus delay slot immediately
  before this entry, and the direct call sites target `0x80015470`. Assigned
  boundary confirmed correct.

## Callers and callees

- 10 direct call sites.
- No callees. The square root is emitted inline as a single machine
  instruction, not as a library call, so the function is a leaf; it still
  allocates a 16-byte frame for one local.

## Globals and access widths

- None. Both operands are pointers to three consecutive 32-bit floats, each
  component read with a 32-bit float load.
- One 12-byte local (three floats) lives at the top of the 16-byte frame; each
  component is stored once and read back once with 32-bit float accesses. The
  local must be an array (or otherwise forced to memory): a plain three-float
  local struct is kept entirely in registers by this compiler and produces a
  frameless 64-byte body instead.

## Regional addresses

- Japan: `0x800155A0`, ROM `0x0161A0`, 96 bytes, body identical word for word.
- Europe: `0x80015900`, ROM `0x016500`, 96 bytes, body identical word for word.
- Both read independently from the regional disassembly before probing.

## Recovered behaviour

Takes two pointers to three-component float vectors and returns the straight
line distance between them. It first forms the difference vector by subtracting
the first vector's components from the second vector's components — note the
direction: second minus first, the opposite of the neighbouring squared-distance
routine — and keeps that difference in a small local. It then squares the three
stored components, sums them in x, y, z order, and returns the square root of
the sum.

## Status

Exact. USA, Japan and Europe all verified byte-identical at their canonical
addresses.
