# func_800735BC

## Boundary
VRAM 0x800735BC-0x80073640, size 132 bytes; the return jump's delay slot
restores the stack pointer. One caller, targeting the entry. Boundary as
assigned is correct.

## Callers / callees
1 caller. Calls func_80006E50 (handle, 32-bit flag word), func_80006E74
(handle, float) and func_80006EB4 (handle, float).

## Globals
None.

## Regional addresses
jp 0x800741EC (rom 0x74DEC), eu 0x80078A9C (rom 0x7969C), lrg_rev1 shares the
USA address. The callee addresses are unchanged in all versions, and all three
regional bodies are structurally identical to USA.

## Behavior
Takes a null-terminated array of handles and one floating-point value. For each
handle in turn, until the terminating null entry, it applies the flag word
0x10000000 to that handle, sets its first floating-point property to zero, and
sets its second floating-point property to the supplied value. An empty array
returns immediately. Nothing is returned.

## Status
exact (USA, jp, eu, lrg_rev1).
