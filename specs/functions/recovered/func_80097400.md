# func_80097400

## USA boundary and calls

ROM `0x98000`, VRAM `0x80097400`, 1356 bytes. The return at
`0x80097944` has the frame-release delay slot at `0x80097948`; the next
word is padding. All 339 assembly words were independently checked against
the canonical USA ROM.

The direct calls, in order, are `func_8008C2F0`, `func_80097F60`, and
`func_80096E90`. The current linked C has the same target sequence.

## Formatter argument correction

The final call is `(state, conversion, cursor, keep, exponent)`, not
`(state, conversion, cursor, exponent, keep)`.

- `0x80097854` forms the precision-derived significant-digit count in `$s3`;
  the following code clamps and rounds that count.
- `0x80097910` loads the state into `$s0`, `0x80097914` loads the conversion
  byte into `$s4`, and `0x80097918` copies the cursor into `$s1`.
- The call at `0x8009791C` loads the signed exponent from `sp+0x9A` into
  `$s2` in its delay slot.
- The helper stores `$s3` into incoming home slot `+0x0C` (argument four)
  and `$s2` into incoming home slot `+0x10` (argument five), at
  `0x80096EA0` and `0x80096E94`, respectively. All 346 helper assembly
  words were checked against ROM. See its recovered spec for the nonstandard
  whole-unit register convention.

Only the proven argument-order correction was retained. Before and after,
the isolated USA audit reports C/ROM 1336/1356 bytes, 332 differing comparable
words, five missing words, and first differing byte `0x3`; neither is exact.
The existing external helper declaration uses the ordinary ABI, unlike the
ROM's whole-unit convention. This is a unit-composition blocker, not grounds
for blind local register or declaration permutations. No matching-only
variants were retained, and the USA split must remain assembly.

## Final digit-chunk cursor correction

The digit cursor advances by eight after every generated chunk, including the
last one. At `0x800977B0`, `blez $s4` exits when no requested digits remain;
its ordinary delay slot at `0x800977B4` is `addiu $s5,$s5,8`, executed on both
edges. The previous C placed that advance after the early break, leaving the
cursor at the beginning of the final chunk and understating the generated
length by eight. The advance now precedes the break. This is a behavior
correction; the standalone comparison remains 1336/1356 bytes and 332 differing
comparable words, and the function remains assembly-backed.

A temporary combined-unit experiment with the real static `func_80096E90`
helper preserved all 1384 exact helper bytes but emitted a 1340-byte driver at
`0x800973F8`, eight bytes before its canonical address. Unit composition alone
does not recover the driver or the intervening alignment. No combined source
or configuration from that experiment was retained.

`tests/test_float_format_cursor.c` exercises the final-chunk path through the
production C with captured formatter arguments. The old source fails the
one-significant-digit assertion; the corrected source yields digit `1`, one
significant digit, and exponent zero. Its native-endian classifier fixture is
explicitly limited to this cursor regression. The decimal scaling constants
10000 and 100000000 were verified against canonical USA ROM words.
