# func_80007A44 — reset the per-slot counter in the 8-entry slot table

## Boundary

- USA VRAM range: `0x80007A44` .. `0x80007A7F` (inclusive), 60 bytes.
- ROM offset `0x8644`, translation unit `main_7BE4.s`.
- The body terminates with a return whose delay slot is empty (a `nop`).
- Boundary as assigned was already correct: no branch inside the body targets an
  address at or beyond `0x80007A80`, and the preceding function ends with its own
  return at `0x80007A40`.

## Callers

Nine direct call sites across the main text, all with no arguments set up and no
use of the return value — e.g. from the routines at `0x80039B70`, `0x8003A400`
and `0x80053500`. It is therefore a `void (void)` routine.

## Callees

None (leaf).

## Globals and access widths

| Symbol | Width | Use |
| --- | --- | --- |
| `D_8009A2B8` | 32-bit word | enable flag; read once, tested against zero |
| `D_800D2038` | array base | 8 records of 0x20 bytes, 0x100 bytes total |
| `D_800D2138` | — | not a distinct datum; this is `D_800D2038 + 0x100`, the one-past-the-end address the loop compares against |

Within each 0x20-byte record only the 32-bit field at offset `0x18` is touched.
That field's type is corroborated by the neighbouring routines at `0x800078BC`
and `0x800088F0`, which load the same offset as a signed word and convert it to
floating point; the record stride of `0x20` is corroborated by the rotated load
at `0x28` in the `0x800088F0` loop.

## Regional addresses

| Version | VRAM | ROM | Size |
| --- | --- | --- | --- |
| USA | `0x80007A44` | `0x8644` | 60 |
| Japan | `0x80007A44` | `0x8644` | 60 |
| Europe | `0x80007A44` | `0x8644` | 60 |
| lrg_rev1 | `0x80007A44` | `0x8644` | 60 |

The code is identical in all four; only the data symbols relocate.

- Japan: `D_8009A2B8` -> `D_8009AFA8`, `D_800D2038` -> `D_800D5288`.
- Europe: `D_8009A2B8` -> `D_8009F808`, `D_800D2038` -> `D_800DACD8`.
- lrg_rev1: unchanged from USA.

In both Japan and Europe the loop limit is again exactly base + 0x100, so the
table size is the same everywhere.

## Recovered behaviour

If the global enable flag is zero the routine does nothing at all and returns
immediately. Otherwise it walks all eight records of the slot table in order and
clears the signed 32-bit counter that lives at offset 0x18 of each record to
zero. No other field is touched, nothing is read back, and there is no return
value.

The original compiler unrolled the eight-iteration loop four times, so the
emitted code advances a cursor by four records at a time and issues four stores
per pass; this is a code-generation artefact of the plain counted loop, not a
property of the source.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
