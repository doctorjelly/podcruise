# func_80091FD0

## Boundary
VRAM 0x80091FD0-0x80092048 (120 bytes, ROM 0x92BD0). Ends with a return whose
delay slot moves the result into the return register. 16 direct callers.

## Callers / callees
16 callers. Calls func_800928F0.

## Globals and access widths
None. Uses a 32-byte stack buffer written a byte at a time, and reads two words
at offsets 0x4 and 0x8 of the object argument, writing one byte at 0x65.

## Regional addresses
- jp 0x80092CC0 (ROM 0x938C0), callee relocated to func_800935E0
- eu 0x80097520 (ROM 0x98120), callee relocated to func_80097E40
- lrg_rev1 0x80091FD0, identical to USA

## Behavior
Fills a 32-byte scratch buffer with copies of the byte-valued second argument,
then hands the object's two stored words, a fixed count of 0x400, the buffer
and a zero flag to the worker routine. If the worker reports success (a zero
result) the same byte value is recorded in the object at offset 0x65. The
worker's result is returned unchanged.

## Status
exact in USA, Japan, Europe and lrg_rev1.
