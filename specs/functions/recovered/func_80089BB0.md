# func_80089BB0

## Boundary
USA VRAM 0x80089BB0-0x80089C33 (132 bytes), ROM 0x8A7B0. Ends with a return
whose delay slot is empty. Four direct callers target the entry; no branch from
the preceding function enters the range. Boundary as assigned is correct.

## Callees
func_800905F0, func_80089CC0, func_800907D0, func_80087E80, func_80090634.

## Globals
- D_80149CB0: one-byte flag, read unsigned and written as a byte.
- D_80149C70: an object whose address is passed by reference.

## Regional addresses
- Japan: 0x8008A8A0 (ROM 0x08B4A0), with D_80149CB0 -> D_8014CF20,
  D_80149C70 -> D_8014CEE0 and the five callees relocated.
- Europe: 0x8008F100 (ROM 0x08FD00), with the corresponding relocations.
- lrg_rev1: identical to USA addresses.

## Behavior
The routine takes a single handle argument. It first hands that handle to a
preparation routine. If the one-byte flag has not yet been set to one, it runs
a one-time initialisation routine, registers the shared object under selector
one, and then performs a setup call on the handle with a zero middle argument
and a trailing one.

Whichever path was taken, it then registers the same shared object under
selector zero and keeps that call's result. It marks the one-byte flag as set,
runs a finalisation routine, and returns the retained result.

## Status
Exact in USA, Japan, Europe and lrg_rev1.
