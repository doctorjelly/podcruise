# func_80064A48

## Boundary
VRAM 0x80064A48-0x80064A88 (64 bytes, 16 instructions). Ends with the return
instruction followed by an empty delay slot. Boundary confirmed: the preceding
function ends before the entry, and all four direct call sites target 0x80064A48.
Not corrected.

## Callers
Four direct call sites.

## Callees
func_80017C18, func_80015288.

## Globals
None referenced directly.

## Regional addresses
- jp 0x800655B8 (rom 0x0661B8), callees func_80017D48 / func_800153B8
- eu 0x80069F28 (rom 0x06AB28), callees func_800180A8 / func_80015718
- lrg_rev1 0x80064A48 (rom 0x65648), same symbols as USA

## Recovered behavior
Takes three arguments: an opaque context pointer, a pointer to an owner record,
and an index. The owner record holds, 0x30 bytes into itself, a pointer to an
array of pointers. The function selects the element of that array at the given
index and hands it to func_80017C18 together with the address of a 48-byte
scratch area reserved in the caller's own frame. It then calls func_80015288
with the first argument and the address of a separate 20-byte scratch area.
Neither scratch area is read afterwards, so the two callees are the sole
consumers; the function returns nothing.

The declaration order of the two scratch areas is load-bearing: the smaller
area must be declared first so that IDO places it at the top of the frame.

## Status
Exact on USA, Japan, Europe and lrg_rev1.
