# func_8003140C

## Verified facts

- USA VRAM `0x8003140C` through `0x800314B3`, ROM `0x3200C`, 168 bytes.
  The return at `0x800314AC` restores the 48-byte frame in its delay slot at
  `0x800314B0`. The three words before the next entry at `0x800314C0` are
  alignment padding and are not part of this function.
- The two direct callers are `func_80039478` and `func_80039B70`. Both pass a
  destination, a signed word value, and an unsigned byte count; neither uses
  the returned pointer.
- The only callees are `func_800313D8`, which receives each destination/value/
  length tranche, and `func_80008F28`, called after every nonempty tranche.
- The function references no globals directly.
- Japan has the equivalent body at `0x80031E6C` / ROM `0x32A6C`, and Europe at
  `0x800349CC` / ROM `0x355CC`. Both have the same 168-byte instruction shape
  and delay slots; only the relocated first helper target differs. LRG uses the
  USA address and body.

## Recovered behavior

Process the requested range in pieces no larger than 65,536 bytes. For every
full piece, submit the current destination, signed value, and piece length to
the first helper, subtract that length, advance the destination, and invoke the
second helper. Submit a final shorter piece in the same way when any bytes
remain. Return the original destination pointer, including for a zero length.

The unsigned length parameter itself is the decreasing counter. The fixed
piece size is held as a signed local, a source distinction required by the
canonical unsigned comparisons and register lifetimes.

## Status

Byte-matching C. IDO 5.3 with the unit's accepted `-O2` profile reproduces all
168 USA bytes exactly. The USA and LRG hybrid substitutions remain subject to
their independent whole-ROM verification.
