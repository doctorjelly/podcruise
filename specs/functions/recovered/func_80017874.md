## Recovered behavior

The routine writes the identity transform into a 4x4 single-precision matrix
laid out as sixteen consecutive floats in row-major order. The four diagonal
entries are set to one and the twelve remaining entries, including the whole
translation row, are set to zero. It takes only the destination address, reads
nothing back, and returns nothing.

## Argument evidence

The routine takes exactly one argument, the destination address; no other
argument register is read. Two constants are materialised once each, zero and
one, and reused for all sixteen stores.

  store sequence in the same order.
