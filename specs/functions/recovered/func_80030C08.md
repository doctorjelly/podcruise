# func_80030C08

## Boundary
VRAM 0x80030C08-0x80030C98, ROM 0x31808, 144 bytes. Ends with the return
instruction and an empty delay slot. One direct caller.

## Callers / callees
1 caller. Calls func_8002FAFC (queried first) and func_8002FAC4 (last).

## Globals
- D_80000318, read as a 32-bit word and compared without sign.
- D_800DB894, written twice and read once, 32-bit.
- D_800DB898, written once, 32-bit.

## Regional addresses
jp func_80031668 (ROM 0x32268); the two writable words move to 0x800DEB04 and
0x800DEB08 and the two calls become func_8003055C / func_80030524.
eu func_800341C8 (ROM 0x34DC8); words 0x800E4534 / 0x800E4538, calls
func_800330BC / func_80033084. lrg_rev1 shares the USA addresses.
D_80000318 keeps its address in every version.

## Recovered behavior
The routine asks a helper for a current allocation cursor and records it. It
then rounds that record up to the next multiple of 64 in place, so the stored
cursor becomes 64-byte aligned while the original unrounded value is kept for
the final step.

A window size is then chosen from a machine-configuration word: when that word
is below 0x800000 the size is 0x4000, otherwise 0x10000. The routine writes the
aligned cursor plus that size into the second word. The same choice is made a
second time (the source repeats the selection rather than caching it), and the
routine finally hands the helper the *unrounded* cursor plus the chosen size
plus 64.

## Status
exact (USA, Japan, Europe, lrg_rev1).
