# func_8007B41C

## Boundary

- USA VRAM range: 0x8007B41C .. 0x8007B427 inclusive (0xC = 12 bytes,
  3 instructions).
- USA ROM offset: 0x7C01C.
- Ends with a return whose delay slot performs the single store, so the store
  is part of the function body.
- Assigned size 12 was correct; no boundary correction.

## Callers and callees

- One direct call site in the USA build (inside the routine at 0x8005EBxx),
  which loads a pointer to a static record into the first argument register
  immediately before the call.
- No callees (leaf function).

## Globals and access widths

- `D_8011C8E0` — one 32-bit word, written. The only value ever stored is the
  incoming pointer argument, so it is modelled as a pointer-sized variable.

## Regional addresses

The body is instruction-for-instruction identical in every version; only the
global address moves.

| version  | VRAM       | ROM     | global      |
|----------|------------|---------|-------------|
| us       | 0x8007B41C | 0x7C01C | D_8011C8E0  |
| jp       | 0x8007C0BC | 0x7CCBC | D_8011FB50  |
| eu       | 0x800808FC | 0x814FC | D_80125580  |
| lrg_rev1 | 0x8007B41C | 0x7C01C | D_8011C8E0  |

## Recovered behavior

Publishes the caller's object as the module's current one: the single pointer
argument is stored into the module-scope slot and nothing else happens. There
is no validation, no return value and no side effect beyond that one store.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
