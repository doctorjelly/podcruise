# func_8008B14C

## Boundary
VRAM 0x8008B14C-0x8008B18C (64 bytes, 16 instructions). Ends with the return
instruction and an empty delay slot. Two direct call sites target the entry; the
only internal label is the head of the function's own loop. Not corrected.

## Callers
Two direct call sites.

## Callees
func_80093A60 (queried repeatedly), func_80093980.

## Globals
None.

## Regional addresses
- jp 0x8008BE3C (rom 0x08CA3C), callees func_80094750 / func_80094670
- eu 0x8009069C (rom 0x09129C), callees func_80098FB0 / func_80098ED0
- lrg_rev1 0x8008B14C, same symbols as USA

## Recovered behavior
Accepts one argument which it stores into its incoming home slot and never
reads; the argument is nonetheless part of the function's real arity. It polls
func_80093A60 in a busy loop, spinning for as long as that query keeps reporting
a non-zero result, so the loop is a drain-until-idle wait. Once the query
reports zero the function issues a single request to func_80093980 with the
fixed selector 0x125 and returns nothing.

## Status
Exact on USA, Japan, Europe and lrg_rev1.
