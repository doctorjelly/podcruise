# `func_80020030`

## Boundary and interface

- Canonical USA interval: VRAM `[0x80020030, 0x80021294)`, ROM
  `[0x20C30, 0x21E94)`, 4,708 bytes.
- The final return is `jr $ra` at `0x8002128C`. Its executed delay slot at
  `0x80021290` restores the `0x1B8`-byte stack frame.
- `func_8004A880` calls the routine from two menu-state paths and
  `func_8004AF60` calls it during an enabled update. All three sites pass one
  state-object pointer and ignore the result.
- The unique structural equivalents are JP `func_800201BC` and EU
  `func_800213E8`. They support the boundary and broad organization; USA is
  the source target.

## Behavioral specification

On its first invocation, set the object's setup byte and return. Later calls
do work only for object modes 3 and 8. For each active count-indexed resource,
construct a placement transform from the saved effect position and an
object-selected height. If a previously generated effect exists, use its mode
to move and clamp a shared scale; apply the resulting pair of scales while
publishing the resource transform.

Update four optional scene nodes. Disable each node, place it at a fixed
mode-dependent offset, apply a half-scale transform, publish it, and re-enable
it. When the scene gate is active and the object's submode is not two, also
emit one count-indexed effect between stored scene positions.

Generate four distinct random values in the range zero through three. Use
them as per-entry modes and select fallback resources when either preferred
resource is absent. For every active entry:

- mode 0 repeatedly samples a point within the scene bounds, up to 20 times,
  until the projected depth clears the lower limit; it records the selected
  side and emits a mode-14 effect;
- mode 1 samples a central resource and moves its projected x coordinate
  outward by 30;
- modes 2 and 3 sample the left and right resources and move projected x by
  minus or plus 30 respectively;
- modes 1 through 3 lower z by 20, mirror x into a second vector, and emit a
  mode-8 effect.

After that loop, emit two more randomly positioned effects. On every active
update, project each generated entry into its object position, apply the same
mode-specific x/z correction, and publish the position to its scene node.

Finally run the shared scene updater. An active completion flag moves the
object into exit state one. Decrease and clamp the transition timer while the
object is not exiting, or increase and upper-clamp it while exiting; mode 8
then dispatches to `func_80021294` or `func_80021F84` respectively.
