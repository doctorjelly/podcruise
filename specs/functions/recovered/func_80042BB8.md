# `func_80042BB8` USA recovery notes

The routine updates a fade value and, for an enabled part with the required
flag, constructs two matrices and submits the resulting effect. Its USA C
function is 820 bytes at `0x80042BB8`; the current linked text has 73 differing
words, down from 75 in the previous source. The frame remains `0xD0`, and the
matrix homes remain `sp+0x50` and `sp+0x90`.

At `0x80042C94–0x80042C9C`, the ROM loads `part->unk060`, shifts it left four
bits with `SLL`, then uses `BGEZL` to skip the effect when the result is
nonnegative. This tests original bit 27: `((u32)part->unk060 &
0x08000000u) != 0` expresses the same gate without signed-left-shift
undefined behavior.

The first vector helper receives the address of `actor->unk050`. The ROM stores
that address at `sp+0x28` at `0x80042CC8` and reloads it at `0x80042D24` for the
later copy helper. A block-scoped `actor050` pointer preserves that embedded
array address across both calls without snapshotting its contents. The
resulting linked words match those two ROM accesses; the total mismatch count
falls by two. Other differences remain, including a floating-register
mismatch at `0x80042C18`. This is not an exact function match.

`tests/test_actor_matrix_flag.c` exercises the bit-27 gate under the shift
sanitizer and checks that a mutation through the first helper is visible when
the later helper receives the same vector address. The original signed shift
fails UBSan for `0x08000000`; the unsigned mask form passes the fixed cases.
