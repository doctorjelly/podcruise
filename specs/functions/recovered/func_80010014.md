# func_80010014 — store one pair of values into the ten-slot table

## Boundary

- USA VRAM range `0x80010014` .. `0x8001003F` inclusive; size 44 bytes
  (11 instructions).
- The body ends with the standard return instruction and a no-operation delay
  slot. The range check branches forward to that return.
- `func_8000FFF8` returns before this label and the single direct call site
  targets `0x80010014`, so the assigned boundary is correct.

## Callers

One direct call site in the USA build, at `0x8005DB78`. Three arguments: a
signed slot index and two word-sized values. No return value.

## Callees

None; leaf function, no stack frame.

## Globals and access widths

| symbol | role | width |
| --- | --- | --- |
| `D_800D5F80` | ten-entry table of signed words, first parallel column | 32-bit store |
| `D_800D5FA8` | ten-entry table of signed words, second parallel column | 32-bit store |

These are the two tables `func_8000FEF0` seeds with negative one.

## Regional addresses

| version | entry | ROM |

Regional data symbols (USA / Japan / Europe): `D_800D5F80` / `D_800D91D0` /
`D_800DEC20`; `D_800D5FA8` / `D_800D91F8` / `D_800DEC48`. All regional bodies
were read directly and match the USA shape exactly apart from those addresses.

## Recovered behaviour

The slot index is compared as a signed value against ten. If it is ten or
greater the routine does nothing. Otherwise the two supplied values are written
into that slot of the two parallel word tables, the first argument into the
first table and the second into the second. As with the forty-slot registry, no
lower bound check is performed, so a negative index would write before the
table.

The single scaled index is computed once and reused for both stores, so the two
tables are always addressed with the same slot.

## Status

Exact. Byte-identical in USA, Japan, Europe and `lrg_rev1`.
