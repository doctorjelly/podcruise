## Recovered behaviour
The function retargets an animation object at a new track position while
remembering where it was. It first marks the object as "position changed" by
setting one bit in the object's flag word. It records the requested blend value
in the first of two blending fields and clears the second. It then snapshots the
outgoing state: the previously resolved key index is copied into the saved-index
field, and the previous playback position is copied, truncated toward zero, into
the saved-position field. Only then is the new playback position stored. Finally
it asks the key-lookup helper for the key index that matches the new position and
stores that index back into the object.
