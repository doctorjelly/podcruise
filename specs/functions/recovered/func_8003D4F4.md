# func_8003D4F4

## Boundary and interface

The canonical USA body spans ROM `0x3E0F4` / VRAM `0x8003D4F4` through the
`addiu $sp,$sp,0x188` return delay slot at `0x8003E098`, for `0xBA8` (2,984)
bytes. The scanner's 2,988-byte interval includes the alignment word at
`0x8003E09C`; the next function starts at `0x8003E0A0`.

Recovered callers `func_80009FA0` and `func_8000A53C` establish thirteen
arguments: an optional resource address, two integer positions, three floats,
two more integer coordinates, a render-option word, and four color components.
The unique structural counterparts are Japan `0x8003DE74` and Europe
`0x80041E34`. They support relocation, not a regional byte-match claim.

The routine calls the recovered angle-to-sine/cosine helper `func_80014CC0`
and the still-unrecovered drawing worker `func_8003BAB0`. It reads or updates
the command cursor `D_801217B0`, cached option word `D_800A4960`, default
resource `D_800A4908`, command payload `D_800A48D4`, and three float constants
at `D_800AAB14` through `D_800AAB1C`.

## Behavior

Return without output when option bit `0x8` is set or either extent is not
greater than the shared lower-bound constant. Record bit `0x20` when both
extents are exactly one. Select the supplied resource or the built-in default;
its verified fields include width and height, two format bytes, a data pointer,
a strip count and fallback span, and a pointer to eight-byte strip records.

Option bit `0x800000` derives a sine/cosine pair; otherwise use `(0, 1)`.
Option bit `0x20000` centers the geometry using half-scaled resource dimensions.
Emit a pipe synchronization command, compare the option word with the cached
word, and conditionally emit render-mode, alpha-compare, depth-source and
texture-state commands. Then emit the supplied RGBA color,
choose one of three combiner recipes, and load a palette when the resource type
is two. Update the cached option word after changing state.

For a nonempty strip table, derive horizontal and vertical texture increments
from the extents unless the relevant option fields request the fixed `0x400`
step. Walk positive-length strip records while maintaining the two clipped
source intervals. For each drawable strip with a nonnull data pointer, compute
scaled destination bounds and source offsets, apply the direction, clipping,
rotation and filtering option bits, and pass those values plus the local
command cursor to `func_8003BAB0`. Finish any type-two resource with the
corresponding texture-state command, then publish the advanced command cursor.

## Flag and rotation corrections

- `8003D668` loads the cached flags into `$v1`, which remains unchanged through
  the mode selection. With neither requested mode bit set, `8003D6E0` tests
  old bit `2`, and `8003D6F0` tests old bit `1`. The mode-command predicate is
  `(oldFlags & 2) || !(oldFlags & 1)`, not `oldFlags & 3`. In particular,
  old mode `1` suppresses the command, while old mode `0` emits it when some
  other requested flag differs. This preserves the original unusual behavior.
- `8003D5A0` shifts the flags left by 8 before the signed branch at
  `8003D5B4`, selecting bit `0x800000`; the former C mask was `0x800`.
- `8003D5E8` shifts left by 14 before the signed branch at `8003D5EC`,
  selecting centering bit `0x20000`; the former C mask was `0x2000`.
  Horizontal reversal still uses the separate `0x2000` test at `8003DC00`.
- Without rotation, `8003D5E0` stores the still-live `1.0f` at `sp+0x16C`,
  and `8003D5E4` stores zero at `sp+0x170`. Those slots become outgoing
  arguments 16 and 15 respectively at `8003DFD4`/`8003DFDC`. The helper's
  first output is sine and its second is cosine, so the caller now uses those
  names consistently and forwards `(sine, cosine) = (0, 1)` by default.

`tests/test_texture_coordinates.c` checks all 16 low-mode transitions, five
rotation/centering flag cases, the forwarded trigonometric pair, and the
existing three coordinate cases. The corrected source passes. Independently
restoring each of these four defects fails its corresponding assertion; the
original source also fails. No additional mask discrepancy was found in the
remaining flag tests through fixed-axis and reversal selection.

## Status

Behavior recovered from the canonical USA body and independently expressed in
C. After these corrections, IDO 5.3 `-O2 -mips2` emits 2,644 bytes for the
2,984-byte target at the canonical address: 655 differing comparable words
and 85 missing words, first differing at byte `0x3`. The preceding source
emitted 2,664 bytes, with 664 differing and 80 missing words. This is not
byte-matching and is not eligible for hybrid-build substitution.
