# func_8003D4F4

## Boundary and interface

The canonical USA body spans ROM `0x3E0F4` / VRAM `0x8003D4F4` through the
`addiu $sp,$sp,0x188` return delay slot at `0x8003E098`, for `0xBA8` (2,984)
bytes. The scanner's 2,988-byte interval includes the alignment word at
`0x8003E09C`; the next function starts at `0x8003E0A0`.

Recovered callers `func_80009FA0` and `func_8000A53C` establish thirteen
arguments: an optional resource address, two integer positions, three floats,
two more integer coordinates, a render-option word, and four color components.
The unique structural counterparts are Japan `0x8003DE74` and Europe
`0x80041E34`. They support relocation, not a regional byte-match claim.

The routine calls the recovered angle-to-sine/cosine helper `func_80014CC0`
and the still-unrecovered drawing worker `func_8003BAB0`. It reads or updates
the command cursor `D_801217B0`, cached option word `D_800A4960`, default
resource `D_800A4908`, command payload `D_800A48D4`, and three float constants
at `D_800AAB14` through `D_800AAB1C`.

## Behavior

Return without output when option bit `0x8` is set or either extent is not
greater than the shared lower-bound constant. Record bit `0x20` when both
extents are exactly one. Select the supplied resource or the built-in default;
its verified fields include width and height, two format bytes, a data pointer,
a strip count and fallback span, and a pointer to eight-byte strip records.

Optionally derive a sine/cosine pair and half-scaled resource dimensions. Emit
a pipe synchronization command, compare the option word with the cached word,
and emit only the render-mode, alpha-compare, depth-source and texture-state
changes needed to reach the requested state. Then emit the supplied RGBA color,
choose one of three combiner recipes, and load a palette when the resource type
is two. Update the cached option word after changing state.

For a nonempty strip table, derive horizontal and vertical texture increments
from the extents unless the relevant option fields request the fixed `0x400`
step. Walk positive-length strip records while maintaining the two clipped
source intervals. For each drawable strip with a nonnull data pointer, compute
scaled destination bounds and source offsets, apply the direction, clipping,
rotation and filtering option bits, and pass those values plus the local
command cursor to `func_8003BAB0`. Finish any type-two resource with the
corresponding texture-state command, then publish the advanced command cursor.
