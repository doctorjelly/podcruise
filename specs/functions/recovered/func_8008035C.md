# func_8008035C

## Boundary

- USA VRAM 0x8008035C..0x80080408, ROM 0x80F5C, size 172 bytes (0xAC).
- Ends with the return instruction plus its delay slot, which pops the 0x18-byte
  frame. Twenty-one direct call sites target 0x8008035C, and the preceding
  function ends before it, so the assigned boundary is correct.

## Callers

Twenty-one direct call sites in USA. Callers hand over a pointer that they
build as `object + 0xAC` and consume the result as a single-precision float
(stored with a float store, compared against float constants).

## Callees

- func_8003A568(pointer, 0) - returns a small non-negative table index.

## Globals and access widths

- D_80120408: table of pairs of 32-bit floats, 8 bytes per entry, indexed by
  the value returned from func_8003A568. Both members are read.
- D_800A6704: signed 32-bit word, read once, only its sign is used.
- D_800ADC5C: 32-bit float, read only on one path.

## Recovered behavior

The function evaluates a linear ramp for one object and clamps the result.

1. Ask the helper which row of the pair table applies to this object, passing
   the object pointer and a selector of zero.
2. Read the two floats of that row: the first is a constant offset, the second
   a slope. Multiply the slope by the object's own float stored eight bytes
   into the record it was given, and add the offset.
3. Clamp the sum. When the signed global mode word is zero or positive the
   ramp saturates at one: anything strictly above one is reported as one,
   everything else is reported unchanged. When the mode word is negative the
   saturation value is taken from a float global instead, and the threshold is
   inclusive: a sum of exactly one already yields the global.
4. The clamped value is returned as a float.

## Compiler notes

The upper clamp on the non-negative path is written as a plain `1.0` (a double
constant narrowed to the float return type). Writing it as `1.0f` makes IDO
share the constant with the one already materialised for the comparison and
loses the extra materialisation the original performs, four bytes short of the
real body.

## Status

Exact in USA, Japan, Europe and lrg_rev1 under the accepted ido53_o2 profile;
no per-unit compiler flags needed.
