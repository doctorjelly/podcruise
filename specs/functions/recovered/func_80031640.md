# func_80031640

## Boundary

- USA VRAM range 0x80031640 - 0x800316A7 inclusive (0x68 = 104 bytes).
- Terminates with the standard return instruction whose delay slot releases the
  0x20-byte stack frame.
- Six call sites; the external ones (0x8002F960, 0x80031BD4 and others) all
  target 0x80031640, the rest are the routine calling itself. Entry confirmed.

## Callers

Called from the module teardown sequence near 0x8002F948 and from 0x80031BD4;
otherwise self-recursive.

## Callees

Itself only.

## Globals

- `D_800DB8A8` - base of a table whose records are 28 bytes apart, four bytes
  ahead of the table used by `func_800315D8`; the two are almost certainly the
  same record array seen through different fields. The field written here is a
  16-bit halfword at the start of each record, so the table is modelled as
  `s16 D_800DB8A8[][14]` and only column zero is touched.

## Parameters

One signed integer selector, with -1 as the "all" sentinel. Nothing is returned.

## Recovered behaviour

The halfword counterpart of `func_800315D8`. When handed the sentinel -1 it
recurses over selectors 0 through 3, clearing every record; otherwise it zeroes
the 16-bit field at the head of the addressed record.

Source-shape notes are the same as for `func_800315D8`: an inequality loop
bound, and a two-dimensional subscript so that the 28-byte stride is folded into
a single address computation.

## Status

Exact in USA, and byte-identical in Japan, Europe and lrg_rev1 from the same
source.
