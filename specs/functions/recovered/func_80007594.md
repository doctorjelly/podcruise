# func_80007594

## Verified facts

- The USA body spans VRAM `0x80007594` through `0x8000770F`, ROM `0x8194`,
  380 bytes. `jr ra` is at `0x80007708`; its delay slot restores the 0x48-byte
  stack frame.
- `func_80007710` returns this routine as a callback, and `func_80007218`
  installs that callback in the subsystem boot record. The third argument is
  saved by the prologue but not read.
- The active and free lists share the anchor at `D_800AFAC0`. Active entries
  have next/previous links, a start address at offset 8, the current
  `D_800AFE88` stamp at offset 12, and a 1 KiB backing-buffer address at offset
  16.
- A new request uses the 24-byte record at
  `D_800AFE98 + D_8009A2C8 * 24`, calls `func_80087D70` with the aligned source
  address, backing buffer, length `0x400`, and `D_800B0498`, then normalizes the
  buffer through `func_80088360`.
- Japan and Europe contain structurally identical equivalents at
  `0x80007594`.

## Behavior

Find the sorted active entry whose 1 KiB window contains the requested address
range. Refresh its stamp and return the normalized backing-buffer address plus
the within-window offset. If no window fits, take a descriptor from the free
list, insert it at the sorted position, align the requested start down to an
even address, queue a 1 KiB transfer into its backing buffer, and return that
normalized buffer address with the removed low bit restored.

## Status

Behavior recovered from the USA binary and independently expressed in C; not
byte-matching. IDO 5.3 `-O2` emits 396 bytes for the 380-byte target and first
differs at byte `0x5`.
