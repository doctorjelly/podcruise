# func_80013DC0

## Boundary and evidence

USA is VRAM `0x80013DC0`, ROM `0x0149C0`, 1,068 bytes through
`0x800141EC`. The return at `0x800141E4` restores the 72-byte frame in its
delay slot. Direct callers are `func_8003E2B0`, `func_8003E870`, and
`func_8003E920`. Europe relocates the routine to `0x80014250` / ROM
`0x014E50`; the Japan mapping is not yet unique enough to claim.

## Behavior

Initialize text-rendering bounds and scan the input for a control sequence.
Consume an optional leading font selector, save the current draw position,
configure the selected page texture, render each page entry, and draw the
resulting bounds when they are nonempty. Finally restore the global draw
position from its configured defaults.
