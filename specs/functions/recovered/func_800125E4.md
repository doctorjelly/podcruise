## Verified facts

The USA body spans VRAM `0x800125E4` through the return delay slot at
`0x800129B4`, ROM `0x131E4`, 980 bytes. Its canonical assembly is
`analysis/generated/us/asm/main_12B38.s:471–722`.

The signed comparison at `0x800125F8` returns when `index >= count`.
Otherwise modes 1 and 3 emit seven texture commands, mode 2 emits a different
seven-command sequence, mode 0 emits thirteen commands for four tiles, and
other modes emit nothing. Commands use the indexed word at list offset 8;
the global cursor `D_801217B0` advances by 56, 104, or zero bytes accordingly.

## Bounded execution evidence

The private reproducer `/tmp/us20-diff125e4/pilot.py` compares raw canonical
ROM code with the freshly linked 948-byte ELF function symbol. It reuses the
reviewed `3B860` runner and adds only the evidenced `ADDU` and `BNEL`
instructions. Eleven prior microtests and six extension tests pass; a second
worker independently reviewed the extension and fixture state checks.

There were no discrepancies in 1,792 cases covering modes 0/1/2/3 and invalid
signed values, signed count/index boundaries including count zero, and four
texture bit patterns. The cases comprise 64 defined index-zero accesses,
1,424 defined paths without array access, 128 accesses beyond the declared
one-element trailing array, and 176 negative-index accesses. The latter two
groups compare machine behavior only; they do not establish defined behavior
for those accesses in the current C declaration. Nine additional packet
fixtures derived independently from the ROM also pass.

All five conditional branches exercised both outcomes and both unconditional
branches executed. The longest path used 124 instructions against the
512-instruction limit. Checks cover command bytes, cursor, buffer guards,
remaining mapped memory, and preserved ABI registers including SP and RA.
The ROM's eight-byte local frame and incoming argument homes are excluded
from final memory equality because they are callee scratch storage. The
function is void; scratch registers including `$v0` are not return values.

This pilot uses aligned, separate list, command, global-cursor, and stack
regions. It does not cover arbitrary aliases or prove exhaustive equivalence.
Unsupported instructions and invalid memory accesses fail closed. Results
and branch coverage are in `/tmp/us20-diff125e4/result.json`; the independent
fixtures are `/tmp/us20-125e4-parent-cases.json`. No source change followed.
