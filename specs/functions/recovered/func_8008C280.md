# func_8008C280

## Boundary
VRAM 0x8008C280-0x8008C2EF (112 bytes). Ends with `jr $ra` and an empty delay
slot. 1 caller; boundary confirmed.

## Callers / callees
1 caller. Calls func_800905F0 (acquire), func_800950F4 (query) and
func_80090634 (release).

## Globals
None.

## Behavior
The routine takes one handle. It acquires the subsystem, then asks the query
helper about the handle, giving it a small local buffer to fill. A non-zero
query result means failure and the answer is zero. On success the routine looks
at the top two bits of the first halfword the helper wrote: the pattern 10
yields 1, the pattern 11 yields 2, and anything else yields 0. The subsystem is
then released and the classification is returned. The classification is
computed before the release call and reloaded afterwards, so the release always
happens exactly once on every path.

## Status
behavior. The compiled body is the correct length (112 bytes) and every
instruction matches except two, which differ only in which scratch registers
hold the loaded halfword and its masked value; the original uses two distinct
temporaries where the rebuilt code reuses the result register. Ten source
shapes were tried (if-chain, nested conditional expression, switch, extra
temporaries, local sized as scalar / array / struct, both branch polarities);
the switch form over a four-halfword local buffer declared after the result
variable is the closest and is what is kept.
