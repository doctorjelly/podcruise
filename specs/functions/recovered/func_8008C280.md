# func_8008C280

## Verified facts

- The canonical USA body spans VRAM `0x8008C280` through the `jr ra` delay
  slot at `0x8008C2EC`, ROM `0x8CE80`, for 112 bytes. `func_8008C2F0`
  starts next; the return delay slot is an explicit `nop`.
- Its only direct USA caller is `func_8003964C`, at `0x80039660`. That caller
  passes `D_800D9C28` and distinguishes return values one and two from zero.
- It calls `func_800905F0`, `func_800950F4`, and `func_80090634`, in that
  order. The query helper receives the original argument and a local buffer.
- The function reads no globals and writes only its stack-local buffer. The
  structurally equivalent Japan and Europe entries are `0x8008CF70` and
  `0x800917D0`; both are also 112 bytes and differ only in relocated call and
  branch targets.

## Behavior

The routine brackets one handle query with subsystem acquire and release
calls. If the query fails, it returns zero. Otherwise it classifies the top
two bits of the first returned halfword: binary `10` becomes one, binary `11`
becomes two, and every other pattern becomes zero. It saves that result before
the release call and returns it afterwards, so release occurs exactly once on
every path.

## Recovery notes

Keeping the scalar result before the four-halfword buffer reproduces the
original stack offsets. Explicitly casting the masked halfword back to `u16`
keeps the loaded value and its mask in the two temporaries used by the
original. The cast is semantically redundant for the tested bit patterns, but
IDO uses it as the source-shape cue for the original register allocation and
emits no extra instruction. A bounded local `decomp-permuter` search with stack
differences enabled identified this equivalent form; the project verifier then
recompiled it independently.

## Status

Byte-matching C for canonical USA. IDO 5.3 with the recorded `ido53_o2`
profile reproduces all 112 bytes exactly, including all three call delay slots
and the empty return delay slot. Japan and Europe were used only to confirm
structure and relocation.
