## Recovered behavior

A thin guarded wrapper around func_80082FA4.

If the second argument is zero the function immediately clears the caller's
result slot and returns, without calling anything.

Otherwise it prepares a local success flag set to zero, calls func_80082FA4 with
the first two arguments unchanged, the caller's result slot, a literal zero, the
fourth argument, and the address of that local flag. The callee is expected to
set the flag when it produced something. On return, if the flag is still zero
the caller's result slot is cleared; if the flag is set the result slot is left
exactly as the callee wrote it.

Nothing is returned; the only observable output is the result slot.

## Source shape notes

Writing the empty case as an early return, and initialising the flag only on the
call path, reproduces the original control flow directly. The third argument is
homed by the compiler so that it survives the call and can be re-tested
afterwards; that store is not a local variable.
