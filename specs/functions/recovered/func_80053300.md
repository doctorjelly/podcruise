# func_80053300

## Boundary
VRAM 0x80053300-0x8005337C, ROM 0x53F00, 124 bytes. Ends with the standard
return sequence whose delay slot is empty. Both callers enter at 0x80053300;
no branch from the preceding function reaches into this range. Boundary as
assigned is correct.

## Callers / callees
Two direct callers. Calls func_80053220 (predicate taking one integer).

## Globals and access widths
- D_800A52BC: 32-bit signed, read once.
- The single parameter is a pointer to an object; only the 32-bit field at
  byte offset 0x124 is touched (one read, one or two writes).

## Regional addresses
- jp 0x80053F88 (ROM 0x54B88); callee func_80053EA8; global D_800A802C
- eu 0x80057FB0 (ROM 0x58BB0); callee func_80057ED0; global D_800AA5BC
- lrg_rev1 shares the USA addresses.

## Recovered behavior
The routine asks func_80053220 whether feature 0x40 is available, passing the
constant 0x40. If the answer is zero it does nothing at all.

Otherwise it advances a small cyclic counter stored in the object at offset
0x124. The cycle length depends on a global mode value. When that global is 2
or greater the counter runs over the four values 4,5,6,7: it is incremented,
and if the result reaches 8 it is reset to 4. When the global is less than 2
the counter runs over 0..4: it is incremented, and if the result reaches 5 it
is reset to 0. In both branches the incremented value is written back before
the wrap test, so the wrap performs a second write.

## Status
exact in USA, Japan, Europe and lrg_rev1.
