# func_80029C24

## Boundary (corrected)

- The assignment gave USA VRAM `0x80029C24`, ROM `0x2A824`, 260 bytes.
- **Corrected**: the body runs to `0x80029D34`, ROM `0x2A824`, **276 bytes**.
  The conditional near the end branches past the apparent return into the
  heuristic label `func_80029D28`, which has zero direct callers and is simply
  the else arm (clear the flag, return). The last instruction of the real
  function is a return whose delay slot is empty.
- The same spurious tail label exists in Japan (`func_8002A5B0`, 16 bytes); Europe already records the tail as an
  internal label. All three regional bodies are 276 bytes.
- Leaf function: no frame, no calls.

## Callers / callees

- 5 direct call sites; no callees.

- `D_800D6CC4` - scalar 16-bit flag (stored at halfword width).

## Recovered behaviour

The routine recomputes two duration/limit counters and a comparison flag.

1. The current record is selected from the 56-byte record array by the global
   index. Its first field selects an entry in the 16-byte entry table.
2. That entry's byte at +0x03 is a category. The category selects a second
   56-byte record, whose first field selects a second 16-byte entry.
3. Two products are formed with 32-bit integer arithmetic: the category's byte
   from the table at +0x24 of the settings structure times the second entry's
   32-bit field, and the current record's byte at +0x01 times the first entry's
   32-bit field. Both products are read before either result is stored.
4. Each product is converted to floating point, scaled by the global float
   factor, truncated back to an integer, incremented by one, and stored - the
   first into `D_800D6CC8`, the second into `D_800D6CCC`.
5. The flag is set to one when the settings field at +0x18 plus the first
   result is less than the second result (signed), and to zero otherwise. The
   comparison re-reads the two stored counters rather than using temporaries.

## Regional addresses

- Europe: VRAM `0x8002C300`, ROM `0x02CF00`.
- lrg_rev1 shares the USA address.

## Status

Behaviour recovered; not byte-identical. The recovered C compiles to exactly
276 bytes with the same instruction sequence apart from one scheduling slot
(the constant 1 for the flag is materialised inside the taken branch rather
than hoisted) and a different register assignment throughout. Three source
facts were confirmed by matching sub-shapes: the category index is unsigned
(which keeps the two 56-byte scalings as shift sequences rather than a shared
constant multiply), the counters are re-read in the comparison (which is what
makes their addresses materialised once), and both products are computed before
either store (which is what lets the pointer loads hoist above the stores).
