# func_800153EC — squared distance between two 3-component vectors

## Boundary

- USA VRAM range: `0x800153EC` .. `0x80015424` inclusive, 60 bytes
  (15 instructions).
- ROM offset `0x15FEC`.
- Ends with a return whose delay slot holds the final addition that produces the
  result, so the returned value is computed in the delay slot.
- Boundary trap checked and cleared: the preceding function (`func_800153C0`,
  44 bytes at `0x800153C0`) ends with a return plus a square-root delay slot at
  `0x800153E8`, so nothing executable precedes this entry. All four direct call
  sites encode `0x800153EC` as their target. The assigned boundary is correct
  and no correction was needed.
- The "starts four bytes early" symptom was a build artefact, not a boundary
  error: `func_800153C0` and `func_800153EC` are compiled as one unit anchored
  at `0x800153C0`, and until the compiler profile gained the R4300 multiply
  workaround flag the first function came out one scheduling filler short (40
  instead of 44 bytes), which slid this function down to `0x800153E8`. With the
  current profile the first function is 44 bytes again and this one lands on its
  canonical address.

## Callers and callees

- 4 direct call sites; results are used for distance comparisons (one call site
  immediately compares the result against a threshold, another walks a table of
  fixed points).
- No callees; leaf function, no stack frame.

## Globals and access widths

- None. Both operands are pointers to three consecutive 32-bit floats; each is
  read once with a 32-bit float load.

## Regional addresses

- Japan: `0x8001551C`, ROM `0x01611C`, 60 bytes, body identical word for word.
- Europe: `0x8001587C`, ROM `0x01647C`, 60 bytes, body identical word for word.
- Both were read independently from the regional disassembly before probing.

## Recovered behaviour

Takes two pointers to three-component float vectors and returns the squared
length of the difference between them: it subtracts the second vector's
components from the first vector's components, squares each of the three
differences, and returns their sum accumulated in x, y, z order. There is no
square root, so callers that only need to rank or threshold distances can use
this directly.

## Status

Exact. USA, Japan and Europe all verified byte-identical at their canonical
addresses. No new source file was shipped: this function is already produced
byte-exactly as the second function of the existing `src/functions/func_800153C0.c`
unit, and adding a standalone file would define the symbol twice. An
independently written standalone source (which also verifies exact on its own at
`0x800153EC`) is parked at `notes/func_800153EC.standalone.c` in the scratchpad
in case the unit is ever split.
