# func_80009F6C

## Boundary

USA VRAM 0x80009F6C..0x80009F9B (48 bytes, ROM 0xAB6C). The body ends with the
return instruction whose delay slot releases the 0x18-byte frame, so the label
covers a complete function. Three direct callers jump to 0x80009F6C itself and
no branch from the preceding function crosses into it, so the assigned boundary
is correct.

## Callers

Thirteen direct call sites in the USA build, all in the same region as the
scene/attract-mode driver around 0x80052E58 and 0x800533E8. None of them use a
result, so the function is treated as returning nothing.

## Callees

`func_80007A44`, called with no arguments and no result.

## Globals and access widths

- `D_8009ADE8` - one 32-bit word, written only.
- `D_8009AEF0` - one 32-bit word, written only.

Both receive the same value, so the compiler materialises the constant once and
stores it twice.

## Regional addresses

| version  | vram       | rom     | D_8009AEF0 | D_8009ADE8 |
|----------|------------|---------|------------|------------|
| us       | 0x80009F6C | 0xAB6C  | 0x8009AEF0 | 0x8009ADE8 |
| jp       | 0x80009F6C | 0xAB6C  | 0x8009BBE0 | 0x8009BAD8 |
| eu       | 0x80009F6C | 0xAB6C  | 0x800A0440 | 0x800A0338 |
| lrg_rev1 | 0x80009F6C | 0xAB6C  | 0x8009AEF0 | 0x8009ADE8 |

Each regional body was read independently and is instruction-for-instruction
the same shape; only the two data addresses move.

## Recovered behaviour

Perform the shared teardown step provided by `func_80007A44`, then invalidate
two cached selection indices by setting both of them to the "nothing selected"
sentinel value of minus one. The order matters only in that the higher-addressed
slot is cleared first, which is what the original code emits.

## Status

Byte-identical to the original in all four builds under the accepted IDO 5.3
`-O2` profile.
