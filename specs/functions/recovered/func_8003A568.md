# func_8003A568

## Boundary

- USA VRAM range `0x8003A568`..`0x8003A5CF` (inclusive), ROM `0x3B168`, size 104 bytes.
- **Boundary corrected.** The assignment gave 32 bytes. The heuristic label
  `func_8003A588` that follows is not a function: it has zero direct callers, and
  the conditional branch in the first block jumps forward past the first return
  straight into it. The true function therefore covers both heuristic labels.
- The body has two exit points. The early exit returns from the delay slot of an
  unconditional return, loading the returned word in that slot. The final exit is
  a return with an empty delay slot.

## Callers

Seven direct call sites in the USA build, all in the rendering/model code around
`0x8007F120`, `0x8007F460`, `0x8007F96C`, `0x8007FAF4` and neighbours. The result
is used both as an integer (compared against another selection) and converted to
floating point by the caller.

## Callees

None. Leaf function.

## Globals

None. All data comes from the first argument.

## Arguments and data shape

- Argument 1 is a pointer to an object record with:
  - a pointer at offset 0x00 to a shared descriptor table,
  - a 32-bit selection array beginning at offset 0x10 (indexed by argument 2),
  - a 32-bit control word at offset 0x2C.
- The descriptor table holds a 16-bit field at offset 0x00 and a pointer at
  offset 0x0C to an array of 84-byte records.
- Each 84-byte record holds a 16-bit table beginning at offset 0x42.
- Argument 2 is a 32-bit index (also used as a shift amount).
- The return value is 32 bits; on the second path it is a sign-extended 16-bit
  value.

## Recovered behavior

The function looks up an entry for one detail level of an object.

It first reads the object's control word. When that word is zero, no remapping is
in effect and the function simply returns the object's stored selection for the
requested level.

Otherwise the control word is turned into a secondary index: for level zero the
word is used unchanged, and for any other level the word is shifted right
arithmetically by the level number. The object's stored selection for the
requested level is then used to pick one 84-byte descriptor record out of the
table reached through the object's descriptor pointer, and the secondary index
selects a 16-bit entry from the table that begins at offset 0x42 of that record.
That 16-bit entry, sign extended, is the result.
