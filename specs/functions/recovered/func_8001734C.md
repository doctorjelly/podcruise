# func_8001734C — build a packed three-by-three rotation from three angles

Proposed merged specification document: `specs/functions/matrix_from_euler.md`.

## Boundary

- USA VRAM `0x8001734C` .. `0x8001745B` (inclusive), ROM `0x17F4C`, size 272
  (0x110) bytes.
- Terminates with a return instruction whose delay slot is empty; the following
  label `func_8001745C` begins a distinct function with its own frame setup.
- No branch from any earlier function targets an address inside this range.
  `boundary_corrected: false`.

## Callers

One direct caller, `func_80017B3C`, which forwards its own three angle
arguments and passes the address of the object substructure that starts 28 bytes
into the object, then sets the low two bits of the halfword 12 bytes into the
object.

## Callees

`func_80014CC0`, three times, with the same contract described in the
specification for `func_8001723C`: an angle in, its sine through the second
pointer and its cosine through the third.

## Globals

None.

No automatic regional mapping existed for this function, so the regional bodies
were located by adjacency (each sits immediately before the regional body of
`func_8001745C`, which does have a mapping) and confirmed by their relocated
caller: in every image the single caller adds 28 to the object pointer, forwards
three angles, then sets the low two bits of the halfword 12 bytes into the
object. Word comparison of the Japanese and European bodies against the USA body
shows differences only in the three call words.

## Recovered behavior

Identical to `func_8001723C` except for the destination layout. Argument 1
addresses nine consecutive single-precision values — a three-by-three rotation
stored row by row with no padding — instead of the upper-left block of a
sixteen-element matrix. The nine values written are exactly the nine listed in
the `func_8001723C` specification, in the same order, at consecutive offsets.
This is the packed rotation that occupies the first nine floats of the
twelve-float object substructure that `func_80017BA8` fills wholesale, whose
last three floats are the translation.

## Status

Behaviour recovered and reviewed; same two missing empty words as
`func_8001723C`, at byte offsets `0x68` and `0x70`, compiled size 264 against an
expected 272. Removing those two words from the original body reproduces the
compiled output byte for byte. See the `func_8001723C` specification for the
toolchain analysis.
