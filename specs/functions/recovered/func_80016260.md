# func_80016260

## Verified facts

- The canonical USA body spans VRAM `0x80016260` through `0x800167E3`, ROM
  `0x16E60`, 1412 bytes. It returns at `0x800167DC`; the delay slot restores
  the 136-byte stack frame. `func_800167E4` begins next.
- The direct caller is `func_80016A20`. There are no callees or data globals;
  all matrix storage is supplied by the three arguments and all floating-point
  constants are synthesized by the compiler.
- Japan and Europe retain normalized equivalents beginning at VRAM
  `0x80016390` and `0x800166F0`; they are structural evidence only.

## Behavior

The function performs an in-place LU decomposition of a three-by-three matrix
using scaled partial pivoting. It copies the input matrix into the output,
records each selected pivot row through the index argument, swaps rows when
needed, and stores the lower-triangular multipliers below the diagonal. It
returns zero when a zero pivot prevents decomposition and one after completing
all three columns.

## Status

Behavior recovered, not byte-matching. IDO 5.3 `-O2` emits 1444 bytes against
the 1412-byte target and first differs at byte `0x7`. The mnemonic sequences
remain 91.3% aligned, but register allocation and control-flow scheduling do
not reproduce the original, so the USA build retains assembly.
