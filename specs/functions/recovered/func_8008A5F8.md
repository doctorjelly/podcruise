# func_8008A5F8

## Boundary

- USA VRAM range: 0x8008A5F8 .. 0x8008A684 inclusive (0x90 = 144 bytes, 36 instructions).
- USA ROM offset: 0x8B1F8.
- Ends with a return whose delay slot performs the final 16-bit store through
  the fifth argument, so that store belongs to the function.
- The single direct call site targets 0x8008A5F8, which is also the frame
  adjustment, so the assigned boundary is correct. No correction.

## Callers and callees

- One direct call site (a routine at 0x8008A50C that has just tested another
  helper's result and branches on this function's return value).
- Leaf function: no calls out.
- Five arguments: a structure pointer, a pointer to a table of 16-bit entries,
  two unsigned byte values, and an out-pointer passed on the stack.
  Returns a 32-bit integer, which is always zero.

## Globals and access widths

None. All state is reached through the arguments.

- Argument 1 is read only at offset 0x60, as a 32-bit signed word, once per pass.
- Argument 2 is a table of two-byte entries, indexed by a byte value scaled by two.
- Arguments 3 and 4 are unsigned bytes: both are masked to eight bits on entry
  and both get the dead home-slot store that IDO emits for sub-word parameters.
- Argument 5 is a pointer to a two-byte entry, loaded from the incoming stack
  argument slot.

## Regional addresses

Body is instruction-for-instruction identical in all four versions; nothing but
the entry address moves, since the function references no globals.

| version  | VRAM       | ROM     |
|----------|------------|---------|
| us       | 0x8008A5F8 | 0x8B1F8 |
| jp       | 0x8008B2E8 | 0x8BEE8 |
| eu       | 0x8008FB48 | 0x90748 |
| lrg_rev1 | 0x8008A5F8 | 0x8B1F8 |

## Recovered behavior

Walks a chain through a table of two-byte links and marks every visited link.

The two byte arguments form a starting link: the fourth argument is its high
byte and the third its low byte. The walk then repeats: remember the current
link, follow it by using its low byte as an index into the table to fetch the
next link, and overwrite the table entry belonging to the remembered link with
the value 3. The walk stops as soon as the newly fetched link, read as a whole
16-bit quantity, falls below the 32-bit limit stored at offset 0x60 of the first
argument, or as soon as its high byte no longer equals the fourth argument.
Because the loop is a bottom-tested one, at least one link is always followed
and at least one table entry is always marked.

The link that ended the walk is written through the fifth argument, and the
function reports zero unconditionally.

Shape notes needed for byte equality: the two-byte link is a union of a 16-bit
value with a pair of bytes, so that the loop can read the high and low bytes
individually while the loop test reads the whole 16 bits; assigning whole links
(rather than two byte fields) is what produces the compiler's aggregate-copy
form. The starting link is built with a shift and an add, not a bitwise or.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
