# func_8003B860

## Verified facts

The USA body spans VRAM `0x8003B860` through the return delay slot at
`0x8003BAAC`, ROM `0x3C460`, 592 bytes. The canonical body is in
`analysis/generated/us/asm/main_3BF24.s:356–514`. It emits 14 graphics commands
and advances the caller's list pointer by 112 bytes. Signed x/y comparisons
of the input point against the upper-left coordinates select which corner is
replaced; equality selects the right or lower side.

The four geometry-x packing instructions are `sll ..., 16` at `0x8003B91C`,
`0x8003B964`, `0x8003B9AC`, and `0x8003B9F4` (assembly lines 407, 427, 447,
and 467). Each retains the low 16 x bits in the upper half of the packet word
and combines them with the masked low 16 y bits.

## Unsigned packing correction

The four C expressions now cast the masked x coordinate to `u32` before
shifting: `((u32)(vx & 0xFFFF) << 16) | (vy & 0xFFFF)`. Previously the shift
operated on a signed `s32`; values whose low 16 bits are at least `0x8000`
could not produce a representable signed result. This includes an ordinary
offscreen x coordinate of -1. The unsigned operation defines the bit packing
performed by the canonical instructions.

The cast-only correction preserves all 592 compiled text bytes. A separate
private variant removing the x mask changed allocation and worsened the word
comparison from 38 to 59 differences; it was rejected. The nine-case actual-C
regression in `tests/test_vertex_packet.c` checks all four corner choices,
equality, negative and extreme coordinates, texture words, command count,
and surrounding guards. It passes with shift sanitization; the original
source fails the sanitizer for the input point (-1, -1).

## Bounded machine-code pilot

The private reproducer `/tmp/us19-diff3b860/pilot.py` extracts the canonical
ROM interval and the freshly linked ELF function symbol, verifying the
address and 592-byte size. Its restricted big-endian MIPS runner supports
only the 13 opcode forms present in these two bodies, rejects unsupported
instructions and invalid memory accesses, and enforces a 512-instruction
limit. Eleven microtests cover the implemented arithmetic, memory, ordinary
and likely branch delay slots, return delay slot, and rejection paths. An
independent worker reviewed that subset.

There were no discrepancies across 4,884 coordinate/texture boundary cases
or four additional hand-evaluated packet fixtures. All eight conditional
branches exercised both outcomes; all four unconditional branches executed.
The longest path used 133 instructions. The runner compared all 112 output
bytes, the final list pointer, complete mapped memory and guards, and the
callee-saved registers, stack pointer, and return address. The function is
void, so scratch registers, including `$v0`, were not treated as return values.

Of the 4,884 matrix cases, 1,736 were defined under the original signed-shift
expressions and 3,148 exercised that original undefined-shift domain. The
latter establish agreement of the two machine-code bodies, not defined
behavior of the old C. The retained unsigned casts remove this distinction
for the packing operation. This is bounded evidence for aligned, separate
list/stack/output buffers; it is not exhaustive input or alias coverage, and
the restricted runner is not a general MIPS emulator. Results and instruction
coverage are in `/tmp/us19-diff3b860/result.json`; no broader execution pilot
was performed in this tranche.
