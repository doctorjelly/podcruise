# func_80035698

## Boundary

- USA VRAM range: `0x80035698` .. `0x800356BB` inclusive.
- Size: 36 bytes (9 instructions).
- Ends with a return whose delay slot is empty; a second, earlier return sits
  inside the body and carries a store in its delay slot.

**Boundary correction.** Two corrections were needed.

1. The assignment file gave `size: 48`, twice the extent of the heuristic label.
2. More importantly, the heuristic label `func_80035698` covers only the first
   24 bytes. Its conditional branch jumps *past* its own return into the label
   the generator called `func_800356B0`, which has no call sites of its own and
   is only reachable from inside this body. The real function therefore runs
   from `0x80035698` to `0x800356BB`, 36 bytes, absorbing that second label.
   The next real function begins at `0x800356BC`.

## Recovered behavior

A one-argument setter for a global switch.

- If the argument is exactly one, write one into `D_800A3D9C`.
- For any other argument value, write zero into `D_800A3D9C`.

Nothing is returned. Note that this is an equality test against one, not a
truth test: an argument of two also clears the switch.
