# func_800320E0

## Boundary

- USA VRAM `0x800320E0` - `0x800321EC`, ROM `0x32CE0`, 272 bytes
  (68 instructions). Ends with the return whose delay slot is empty. Boundary
  as assigned; no correction.
- Leaf function: no frame; the square root is the hardware instruction, not a
  call.

## Callers / callees

- 5 direct call sites; no callees.

## Globals and access widths

- `D_800AA3A0` - scalar 32-bit float divisor.
- `D_800AA3A4` - scalar 32-bit float offset.
- `D_800AA3A8` - scalar 32-bit float lower clamp bound.

## Parameters

- Argument 1: pointer to an array of at least seven 32-bit floats (the output).
- Argument 2: pointer to an array of at least twelve 32-bit floats (the input).

## Recovered behaviour

The routine normalises six raw quantities into a seven-slot table of
fractions and then clamps every slot.

1. Slot 0 is input 0 divided by one.
2. Slot 1 is input 1 divided by one thousand.
3. Slot 2 is one minus the square root of input 3 divided by one, divided in
   turn by the first global divisor.
4. Slot 3 is input 4 less four hundred and fifty, divided by two hundred.
5. Slot 4 is eight divided by the square root of half of input 5, less the
   second global offset.
6. Slot 5 is input 9 divided by twenty.
7. Slot 6 is a straight copy of input 11.
8. The lower bound is then read once from the third global, and each of the
   seven slots in turn is raised to that bound if it is below it and lowered to
   one if it is above one. Both tests read the slot back from memory, so the
   second test observes the value written by the first.

The loop counter is an unsigned 8-bit variable, which is why the compiled
counter is masked to eight bits on each iteration.

The three divisions by one and the halving are written as divisions in the
source: the compiler turns a division by a constant whose reciprocal is exact
into a multiply, which is why a multiply by 1.0 survives where a literal
multiplication by 1.0 would have been folded away.

## Regional addresses

- Europe: VRAM `0x800356A0`, ROM `0x0362A0`.
- lrg_rev1 shares the USA address.

## Status

Behaviour recovered; not byte-identical. The recovered C compiles to exactly
272 bytes and every instruction matches except that the two long-lived
floating-point values occupy each other's registers: the original keeps the
constant one in the lower register and the clamp bound in the argument
register, and the recovered source does the reverse. Five instructions differ
only in those two register numbers; no other difference remains.
