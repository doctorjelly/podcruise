  empty delay slot at `0x8008459C`.
- Boundary confirmed: label/endlabel bracket the range, the single direct call
  site targets `0x800844C8`, and every internal branch lands inside the range.
  Not corrected.

## Recovered behavior

The object carries a run of eight single-precision entries starting at offset
`0x1C`, which behave like an ordered schedule: an entry is "present" while it
is below a ceiling of 20, and the value -1 marks the end of the run. A separate
word in the object, obtained through the accessor, states how many entries are
actually populated.

The routine reports the index of the last usable entry, or -1 when there is
none. It first asks the accessor for the populated count and gives up
immediately if that count is not positive. It then rejects the object outright
if the very first entry already exceeds the ceiling.

Otherwise it walks forward from the second entry, stopping as soon as it runs
out of the eight slots, meets the end-of-run marker, or meets an entry that has
reached the ceiling. Stepping back one place from wherever it stopped gives the
index of the last entry that was still usable.

Finally the routine cross-checks that index against the populated count: if the
index has reached or passed the count the schedule is inconsistent and -1 is
returned, otherwise the index itself is the result.

Matching details worth recording. First, the ceiling must be held in an
ordinary local rather than repeated as a literal — the original keeps a
register copy of it alive across the loop, which a repeated literal does not
produce. Second, the walk must be phrased as a single loop condition that
conjoins the bound test, the marker test and the ceiling test (with the ceiling
test written in its positive "still below" form); phrasing it as a counted loop
with two break statements makes the compiler strength-reduce the subscript into
a pointer and reverses the ceiling comparison. Third, the final cross-check
must be written as an early return on the failing case.

## Status

Exact in USA, Japan, Europe and lrg_rev1.
