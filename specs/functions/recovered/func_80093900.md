# func_80093900

## Boundary

VRAM 0x80093900..0x8009394F (80 bytes, USA ROM 0x94500). The body ends with a
return and an empty delay slot at 0x80093948. Boundary as assigned; no
correction. Note that one conditional edge inside the body leaves the function
entirely and lands on the entry of the neighbouring routine at 0x80093950,
which then returns on this function's behalf, and it does so with a working
value already live in a register. That cross-function register handoff is only
possible in hand-written assembly.

## Callers

Three direct call sites in USA: 0x8008B044, 0x8008B6EC and 0x8009080C. The
first passes a buffer address and a length of 64 bytes.

## Callees

Falls through by branch into the routine at 0x80093950 for the whole-cache
case; no ordinary calls.

## Globals and access widths

None. The function only touches its two arguments and the data cache.

## Regional addresses

- Japan: 0x800945F0, ROM 0x0951F0
- Europe: 0x80098E50, ROM 0x099A50
- lrg_rev1: 0x80093900, ROM 0x94500 (same as USA)

## Recovered behavior

Flushes a byte range out of the processor's data cache so that the contents are
visible to other bus masters. It takes a start address and a byte count and
returns nothing.

If the count is zero or negative it does nothing. If the count is at least 8192
bytes — the full size of the data cache — it hands off to the neighbouring
whole-cache routine, which sweeps every cache line instead of walking the
range. Otherwise it computes the end of the range, gives up immediately if that
end did not come out above the start (which happens when the range wraps the
address space), rounds the start address down to a 16-byte cache-line boundary,
and then writes back one cache line at a time from that rounded start until it
passes the last line of the range.

## Status

Skipped: not recoverable as C. The loop body is a cache-maintenance instruction
that the compiler has no way to emit — there is no intrinsic, no library call
and no memory access that generates it — and the exit into the neighbouring
routine relies on a register value crossing a function boundary. The
disassembly itself flags the body as hand-written. Behavior is documented above
so the eventual assembly unit can be described, but no C source is offered.
