# func_8003527C

- The body ends with a return whose delay slot holds the final packet store.
- The assignment's size (104) was confirmed correct; no boundary correction.

## Recovered behavior

The function appends three eight-byte command packets to the buffer addressed by
the cursor D_80112C90, advancing the cursor one packet at a time.

1. Constant command word 0xDA380003 paired with the word held at offset 0x34 of
   the structure passed in.
2. Constant 0xDC38000E paired with the word held at offset 0x38 of that same
   structure.
3. Constant 0xDB0C0000 paired with the constant 0x00010000.

This is the same three-packet sequence as func_80034DA8 and func_800352E4 except
that the two payload words come from the caller-supplied structure rather than
from globals, and no flag is cleared. Nothing is returned.

## Source shape notes

As with the sibling functions, each packet had to be emitted from its own
brace-enclosed block using a local pointer initialised from a post-increment of
the cursor, with the three statements of a block on one source line.

## Status

Exact on us, jp, eu and lrg_rev1.
