# func_80062270

## Boundary and interface

The canonical USA routine spans ROM `0x62E70` / VRAM `0x80062270` through
the `nop` return delay slot at `0x80062C74`, for `0xA08` (2,568) bytes. The
former `func_80062274` label is an interior false split: the preceding
`mtc1 $zero,$f0` initializes both stack outputs consumed by the body. The next
routine starts at `0x80062C78`. No inbound reference to either entry was found
anywhere in the USA ROM.

The function takes one pointer. Its verified fields include a state at `0x14`,
elapsed and limit values at `0x18/0x1C`, a node and list at `0x30/0x34`, four
three-float vectors beginning at `0x38`, angles at `0x68/0x6C`, a scale at
`0x94`, two timer pairs, and state bookkeeping through `0xB8`.

## Calls, globals and dispatch

The routine uses the recovered vector, node-transform, animation-time,
transition, waypoint, random-number and object-steering helpers. Its addressed
data are `D_800A5124`, `D_800A5130`, `D_800A513C`, `D_800A5B30`, five distinct
double constants at `D_800AD328` through `D_800AD348`, `D_80118D90`,
`D_80118EF8`, and the per-frame increment `D_80120BF8`.

The 68-entry USA jump table at `D_800AD218` was read from the canonical ROM,
not inferred from target order. Many states intentionally share a target. The
merged body and its return slot have the same size and structure in Japan
(`0x80062DE0` through `0x800637E4`) and Europe (`0x80067750` through
`0x80068154`). Those builds are boundary evidence only.

## Recovered behavior

Start both range outputs at zero, advance the object's elapsed time, refresh
its node-relative vector and world position, and obtain the active animation
range. Dispatch on the state:

- states 1, 3, 7, 9, 10, 13, 15, 25, 26, 31, 33, 35--39 use animation-time
  thresholds to select the next state; state 33 also installs a fixed target;
- states 8, 17, 18 and 29 use the nonnegative random source for intermittent
  transitions, timer durations, position blending or target selection;
- states 11 and 12 update steering/proximity and can return when the waypoint
  helper reports that no transition was performed;
- states 19, 20, 30 and 34 steer the object toward its target, update its
  position or desired angle, and use waypoint/state helpers to choose the next
  phase;
- states 14 and 32 require both a double-precision animation threshold and an
  elapsed-time limit before advancing;
- states 40, 41, 42, 46, 50, 55, 60, 65 and 67 set the attached animation
  amount to the shared rate, half that rate, or zero;
- state 0 returns immediately. The unlisted states perform no case-specific
  action.

After case handling, state 27 also returns without a node transform. Other
states update the node using the saved scale and angle. Mode 2 first subtracts
the list-derived angular offset; other modes use the angle directly.

## Status

Behavior-recovered C. IDO 5.3 `-O2 -mips2` places the merged source at the
canonical address and emits 2,564 bytes versus the original 2,568; the first
difference is at byte `0x17`. It is not byte-matching and is not eligible for
hybrid-build substitution.
