# func_8006D0C0

## Boundary

- USA VRAM `0x8006D0C0` through `0x8006D14F`, ROM `0x6DCC0`, 144 bytes.
- The analyzer's `func_8006D13C` label is an internal target reached by the
  branch-likely at `0x8006D128`; it is not an independent function.
- The high-result path returns at `0x8006D134` and stores `-1.0f` in its delay
  slot. The other path stores `0.0f` at `0x8006D144`, then returns at
  `0x8006D148` with an empty delay slot. The next prologue begins at
  `0x8006D150`.

## References

The sole direct USA call is in `func_8006D150`. It passes a racer-like object,
two point pointers, and a Boolean permission value. The second argument is
spilled but otherwise unused. This function is a leaf and reads no globals.
Japan and Europe preserve corresponding adjacent bodies, while the USA retail
image remains the canonical source and comparison target.

## Behavior

The function first chooses a temporary floating-point value. A point Z value
below the object's threshold selects zero. Otherwise flag `0x200` selects
`500.0f`; when that flag is clear, a nonzero fourth argument selects the
object's value at offset `0x184`, and a zero fourth argument again selects
`500.0f`.

It writes `-1.0f` to object offset `0x2FC` when the selected value is greater
than `400.0f`, or `0.0f` otherwise. It does not return a defined value.

## Status

Byte-matching C. IDO 5.3 with the accepted `ido53_o2` profile reproduces all
144 bytes exactly for USA retail and the LRG USA revision. The exact comparison
also proves that the analyzer's apparent 20-byte successor is part of this
parent body.
