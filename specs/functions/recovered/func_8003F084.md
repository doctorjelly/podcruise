# func_8003F084

## Verified boundary and references

The USA entry is VRAM `0x8003F084`, ROM `0x3FC84`, and the complete body is
316 bytes. The first six instructions precede the stack adjustment but belong
to this call target; the scanner's label at `0x8003F09C` is not a second
function. The return is at `0x8003F1B8`, and its `nop` delay slot is at
`0x8003F1BC`. The next function begins immediately at `0x8003F1C0`.

Recovered callers `func_800573E8` and `func_80059E54` contain five calls with
the same eight-argument shape. This function calls `func_8008A6B4` to format a
temporary string and `func_8003EC40` to draw it. It reads rounding adjustment
`D_800AAB98` and selects format data at `D_800AAB50` or `D_800AAB60`.

The LRG revision retains the same address and bytes. The JP/EU normalized
window search reports this body as non-unique because its neighboring
three-digit timer routine has nearly identical structure, so no regional
identity is inferred from that search alone.

## Behavior

Convert a floating time value into minutes, seconds, and hundredths. Carry a
rounded value of 100 hundredths into seconds and, when needed, minutes. Format
the time with the minute-bearing form only when minutes are nonzero, then draw
the result at the requested coordinates and four byte-sized color components.

## Compiler status

**Byte-matching C.** IDO 5.3 with the accepted `ido53_o2` flags reproduces all
316 USA bytes exactly. Repeating the fractional conversion in the carry test
allows IDO to common-subexpression-eliminate it while reproducing the original
integer-register allocation; the project verifier independently confirms the
linked bytes.
