# func_80093FB4

## Boundary
USA VRAM 0x80093FB4-0x80094028 (116 bytes, ROM 0x94BB4). Ends with a return
and an empty delay slot. Two direct call sites, both supplying a register pair.
Boundary confirmed correct.

## Compilation
This body carries the -O1 fingerprint described in the project brief: both
incoming argument words are homed and reloaded, every local lives in a stack
slot, and a computed pair is stored to stack and never read back. It was
matched with the -O1 profile.

## Callers / callees
Callers at 0x800907A8 and 0x80093F10. Callees: func_8008CA80 (no arguments,
returns a token), func_8008C550 (no arguments, returns a word), func_80097980
(one word), func_8008CAA0 (the saved token).

## Globals
D_8014C520, accessed as a full word, both written and immediately read back.

## Behavior
Takes a single 64-bit value, delivered as a high word and a low word.

It first acquires a token from one routine and keeps it for the duration. It
then queries a second routine for a 32-bit quantity, publishes that quantity in
the global word, and reads the global back to use it.

The 64-bit argument and that unsigned 32-bit quantity are added together as a
full 64-bit sum, carry included. Only the low half of the sum is used: it is
passed to a third routine. The high half is computed and kept in the local
64-bit variable but is not otherwise consumed.

Finally the saved token is returned to the routine that issued it.

## Status
Exact in USA, Japan, Europe and lrg_rev1.
