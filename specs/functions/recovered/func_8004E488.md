# func_8004E488 — set or clear one request bit for one slot

## Boundary (corrected)

* The assigned boundary said 72 bytes, `0x8004E488` .. `0x8004E4CF`. That is
  wrong. The real function is **108 bytes**, USA VRAM `0x8004E488` ..
  `0x8004E4F3`, ROM `0x4F088`.
* The heuristic scan named a second function at `0x8004E4D0` (36 bytes). That
  label has **zero direct callers**, is reached only by the conditional branch
  in the first instruction of `func_8004E488`, and — decisively — it consumes a
  register that is computed in `func_8004E488`'s own delay slot, so it cannot
  be entered from anywhere else. It is the "clear" arm of this function.
* With the correction the body ends at `0x8004E4EC` with a return and an empty
  delay slot, and the next real function starts at `0x8004E4F4`.
* The same correction applies to the regional forms: japan `func_8004F13C` and
  europe `func_80052FF0` are the tails of japan `func_8004F0F4` and europe
  `func_80052FA8`, and lrg_rev1 repeats the USA addresses.

## Callers and callees

* Callers: 24 distinct sites (72 call instructions); typically called in runs of
  one call per bit of a mask word.
* Callees: none — leaf.

## Globals and access widths

| symbol | shape | use |
| --- | --- | --- |
| `D_800A4B94` | four 32-bit words | per-slot request mask |
| `D_800A4BA4` | four 32-bit words | per-slot "newly requested" mask |

Both are the tables cleared by `func_8004DFEC`.

## Arguments

1. slot index (32-bit; scaled by four to index both tables)
2. enable flag (32-bit; non-zero means set, zero means clear)
3. bit mask (32-bit)

## Recovered behaviour

For the given slot, either add the mask bits to that slot's request word or
remove them, according to the enable flag.

When enabling, the function first looks at the request word as it stands. If
none of the requested bits are already present, the same bits are also added to
the companion "newly requested" word, so that a caller can tell a fresh request
from a repeat of one already outstanding. The request word then gains the bits
in either case.

When disabling, only the request word is touched: the mask bits are removed
from it and the companion word is left alone.

## Status

Exact at the corrected 108-byte boundary. Byte-identical in USA, Japan, Europe
and lrg_rev1.
