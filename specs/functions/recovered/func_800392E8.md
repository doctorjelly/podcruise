# func_800392E8

## Boundary
VRAM 0x800392E8-0x8003931C (52 bytes), ROM 0x39EE8. Ends with the return
instruction followed by an empty delay slot. Four direct callers target the
entry; no branch from the preceding function reaches into it. Boundary confirmed
as assigned.

## Callers / callees
Callers: 4 direct call sites. Callees: func_80089BB0, func_800391F4.

## Globals and access widths
- D_800D9C28 — address taken only; passed as a pointer argument.
- D_800A26B8 — written as a 32-bit word.

## Regional addresses
lrg_rev1: same address as USA (0x800392E8), verified exact.
Japan and Europe: no body of this shape exists in either build; the routine was
restructured (most likely inlined or merged) in those revisions, so no regional
unit is claimed.

## Recovered behavior
Hands the fixed data block at D_800D9C28 to a helper that consumes it, clears the
32-bit state word D_800A26B8 to zero, and then requests mode 5 from the module's
state-change routine. Returns nothing.

## Status
exact (USA and lrg_rev1 byte-identical).
