# func_80043598

## Verified facts

- The canonical USA body spans VRAM `0x80043598` through the `jr ra` delay
  slot at `0x800438B8`, ROM `0x44198`, for 804 bytes. `func_800438BC` starts
  immediately afterward with a separate frame.
- `func_80043B6C` is the sole direct caller. The body calls
  `func_80082BE0`, five state-specific camera routines, matrix/orientation
  helpers, an object-presence query, player-record accessors, feedback-state
  helpers, and two final presentation routines. Its computed jump is a
  nine-entry switch table, not an indirect call.
- It reads or writes `D_800A5998`, `D_800A4AD8`, `D_800A4ADC`,
  `D_800A4AE0`, and `D_80120BF0`. The switch table begins at `D_800AACD0`.
- The object fields used directly are its matrix at `0x20`, player and handle
  identifiers at `0x74` and `0x78`, state at `0x7C`, linked object at `0xF4`,
  target position at `0x138`, and control values at `0x2A8` through `0x2B8`.
- Japan and Europe map the entry to `0x80043DA0` / ROM `0x449A0` and
  `0x80047F38` / ROM `0x48B38`. Both retain the 804-byte body and the same
  return placement.

## Behavior

Reject inactive or unassigned objects. When a linked object exists, either
force camera state four under the global override or periodically choose a
new state from a seven-entry table using the runtime random source. Clear the
linked object's special bit except for the table's final choice.

Initialize two view parameters, dispatch the current state to its camera
update routine, then rebuild the object's matrix so it faces the stored target
while preserving roll. If the object's handle is currently present, publish
two values to its player record, update view and feedback globals, and run the
remaining presentation updates.

## Status

Behavior recovered, not byte-matching. Linked IDO 5.3 `-O2` emits the exact
804-byte size and the same control-flow and call layout. Eleven instruction
words differ: the generated frame is 176 bytes rather than 168, two compiler
spill slots move, and three dependent floating-point instructions use a
different temporary register. Three evidence-driven source forms reduced the
difference to this register/stack allocation issue, so no exact claim is made.
