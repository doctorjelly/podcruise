# func_80018480

## Verified facts

- The canonical USA function spans VRAM `0x80018480` through the `jr ra`
  delay slot at `0x80019B7C`, ROM `0x19080`, for `0x1700` (5,888) bytes.
  The return delay slot restores the `0x250`-byte frame, and
  `func_80019B80` begins next.
- Recovered callers are `func_8001D05C`, `func_80020030`,
  `func_80026B3C`, and `func_80027A0C`. Together they establish the matrix,
  integer mode/enable, six scalar, and two feedback arguments used by the C
  signature.
- The function calls the recovered vector and matrix helpers from
  `func_80014CC0` through `func_80017D48`, node-state helper
  `func_800181BC`, feedback helper `func_80076180`, node-parameter helper
  `func_800833B4`, mesh animator `func_800834F0`, and the conditional update
  `func_80029494`. The source candidate emits the same 193 calls in the same
  order as the USA body.
- Global accesses cover the mode words `D_8009B7D8` and `D_800D76F4`, the
  countdown `D_800A21AC`, two parameter arrays, per-type scalar and geometry
  tables, the animation constants `D_800A9AD0` through `D_800A9B3C`, and the
  frame-time value `D_80120C00`.
- The Japan and Europe structural equivalents begin at `0x800185B0` (ROM
  `0x191B0`) and `0x80018910` (ROM `0x19510`). Both end exactly `0x1700`
  bytes later. They confirm the same large body and relocation pattern; USA
  remains the source-recovery target.

## Behavior

The routine rebuilds the transform and display state for a multi-part panel or
model object. It first derives eight phase samples when animation is enabled,
optionally scales the requested dimensions by a per-type factor, installs node
parameter lists, and marks selected child nodes active.

It copies and scales the supplied base matrix, then updates the object's
primary children. A global diagnostic mode selects a simplified transform for
the child at offset `0x128`; the normal path instead positions, mirrors,
rotates, and scales the children at offsets `0x04` through `0x14` and
`0xF8` through `0x100`. Per-type attachment vectors and the sampled phases
control those adjustments. Each non-null updated child receives its matrix and
the corresponding node-state flags.

The normal path also forwards the two feedback amounts, clears two state bits
on eight auxiliary nodes, and decrements the shared effect countdown while it
is positive. Four of those nodes are rebuilt as beams between pairs of primary
children: the function transforms two per-type endpoints, constructs an
orthogonal basis along the difference vector, scales the beam to the measured
length, and optionally updates its mesh animation. Finally it applies the
mode-dependent state to the overlay node at offset `0xEC`.

## Recovery notes

- Stack ranges `0x1C8..0x207`, `0x208..0x247`, `0x4C..0x8B`,
  `0x8C..0xCB`, and `0xCC..0x10B` are 4-by-4 matrices. Several apparent
  scalar temporaries are their row vectors; keeping those aliases is necessary
  to understand the in-place helper calls.
- Stack ranges `0x164..0x183` and `0x184..0x1A3` are the eight cosine and
  sine samples. The per-type geometry record is `0x6C` bytes and exposes
  vectors at offsets `0x00`, `0x0C`, `0x24`, and `0x30`.
- All four disjoint USA windows were checked through their branch and call
  delay slots. Generated control-flow output was used only as a mechanical aid;
  helper contracts, aliases, and the retained C were reviewed against the USA
  instructions and recovered callers.

## Status

**Behavior-recovered C, not byte-matching.** The candidate compiles under the
recorded IDO 5.3 `-O2` profile to `0x163C` bytes versus the canonical
`0x1700`, with its first instruction-word difference at byte 3. Matching call
order and global coverage support the recovered behavior, but only an exact
compiler comparison may promote this function to byte-matching status.
