# func_800442E4

## Boundary
VRAM 0x800442E4-0x8004436F (140 bytes), ROM 0x44EE4. Ends with the return
instruction followed by an empty delay slot. Single direct caller; no branch
targets from the preceding function reach into this range.

## Callers / callees
One caller. Calls func_800862D8 (five integer arguments, fifth on the stack),
func_8008635C (two integer arguments), func_80086730 (one integer argument
followed by five single-precision arguments, the last two on the stack) and
func_8000A920 (two integer arguments).

## Globals
None.

## Regional addresses
- jp: func_80044AF4 @ ROM 0x456F4
- eu: func_80048C84 @ ROM 0x49884
- lrg_rev1: same addresses as USA

## Behavior
A parameterless setup routine. It configures two numbered channels (0 and 1)
with the same four-value description, then applies a mode selection to channel
1, then submits a six-value floating description for channel 1 in which the
first value is 85 and the remaining four are -1. Finally it issues a
notification with a fixed negative identifier and a zero payload. It returns
nothing.

## Status
exact in USA, Japan, Europe and lrg_rev1.
