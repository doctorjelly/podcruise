# func_8003423C

## Boundary

USA VRAM 0x8003423C - 0x80034373 inclusive, ROM 0x34E3C, size 312 bytes
(78 instructions). The body ends with the return instruction at 0x8003436C
whose delay slot at 0x80034370 performs the twelfth store. Two direct callers
(0x80037ED4 and 0x80037EE8) both target 0x8003423C. The body is straight-line;
there are no internal labels. Boundary confirmed, not corrected.

## Callers

Two, both at 0x80037ED4 and 0x80037EE8.

## Callees

None; leaf function, no stack frame.

## Globals and access widths

| symbol      | width | use                                                     |
|-------------|-------|---------------------------------------------------------|
| D_800A3FF0  | word  | current index, re-read before every copied element       |
| D_80112EA0  | f32   | table of 48-byte records, each twelve single floats      |

The 48-byte stride is materialised as a constant in a register and applied with
an unsigned multiply, which is what IDO emits for a non-power-of-two element
size.

## Argument

One argument: the destination, a block of twelve consecutive single-precision
floats.

## Recovered behaviour

Copies the twelve single-precision floats of the currently selected record out
of the 48-byte-strided global table into the caller's buffer.

The selection index is the standalone global word, and it is re-read from
memory before each of the twelve elements is fetched, with the record address
recomputed each time. That is a direct consequence of the destination being an
unqualified float pointer: each store may alias the index word, so the compiler
cannot keep the index or the record address alive across a store. The
observable effect is that if a store into the destination were to overwrite the
index, later elements would come from a different record; the original code has
that property and the recovered source preserves it.

## Notes on shape

- The twelve copies are twelve separate statements in the source, not a loop.
  A loop over a literal count of twelve is unrolled only four ways by the
  compiler and strength-reduces the destination into a moving pointer, giving a
  324-byte body with a live loop counter instead of the 312-byte straight-line
  original.
- The record type is expressed as a two-dimensional array of twelve floats;
  the index expression is repeated verbatim in every statement, which is what
  produces the repeated index load and multiply.

## Status

Exact in all four versions (usa, japan, europe, lrg_rev1).
