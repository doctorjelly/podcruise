- JP and EU equivalents begin at `0x80087E8C` and `0x8008C6E0`.

## Behavior

The routine begins a frame's scene command list, advances buffer state, selects
full-screen or split-view setup, and iterates four enabled views. For each view
it updates camera/render state and records a reference position, then emits the
closing commands and runs the post-scene passes before clearing the one-frame
request flag.
