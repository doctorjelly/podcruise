# func_80052134

## Boundary

- USA VRAM range: 0x80052134 .. 0x800521BC inclusive (0x8C = 140 bytes,
  35 instructions).
- USA ROM offset: 0x52D34.
- Ends with a return whose delay slot moves the result into the float return
  register, so that move is part of the function.
- Assigned size 140 was correct; no boundary correction.
- One instruction inside the range is unreachable: the compiler's
  branch-likely idiom duplicates the single-instruction else branch into the
  delay slot and leaves the original copy stranded just before the join
  label. It is inside the function and counts towards its size.

## Callers and callees

- Six distinct direct call sites in the USA build.
- One pointer argument, returns a float.
- No callees (leaf function).

## Globals and access widths

- None. Everything is reached through the argument.
- Fields used: a signed 32-bit counter at offset 0x78 of the argument, and a
  pointer at offset 0x84 to a second record. In that second record, two
  32-bit floats are read, at offsets 0xE0 and 0xE8.

## Recovered behavior

Reports how far a participant has travelled, in laps, as a single float.

The linked record holds a current fractional position around the circuit and
the fractional position of the start line, both in the range zero to one. The
function takes the signed distance from the start line to the current
position and makes it positive, then folds it: if that distance is more than
half a lap the complement to a full lap is used instead, so the correction is
always the shorter way round the circuit.

The completed-lap counter is then added to the current fractional position and
the folded correction is subtracted, which converts the raw counter and
fraction into a distance measured from the start line. Negative results, which
occur just before a participant first reaches the start line, are clamped to
zero.

## Recovery notes

The absolute value must be written as an if/else in which both arms evaluate
the same subtraction and the negative arm negates it. Computing the difference
once and negating it conditionally is three instructions shorter, and writing
the reversed subtraction in one arm emits a reversed operand order that the
original does not have. Written as an if/else, the compiler produces the
branch-likely form with the duplicated else instruction, which is exactly the
original layout.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
