# func_8002D598

## Boundary and evidence

USA occupies VRAM `0x8002D598` through `0x8002D6EB`, ROM `0x02E198`
through `0x02E2EB`, for 340 bytes. The jump table at `0x800A9F24`
contains 25 targets, all inside this range. Consequently, the apparent
12-byte return islands are switch cases rather than separate functions.
The final return is at `0x8002D6E4`; its delay slot moves the selected pointer
into the return register. Earlier cases return with their address adjustment
in the delay slot.

The two direct callers are at `0x80024C5C` and `0x80025BB4`. The function has
no callees. It reads only its jump table and the addresses of the 25 records
from `D_800A98E4` through `D_800A9AA8`.

Japan has the same 340-byte selector at `0x8002DFFC` / ROM `0x02EBFC`.
Europe expands the corresponding selector at `0x80030628` / ROM `0x031228`
to choose locale-dependent records, so it is structural evidence rather than
an identical regional body.

## Behavior

Map integer selectors 0 through 24 to a fixed table of record addresses.
Return null for every value outside that range.

## Status

Byte-matching C for USA retail and the USA LRG revision. IDO 5.3 with the
accepted `-O2` profile reproduces all 340 bytes exactly. The object-local jump
table requires its original address `0x800A9F24` and 4-byte alignment.
