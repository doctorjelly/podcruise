# func_80087CB0

## Verified facts

- The USA body is VRAM `0x80087CB0` through `0x80087CB7`, ROM `0x888B0`,
  eight bytes. The return jump is the first instruction and its delay slot is
  the single-precision square-root instruction. The two following `nop` words
  are alignment padding before the handwritten routine at `0x80087CC0`.
- The routine has no direct `jal` callers, pointer-table references, globals,
  stack frame, or callees. Its input and result use the normal single-precision
  floating-point argument and return registers.
- Japan maps to `0x800889A0` / ROM `0x895A0`; Europe maps to `0x8008D200` / ROM
  `0x8DE00`.

## Behavior

Return the single-precision square root of the supplied value. IDO expresses
the standard `sqrtf` operation directly as the return jump's delay-slot
instruction rather than a library call.

## Status

Exact. A linked IDO 5.3 `-O2` comparison reproduces all eight USA bytes at the
canonical address. The Japan and Europe bodies contain the same two words at
their independently mapped addresses; only USA is integrated here.
