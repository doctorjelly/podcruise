# func_80011824 — indexed word store

## Boundary
- USA VRAM `0x80011824` .. `0x80011837` inclusive; ROM `0x12424`; size 20 bytes
  (5 instructions).
- Terminates with a return whose delay slot performs the single store; nothing
  executes after the delay slot.
- Preceding function ends with its own return before this entry; both direct
  call sites in the USA build target `0x80011824` exactly. No branch from any
  neighbouring body lands inside this range. Boundary confirmed as assigned.

## Callers
Two direct call sites, both inside the same routine in the `0x8005D8xx`
neighbourhood. Both pass a computed integer index in argument 1 and a plain
integer counter in argument 2.

## Callees
None. Leaf function, no stack frame, no saved registers.

## Recovered behaviour
The routine takes a signed word index and a signed word value and writes the
value into the word-wide global table at that index. It performs no bounds
check, reads nothing back, and returns no result.
