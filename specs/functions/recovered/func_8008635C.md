# func_8008635C

## Boundary

- USA VRAM `0x8008635C` .. `0x800863C4` inclusive, ROM `0x86F5C`, size 108 bytes
  (27 instructions).
- Terminates with `jr $ra` whose delay slot stores the second argument into the
  selected record; the store is shared by both arms of the branch, so it is part
  of the function.
- The preceding function returns at `0x80086354`, and the thirteen call sites all
  reach `0x8008635C` with a direct `jal`. The assigned boundary is correct.

## Callers

Thirteen direct call sites in the USA build. Observed arguments are small
literal indices with either a literal value or zero as the second argument.

## Callees

None; no frame is set up.

## Globals

`D_80120DF0` - an array of records, stride 368 bytes. Two fields are used: a
32-bit flag word at offset 0 (read-modify-write) and a 32-bit signed value at
offset 4 (written).

## Interface

Two 32-bit signed integers: a record index and a value. Nothing is returned.

## Recovered behavior

The routine records a value against one entry of a table and keeps a single
enable bit in that entry's flag word consistent with it.

A negative value means "no value": bit 0 of the flag word is cleared. A value of
zero or more means the entry is active: bit 0 is set. All other flag bits are
preserved. Either way the value itself, including the negative sentinel, is
stored into the entry's second word.

The index arithmetic is performed with shifts and subtractions rather than a
multiply, which is the usual expansion of a constant stride of 368.
