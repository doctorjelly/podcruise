# func_80080148

## Boundary

- USA VRAM range: 0x80080148 .. 0x800801B7 inclusive (0x70 = 112 bytes,
  28 instructions).
- USA ROM offset: 0x80D48.
- Ends with a return whose delay slot performs the last float store, so that
  store is part of the function.
- No stack frame; the argument stays in its incoming register throughout.
- Assigned size 112 was correct; no boundary correction.

## Callers and callees

- Two direct call sites in the USA build. Both sit inside a loop that walks an
  index upward and calls this routine only when a 16-bit status field for that
  index is zero, passing the loop index as the sole argument.
- No callees (leaf function).

## Arguments and return

One signed 32-bit integer: a record index. No return value.

## Globals and access widths

- `D_8011DCF8` — an array of 32-bit words addressed as ten words per record.
  Words 0 through 9 of the selected record are written with zero.
- `D_8011DD00` — appears in the generated disassembly as a separate symbol but
  is not a separate object: it is `D_8011DCF8 + 8`, the address the compiler
  materialises for the tail of the same clear loop after it peels the first two
  iterations. The recovered source references only `D_8011DCF8`; the compiler
  folds the eight-byte displacement into the relocation and reproduces the
  original bytes exactly. No `--sym` for the second name is required.
- `D_80120408` — an array of 32-bit floats addressed as two floats per record.
  Both floats of the selected record are written with 0.0.

## Regional addresses

The body is instruction-for-instruction identical in every version; only the
global addresses move.

| version  | VRAM       | ROM     | word array   | float pair   |
|----------|------------|---------|--------------|--------------|
| us       | 0x80080148 | 0x80D48 | D_8011DCF8   | D_80120408   |
| jp       | 0x80080DE8 | 0x819E8 | D_80120F68   | D_80123678   |
| eu       | 0x80085628 | 0x86228 | D_80126998   | D_801290A8   |
| lrg_rev1 | 0x80080148 | 0x80D48 | D_8011DCF8   | D_80120408   |

(The disassembly's `D_8011DD00` / `D_80120F70` / `D_801269A0` are the same
plus-eight aliases in each region.)

## Recovered behavior

Clears one slot of a parallel pair of tables. Given a record index it writes
zero into all ten words of that record in the integer table and 0.0 into both
floats of the matching record in the float table. It is the per-entry reset
used by the callers when they discover an unused slot.

Two source-shape facts were needed to reproduce the original bytes:

- The record offset in the integer table is an explicit multiplication of the
  index by ten written in the source, not a two-dimensional subscript. The
  compiler emits a real hardware multiply for it and reuses the register that
  already holds the literal ten from the loop bound; a two-dimensional array
  makes it strength-reduce the multiply into shifts and adds instead, which is
  four bytes shorter and does not match.
- The clear loop's subscript is written with the loop counter first and the
  record offset second. Written the other way round the compiler allocates one
  extra temporary, which changes the register numbers of the last two
  instructions even though the instruction sequence is otherwise identical.
- The float pair is a two-dimensional subscript, not an explicit doubling of
  the index; the explicit form costs one extra temporary register and
  perturbs the same two instructions.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
