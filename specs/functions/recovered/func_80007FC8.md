# func_80007FC8

## Boundary
VRAM 0x80007FC8-0x8000803B, 116 bytes, frame 0x28, empty return delay slot.
Single caller targets the entry; the two interior labels are branch targets of
this body, not separate functions.

## Callers / callees
Calls func_80007CE4 (returns a pointer, or zero on failure) and func_800894D0.
func_80007CE4 has no generated listing in this build's disassembly, so its arity
could not be confirmed; it is declared with no parameters here.

## Globals
D_8009A2BC — read as a word and passed as the first argument to func_800894D0.

## Structure fields observed
Through the pointer returned by func_80007CE4: a word at offset 0xC that is
itself a pointer to a table. In that table: a signed halfword element count at
offset 0xE and an array of words starting at offset 0x10.

## Regional addresses
Not established; USA is not byte-exact so the regional forms were not probed.
jp and eu both place the body at 0x80007FC8 (rom 0x8BC8).

## Behavior
Takes one word parameter and returns a word. It first obtains the current owner
object; if none exists it returns -1. Otherwise it derives an index from the low
fifteen bits of the parameter and, if that index is within the owner's table
(non-negative and below the stored element count), looks up the corresponding
entry and returns whatever the lookup helper makes of it, together with the
global handle in D_8009A2BC. If the index is out of range it returns -1.

## Status
behavior. The recovered C reproduces the frame size, the whole control flow and
every memory access, but differs by one instruction: the compiler in the
original scheduled the table pointer load into the delay slot of the
range-check branch and kept the shared return tail, whereas the reproduction
emits a branch-likely with a duplicated tail and spills the result one word
higher (0x1C rather than 0x18). Ten source-shape variations were tried
(declaration order, extra locals, nested versus combined conditions, goto to a
shared tail, early returns, caching the table pointer inside and outside the
guard); the early-return form reaches the correct 116-byte length but loses the
result spill entirely, and the retained form keeps the correct frame and spill
but is 120 bytes.
