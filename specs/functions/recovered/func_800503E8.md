# func_800503E8

## Boundary

- USA VRAM range 0x800503E8 - 0x8005044F inclusive (0x68 = 104 bytes).
- Terminates with the standard return instruction; its delay slot is empty
  because the frame is released one instruction earlier.
- Eighteen direct call sites in the USA image, every one targeting 0x800503E8.

## Callers

Widely called; sites include 0x8001AE58, 0x8001F688 and 0x8001F764.

## Callees

- `func_8005058C(a, b, 1, 0, extra)` - a five-argument routine, the fifth
  argument passed on the stack.

## Globals

- `D_800A4C00` - base of a table of 32-byte records, addressed here by the
  second parameter. Two pointers derived from it are handed to the callee: the
  record itself and the sub-object twelve bytes into it.
- `D_800A2198` - a 32-bit word holding a "most recent" selector.

## Parameters

Four integers: a pointer to a caller-owned object, a record index, a selector,
and an opaque value forwarded to the callee. All four arrive in argument
registers and all four are homed on the frame; the record index and the opaque
value are read back out of their home slots rather than kept live, which is what
the original does too. Nothing is returned.

Regional bodies were read independently; identical shape, only relocations
differ.

## Recovered behaviour

Binds a caller-supplied object to one of the 32-byte table records and starts it.
It first records the chosen record index in the object, at the field 0x34 bytes
into it. It then calls the shared start routine with the record's address, the
address of the twelve-byte-in sub-object, a mode value of one, a zero, and the
caller's opaque fourth argument. Finally, unless the selector argument is the
sentinel -1, it publishes that selector into the module-wide "most recent"
word.

Source-shape note: the object field is written before the call, matching source
order, and the table is addressed as a flat byte array with the record stride
folded into the subscript, so that the base address is materialised once and the
sub-object pointer falls out as a small offset from it.

## Status

Exact in USA, and byte-identical in Japan, Europe and lrg_rev1 from the same
source.
