# func_80087CC0

## Boundary

- USA VRAM `0x80087CC0` .. `0x80087D44` inclusive, ROM `0x888C0`, size 136 bytes
  (34 instructions).
- Terminates with `jr $ra` and an empty delay slot.
- Four direct `jal` call sites reach `0x80087CC0`; the preceding two words are
  padding. The assigned boundary is correct.

## Callers

Four direct call sites in the USA build, two of them in the same routine near
`0x80011B58` and `0x80011C2C`.

## Callees

None, but one conditional branch leaves the body entirely and lands at
`0x80087D48`, a nine-instruction routine with no callers of its own that ends in
its own `jr $ra`. The pair behaves as one routine with two entry-free arms: the
second arm is the whole-cache path of the first.

## Globals

None. Both arms operate on a fixed-size hardware cache and on the address range
described by the arguments.

## Interface

A base address and a signed byte count.

## Recovered behavior

The routine invalidates a range of the processor's data cache.

A non-positive byte count returns immediately. A count that reaches or exceeds
the whole cache size (8192 bytes) transfers to the second arm, which walks the
entire cache from its base in 16-byte steps and invalidates every line. For a
smaller range, the routine first checks that the end address is above the start
address, then handles the two possibly-partial lines at each end of the range
with a "invalidate only if clean, otherwise write back and invalidate" operation
so that unrelated data sharing those lines is not lost, and finally invalidates
every whole line strictly inside the range in 16-byte steps.

This is the standard cache maintenance primitive of the platform's system
library.

## Status

Skipped. The body is authored assembly, not compiler output: it issues the
processor's cache maintenance instruction, which has no C spelling, and it uses
a branch into a separate labelled routine as an alternate arm. The generated
disassembly itself marks both this function and `0x80087D48` as handwritten. No
C source can produce these bytes without inline assembly, which the project
rules forbid, so no source file was created.
