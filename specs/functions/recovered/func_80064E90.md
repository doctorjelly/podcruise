# func_80064E90

## Boundary
VRAM 0x80064E90-0x80064F1B (140 bytes), ROM 0x65A90. Ends with the return
instruction whose delay slot restores the stack pointer. One direct caller.

## Callers / callees
One caller. Calls func_800181BC (five integer arguments, fifth passed on the
stack) and func_8003FD7C (the same object pointer this function received).

## Globals
None; all state is reached through the single pointer argument.

## Object layout touched
- word at byte offset 0x70: element count, read as a signed value
- word at byte offset 0xF0: optional pointer whose first word is cleared
- consecutive words from byte offset 0xF4: per-element handles

## Regional addresses
- jp: func_80065A00 @ ROM 0x66600
- eu: func_8006A370 @ ROM 0x6AF70
- lrg_rev1: same addresses as USA

## Behavior
Releases the resources held by one object. It walks the object's handle array
for as many entries as the object's count field says, re-reading that count
each pass because the release call may change it, and for every non-null handle
performs a release with a fixed descriptor (kind 2, a negative selector, size
16 and flag 3). It then clears the first word of the object's auxiliary pointer
if that pointer is set, and finally hands the object itself to the higher-level
teardown routine.

## Status
exact in USA, Japan, Europe and lrg_rev1.
