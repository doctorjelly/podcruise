# func_8001745C — reset a 4x4 transform to a pure rotation about the origin

Proposed merged specification document: `specs/functions/matrix_from_euler.md`.

## Boundary

- USA VRAM `0x8001745C` .. `0x800174B7` (inclusive), ROM `0x1805C`, size 92
  (0x5C) bytes.
- Terminates with a return instruction whose delay slot is empty; the following
  label `func_800174B8` begins a distinct function with its own frame setup and
  is itself the target of 28 direct calls. `boundary_corrected: false`.

## Callers

88 direct call sites. Every site inspected loads a matrix address into the first
argument and supplies three single-precision angles in the remaining three
argument slots, frequently with a literal zero for one or two of them.

## Callees

`func_8001723C`, once, in tail position.

## Globals

None.

| version | address | ROM | callee replacing `func_8001723C` |

Both regional bodies were read in full and are structurally identical to the USA
body, differing only in the call target.

## Recovered behavior

Argument 1 addresses a sixteen-element single-precision matrix stored row by
row. The function clears the whole last row to zero, clears the last element of
each of the first three rows, sets the bottom-right element to one, and then
hands the matrix and the three angle arguments to `func_8001723C`, which fills
the upper-left three-by-three block. The net effect is a complete transform that
rotates by the three angles and translates by nothing.

## Status

Exact. Byte-identical to the USA image, and to the Japanese, European and
LRG rev1 images at their own addresses.
