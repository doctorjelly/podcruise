# func_8008FD60

## Boundary
VRAM 0x8008FD60-0x8008FDEB (140 bytes), ROM 0x90960. Ends with the return
instruction whose delay slot restores the stack pointer. Two direct callers.

## Callers / callees
Two callers. Calls func_80090500 twice (interrupt-state save then restore),
func_80088020, func_80096710 (a 16-byte copy) and func_80088050.

## Globals
None.

## Object layout touched
- word at byte offset 0x08 of the first argument: head entry pointer
- byte offset 0x0C of that entry: 16-byte payload destination
- word at byte offset 0x08 of that entry: successor, returned to the caller

## Regional addresses
- jp: func_80090A50 @ ROM 0x91650
- eu: func_800952B0 @ ROM 0x95EB0

## Behavior
Pops one entry from a queue while interrupts are masked. It masks, reads the
queue's head entry, and if there is one, detaches it, copies its 16-byte
payload into the caller's buffer, recycles the entry back to its owner, and
remembers the successor entry. If the queue is empty it writes -1 into the
first halfword of the caller's buffer and remembers nothing. It then restores
the previous interrupt state and returns the remembered successor, or zero when
the queue was empty.

## Status
behavior. USA output is the correct length with exactly two adjacent
instructions transposed: the zeroing of the result and the load of the output
buffer address are emitted in the opposite order. Eight source-shape
experiments (declaration order, statement order, one-line grouping, inverted
condition, else-branch initialisation, cached buffer pointer, signed/unsigned
buffer element) did not move that pair.
