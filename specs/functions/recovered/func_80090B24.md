# func_80090B24

## Boundary

- USA VRAM `0x80090B24` - `0x80090C1C`, ROM `0x91724`, 252 bytes (63 instructions).
- Ends with the return instruction whose delay slot clears the integer result
  register; the label boundary in the assignment is correct (no correction).
- Three direct callers; no callees; no globals referenced.

## Callers / callees

- 3 call sites, all direct.
- Leaf function: no stack frame, no calls.

## Parameters and globals

- Argument 1: pointer to a block of 14 unsigned 16-bit values.
- Argument 2: pointer to one unsigned 16-bit accumulator.
- Argument 3: pointer to a second unsigned 16-bit accumulator.
- No globals; no static data.

## Recovered behaviour

The routine computes a two-part 16-bit checksum over a fixed-length block of
fourteen halfwords.

1. Both accumulators are cleared, the third argument first and the second
   argument second. (The order is observable: the compiler forwards the second
   clear into the first accumulation but reloads the other accumulator,
   because the two pointers may refer to the same storage.)
2. For each of the fourteen halfwords in order, the routine adds the halfword
   to the first accumulator and adds the bitwise complement of the halfword to
   the second accumulator. Both accumulations are performed by reading the
   accumulator, adding, and writing back at 16-bit width, so both totals wrap
   modulo 65536, and each read observes any aliasing between the pointers.
3. The routine reports zero.

The block is 28 bytes; the loop counter in the original runs over byte offsets
(0, 2, ... 28) rather than element indices, which is why the compiled loop is
peeled by two elements and then unrolled by four.

## Regional addresses

- Japan: VRAM `0x80091814`, ROM `0x092414`.
- Europe: VRAM `0x80096074`, ROM `0x096C74`.
- lrg_rev1 shares the USA address.

## Status

Behaviour recovered; not byte-identical. The recovered C compiles to 228 bytes
against 252: identical semantics and identical loop structure, but the original
maintains four separate address induction variables through the unrolled body
where the clear source shape yields one base with folded offsets. A source
written with four explicit cursor pointers reproduces the exact 252-byte size
and the same instruction shape, but not the register assignment, so the plainer
version was kept.
