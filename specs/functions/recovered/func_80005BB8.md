# func_80005BB8

## Boundary

- VRAM 0x80005BB8 .. 0x80005C54 (exclusive), ROM 0x67B8, size 156 bytes.
- The body ends with the return instruction; its delay slot performs the final
  32-bit store of the updated flag word back into the entity at offset 0x100.
- The assigned size 156 is correct. The next label (func_80005C54) is a
  separate 8-byte routine and no branch inside this body reaches past the
  return, so the boundary needed no correction.

## Callers and callees

- One direct caller. No calls out (leaf).

## Globals and access widths

- `D_8009A2A0` — 32-bit signed counter, read once and written once.
- `D_800AF4C0` — array of 32-bit pointers (300 entries; a sibling routine
  clears the whole 0x4B0-byte region), one element written by 32-bit store.

## Recovered behavior

Registers one entity with the global active list and primes its animation
range.

1. The entity pointer is appended to the shared pointer table at the index
   held by the global counter, and the counter is bumped by one. No bounds
   check is performed.
2. The entity's first range field (0x0F0) is set to zero.
3. A selector bit (value 0x20) in the entity's flag word chooses which of two
   stored bounds becomes the entity's current range end: the higher-addressed
   bound when the bit is set, the lower-addressed one when it is clear.
4. Another float field (0x0DC) is zeroed, and the range end just chosen is
   copied into two further float fields (0x0F8 and 0x0FC), so all three start
   out equal.
5. If the low four bits of the flag word equal 8, the entity's attached record
   (pointer at 0x124) has one bit (value 8) cleared from its 16-bit field at
   offset 0x0C, when that pointer is non-null.
6. Finally a bit (value 0x1000000) is set in the entity's flag word. Because
   the previous step may have written through an unrelated pointer, the flag
   word is re-read on that path before the bit is set, which the compiler
   reproduces by itself from the plain source expression.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
