# func_8006C6D0

## Boundary

USA VRAM 0x8006C6D0 - 0x8006C707 inclusive (56 bytes, 14 instructions), ROM
0x6D2D0. The body ends with a return whose delay slot is empty. Both direct
call sites target 0x8006C6D0. Nothing from the preceding function branches into
the range. Boundary as assigned is correct.

## Callers

Two direct call sites, at 0x8006E22C and 0x8006EF90. Both pass an object
pointer as the first argument and a small integer as the second; one passes the
literal 1, the other passes a value fetched from its own stack frame. Both
guard the call on an unrelated module flag of their own.

## Callees

None. This is a leaf.

## Globals and access widths

- `D_800D76F0` - an array of 32-bit words, indexed by the second argument
  (scaled by four). One element is read; nothing is written.

## Parameters and return

Two arguments: a pointer to an object, and a signed 32-bit index. No return
value.

## Recovered behavior

The routine conditionally raises one status bit on an object.

It first inspects the table entry selected by the index argument and tests bit
0x2000 of that entry. If that bit is clear the routine does nothing at all.

If it is set, the routine reads the object's 32-bit status word at byte offset
0x60 and tests bit 0x1000. If that bit is already set the word is left alone;
otherwise bit 0x1000 is set and the updated word is written back to offset
0x60. The already-set case is tested explicitly rather than being folded into
an unconditional read-modify-write, so the store is genuinely skipped when the
bit is present.

## Status

Exact on USA, Japan, Europe and lrg_rev1.
