# func_8005337C

## Boundary and interface

USA ROM `0x53F7C` / VRAM `0x8005337C`, through VRAM `0x80053AD4`:
`0x758` bytes. The return at `0x80053ACC` has a `nop` delay slot. The load of
`D_800A5998` at the entry is consumed after the stack-frame setup, proving that
`func_80053384` is an interior false split rather than a second callable
routine. No direct `jal` caller is currently recovered; the single argument is
an owner/state pointer used throughout the body.

## Recovered behavior

Update an owner according to the low nibble of its flags. The seven states
respectively run a countdown and toggle participant readiness, advance an
active timer while watching abort conditions, wait for a finish request, wrap
a three-second phase, wait for an external handle before starting a sweep,
count down that sweep and select a follow-up event, or defer final cleanup until
the owner's timer expires. State transitions preserve the upper flag bits.

The participant loops walk `owner->count` records at a fixed `0x88` stride.
During the initial countdown they set bit `0x800` on each live participant only
inside the open interval defined by the two float limits. At expiry they clear
the timer, select state one, mark each live record, and send the four-byte
`Go!!` message. The sweep-start path selects state five, sets a 9.1-second
timer, starts its effect and camera actions, sends its control message, and
sets the two-second shared cooldown. Once the cooldown expires, the follow-up
path chooses between a default table entry and a signed alternate entry using
one random draw and membership in the `Hang` list.

## Regional evidence

The two-instruction entry prefix relocates together with the body to Japan
`0x80054004` / ROM `0x54C04` and Europe `0x8005802C` / ROM `0x58C2C`. These
versions support the merged boundary; USA remains the only claimed target.
