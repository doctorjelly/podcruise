# func_8000646C

## Boundary

- USA VRAM 0x8000646C..0x8000651C, ROM 0x706C, size 176 bytes (0xB0).
- Ends with the return instruction plus its delay slot restoring the 0x28-byte
  frame; three callee-saved registers are saved and restored.
- Two direct call sites (the same jump-table arm in two overlapping listings)
  target 0x8000646C, so the assigned boundary is correct.

## Callers

Reached from one arm of a jump table dispatch; the caller passes a single
object pointer and ignores the (absent) result.

## Callees

- func_80017E70(object, 2, value) - already recovered; stores `value` into the
  object when the selector is 2.

## Globals and access widths

None. Everything is read through the argument record:

- offset 0x114: 32-bit float threshold
- offset 0x118: signed 32-bit index
- offset 0x11C: pointer to an array of 32-bit floats
- offset 0x120: pointer to an array of signed 32-bit words
- offset 0x124: pointer to a null-terminated array of object pointers

## Recovered behavior

The record carries a keyframe cursor: an index, a float track and a parallel
integer track. The function picks the integer value that goes with the current
position and broadcasts it to a list of objects.

1. Compare the float track entry one past the current index with the record's
   threshold float. When that next entry is strictly below the threshold the
   position has already advanced, so the integer one past the index is taken;
   otherwise the integer at the index itself is taken.
2. If the record holds a target list at all, and the list is not immediately
   terminated, walk it. Each entry is an object pointer, and the walk stops at
   the first null entry.
3. Every object in the list is handed to the accessor helper with selector two
   and the integer chosen in step one, which writes it into the object.

## Compiler notes

The list guard is a short-circuit test of both the list pointer and its first
entry, followed by a bottom-tested loop over a separate cursor variable
initialised from the list pointer. Both halves matter: folding the guard into
the loop condition removes the register copy of the first entry, and using the
list pointer itself as the cursor removes the copy of the list pointer.

## Status

Exact in USA, Japan, Europe and lrg_rev1 under the accepted ido53_o2 profile;
no per-unit compiler flags needed.
