## Behavior
Takes a pointer to a caller-owned display-list cursor. It captures the current
cursor position, then obtains a scratch data block from an allocator and fills
that block from the fixed global source object. It writes one two-word command
at the captured position: the first word is the fixed command code 0xDA380007,
the second the address of the freshly filled block. It then advances the
caller's cursor by the two words just written.

## Status

original; the only remaining difference is which scratch registers the allocator
picked for the cursor reload and the advanced pointer (a uniform one-register
shift). Seven source shapes were tried (local ordering, struct vs array element
access, statement grouping, extra explicit temporary) without moving it.
