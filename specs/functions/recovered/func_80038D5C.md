# func_80038D5C

## Boundary

USA VRAM `0x80038D5C` through `0x80038DBB` inclusive (96 bytes), ROM
`0x3995C`. The return is at `0x80038DB4`; its `0x80038DB8` delay slot is
`nop`, and the next function begins at `0x80038DBC`.

## Callers / callees
The only direct USA call is at `0x80087C68` in `func_800879B8`. Direct
callees are `func_80033E08` and `func_800344F4`.

## Behavior
Takes a pointer to a caller-owned display-list cursor. It captures the current
cursor position, then obtains a scratch data block from an allocator and fills
that block from the fixed global source object. It writes one two-word command
at the captured position: the first word is the fixed command code 0xDA380007,
the second the address of the freshly filled block. It then advances the
caller's cursor by the two words just written.

## Status

Byte-matching C. The independently written source compiles with the accepted
IDO 5.3 profile to a 96-byte body at `0x80038D5C` that is byte-identical to the
USA ROM. The exact form keeps a late alias for the original cursor before
advancing the working cursor; this gives the canonical tail register allocation
without inline assembly or a fixed-register extension. The match was verified
with the repository's linked per-unit comparison, including the return delay
slot.
