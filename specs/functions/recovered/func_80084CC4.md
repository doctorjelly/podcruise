# func_80084CC4

## Boundary
USA VRAM 0x80084CC4-0x80084D44, ROM 0x858C4, size 128 bytes. Ends with the
return instruction followed by an empty delay slot. Boundary confirmed correct.

## Callers / callees
One caller. Calls func_8008A360 (one 32-bit argument) and func_80039CD8 (one
integer argument).

## Globals
- D_800A68AC — 32-bit word, read and passed on.
- D_800D9DB0 — single byte, read/modified/written (a three-state counter).
- D_800D9DB1 — single byte, read and written (a toggle).
- D_800A40F0 — 32-bit word, tested and cleared.

- lrg_rev1 shares the USA addresses.

## Behavior
A per-frame housekeeping step. It first hands the currently selected handle to
a service routine. It then advances a byte-sized rotating index, wrapping it
back to zero once it would reach three, giving a 0-1-2 cycle. It flips a
byte-sized alternating flag between one and zero by subtracting the current
value from one. Finally, if a pending-request word is non-zero it invokes a
handler with a zero argument and clears the word. Returns nothing.

## Status
exact in USA, Japan, Europe and lrg_rev1.
