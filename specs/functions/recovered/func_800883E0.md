# func_800883E0

## Boundary

- USA VRAM range: 0x800883E0 .. 0x800883EB inclusive (0xC = 12 bytes, 3 instructions).
- USA ROM offset: 0x88FE0.
- Terminates with a return whose delay slot performs the memory-mapped read,
  so the load is part of the function body.
- A single alignment filler word precedes the entry and another follows it; the
  neighbouring routines are separate bodies with their own call sites.
- Assigned size 12 was correct; no boundary correction.

## Callers and callees

- One direct call site in the USA build, inside the audio-submission path at
  0x800074A4. The caller immediately shifts the returned value right by two,
  i.e. it treats the result as a byte count and converts it to words.
- No callees (leaf function).

## Globals and access widths

- No linker symbols. The function reads one 32-bit word from the fixed
  uncached peripheral address 0xA4500004, which is the second register of the
  audio interface block (the outstanding transfer length). The high half of the
  address is materialised into a scratch register and the low half becomes the
  load displacement, which is the shape produced by a constant-address pointer
  dereference rather than by a named data symbol.

## Regional addresses

The body is instruction-for-instruction identical in every version, and the
peripheral address is an absolute constant, so nothing relocates.

| version  | VRAM       | ROM     |
|----------|------------|---------|
| us       | 0x800883E0 | 0x88FE0 |
| jp       | 0x800890D0 | 0x89CD0 |
| eu       | 0x8008D930 | 0x8E530 |
| lrg_rev1 | 0x800883E0 | 0x88FE0 |

## Recovered behavior

Reads and returns the current audio interface transfer length: the number of
bytes the audio DMA engine still has queued. Takes no arguments and has no side
effects of its own; the caller divides the result by four to obtain a sample
count.

The access must be written as a dereference of the literal hardware address.
Expressing the same read through a named external word instead folds the
address into the return register and loses the scratch register the original
uses, which is how the constant-address form was confirmed. The recovered
source also marks the location as changing independently of the program, which
is the honest description of a device register; that qualification does not
affect the emitted bytes either way, since the value is read exactly once.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
