# func_80031560

## Boundary
USA VRAM 0x80031560-0x800315D8 (120 bytes, ROM 0x32160). The return's delay
slot carries the frame release. Six direct call sites including its own
self-call. Boundary confirmed correct.

## Callers / callees
Self-recursive; other callers pass either a small index or the sentinel -1.

## Globals
D_800DB8A0: an array of 28-byte records. A full word is written at offset 0x0C
of a record and a 16-bit halfword at offset 0x06.

## Regional addresses
- jp 0x80031FC0 (ROM 0x32BC0); array at D_800DEB10
- eu 0x80034B20 (ROM 0x35720); array at D_800E4540
- lrg_rev1 shares the USA addresses

## Behavior
Takes one index. The value -1 means "all", and in that case the routine simply
calls itself once for each of the four indices zero through three and returns.

For a real index it selects the corresponding 28-byte record in the global
array and initialises two fields of it: the word at offset 0x0C is set to one,
and the halfword at offset 0x06 is set to 0x8000, the unsigned mid-scale value
for a 16-bit quantity.

## Status
Exact in USA, Japan, Europe and lrg_rev1.
