# func_8008A710

## Boundary
VRAM 0x8008A710-0x8008A750 (64 bytes, 16 instructions). The final instruction is
the frame release in the return's delay slot. Two direct call sites target the
entry. Not corrected.

## Callers
Two direct call sites.

## Callees
func_80093820 (entered first, no arguments), func_80093890 (given both incoming
arguments, produces the result), func_80093864 (entered last, no arguments).

## Globals
None.

## Regional addresses
- jp 0x8008B400 (rom 0x08C000)
- eu 0x8008FC60 (rom 0x090860)

## Recovered behavior
A bracketed wrapper around a single operation. Both incoming arguments are saved
into their home slots so they survive the first call. The function opens with
func_80093820, then performs the real work by passing the two arguments through
to func_80093890 and keeping its result, then closes with func_80093864, and
finally returns the kept result. The bracketing calls take no arguments and
their results are discarded, so they read as an acquire/release or
begin/end pair around the middle call.

## Status
Behavior recovered, not byte-exact. The compiled body is 60 bytes against the
original's 64: the original parks the kept result in a callee-saved register
across the closing call, while the accepted profile spills it to a stack slot
instead. Every source-level variation tried (result type, declaration position,
nested block with initialiser, extra copy, unprototyped callee, extra reserved
local) and every flag variation tried (-O1, -O3, -mips1, -mips3, no r4300_mul
workaround, no loop unrolling, the IDO 7.1 profile) reproduce the same spill.
The same register-choice discrepancy appears in func_8008C770, which sits in the
same address region, so this is likely a per-unit compiler option that the
matching configuration does not yet carry rather than a source-shape problem.

## Status update (retry pass)

Exact. The translation unit was built at optimisation level 1, and the value the
body holds across the inner call was declared with the `register` storage class
so it stays in a callee-saved register instead of spilling to the frame. Japan,
Europe and lrg_rev1 all verify exact from the same source with name remapping
only; the regional bodies were read independently and are structurally identical.
