# func_8005F31C

  USA ROM offset `0x5FF1C`.
- The body ends with `jr $ra` and an empty delay slot; the single conditional
  branch in the entry block targets that return, not anything past it, so the
  function is self-contained.
- The next label, `0x8005F33C`, opens with its own frame adjustment
  (`addiu $sp, $sp, -0x78`), confirming the end of this body.
- Four direct call sites all target `0x8005F31C` itself.
- No boundary correction was required.

## Callers / callees

- Callers: 4 direct call sites, all within the same text section, and all of
  them pass a pointer loaded out of a parent object plus the address of a
  global as the second argument.
- Callees: none. This is a leaf.

## Globals and access widths

- None. The function touches only memory reached through its first argument.
- Argument 1 is a pointer to an object; two of its fields are used:
  a signed 32-bit counter at offset `0x14` and a 32-bit pointer slot at
  offset `0x18`.
- Argument 2 is a pointer value (the observed call sites pass the address of a
  static object).

## Recovered behavior

Registers a subscriber against a target object. If the caller passes a null
target the routine does nothing at all and returns immediately. Otherwise it
increments the target's 32-bit reference/registration count held at offset
`0x14` by one, and stores the supplied pointer into the slot at offset `0x18`,
overwriting whatever was there before. There is no bounds check, no read-back
of the stored pointer, and no return value.

The ordering matters for reproducing the original code: the counter is bumped
first and the pointer stored second. The compiler then hoists the pointer store
into the gap after the counter load, which is what the original bytes show.

## Status

Exact. USA, Japan, Europe and lrg_rev1 all verified byte-identical.
