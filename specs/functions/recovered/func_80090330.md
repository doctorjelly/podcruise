# func_80090330

## Boundary
USA VRAM 0x80090330-0x800903C3 (0x94 = 148 bytes), ROM 0x90F30.
0x18-byte frame; the body ends with a return whose delay slot is empty. Three
padding words follow before the next function, and the two direct call sites
both target 0x80090330, so the label is a real entry. The preceding function
(0x800902A0) returns at 0x8009031C and no branch of it reaches past that.

## Callers / callees
Two direct callers, both inside the same subsystem at 0x80088D90 and 0x80088FA0.
Both load the third argument as a single unsigned byte (one from a record field,
one from a byte just written into that field), which fixes the third parameter
width.

Calls `func_80088500` once with no arguments; it is already recovered and
returns a pointer to a recycled record, or null when the free list is empty.
Then it makes one indirect call through a function pointer reached from the
second argument.

## Globals
None referenced directly.

## Regional addresses
- JP 0x80091020, ROM 0x91C20; the allocator moves to 0x800891F0.
- EU 0x80095880, ROM 0x96480; the allocator moves to 0x8008DA50.
- lrg_rev1 shares the USA addresses.
All three regional bodies were read instruction by instruction and differ from
USA only in the call target of the allocator.

## Recovered behavior
Nothing happens unless the second argument currently owns a stream. When it
does, a record is taken from the shared free list; if the list is exhausted the
function returns quietly. Otherwise the record is filled in: its position field
becomes the first argument's base value plus the stream's own running offset,
its kind field is set to the constant that identifies this event, its payload
becomes the magnitude of the byte-sized third argument, and its link field is
cleared. Finally the stream's registered receiver is invoked with a selector of
3, the freshly built record, and the owner, which hands the event off for
queueing.

## Notes on shape
The neighbouring routines at 0x80090200, 0x800902A0 and 0x800903D0 are the same
shape with different tags and payload widths (halfword, float, none), which
confirmed the field map. The one shape fact that mattered: the position field
must be assigned before the kind field. Written the other way round IDO emits
the constant-and-store pair ahead of the two pointer loads and the body diverges
at offset 0x30 while staying the same length. The payload is written as the
magnitude of a signed local seeded from the unsigned byte parameter; IDO does not
fold the sign test away, and the untaken negate arm is present in the original.
