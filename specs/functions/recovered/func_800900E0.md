# func_800900E0 — post a kind-14 event to a voice's stream sink

## Boundary
- USA VRAM 0x800900E0 .. 0x8009016B (140 bytes, ROM 0x90CE0).
- Ends with the return instruction plus an empty delay slot; the 24-byte frame
  is released just before it, and a single alignment word follows the body.
- Boundary confirmed: the one direct call site targets 0x800900E0, the frame
  adjustment is the first executed instruction, and no branch from the previous
  function enters the range. Not corrected.

## Callers
One direct call site, at 0x80088D48 inside the large per-frame update routine.
It passes a clock/context pointer taken from a parent object, the voice, and a
word read out of a neighbouring object. The return value is not used.

## Callees
- `func_80088500()` — no arguments; takes the head node off the shared free
  list and returns it, or returns zero when the list is empty.
- An indirect call through the sink's own function table (the third word of the
  sink object), invoked with the sink, the constant 3, and the new event.

## Globals and access widths
None directly; everything is reached through the arguments.

## Arguments
1. a context object holding a 32-bit timestamp at offset 0x1C;
2. a voice object whose stream pointer sits at offset 0x08 and which carries a
   16-bit tag at offset 0x1A;
3. a 32-bit payload word.

## Regional addresses
| version | entry | rom | allocator |
|---|---|---|---|
| us | 0x800900E0 | 0x90CE0 | func_80088500 |
| jp | 0x80090DD0 | 0x919D0 | func_800891F0 |
| eu | 0x80095630 | 0x96230 | func_8008DA50 |
| lrg_rev1 | 0x800900E0 | 0x90CE0 | func_80088500 |

All three regional bodies were read independently and are the same shape as the
USA one apart from the relocated allocator address.

## Recovered behavior
If the voice has no stream attached, nothing happens at all.

Otherwise an event record is taken from the shared free list. If none is
available the request is silently dropped. When one is obtained it is filled in
as follows:

- its scheduled time becomes the context timestamp plus the stream's own
  running offset (the 32-bit field at 0xD8 of the stream);
- its kind is set to 14;
- its payload word is the third argument;
- its first word is cleared;
- its 16-bit secondary field copies the voice's tag from offset 0x1A.

The filled record is then handed to the stream's sink by calling the function
stored in the sink's table with the sink itself, the constant 3, and the event.

This is the same family of posting helpers as the neighbouring routines at
0x80090170 and 0x800902A0; it differs from them in the event kind, the 32-bit
payload, and the extra copy of the voice tag.

## Status
Exact. Byte-identical to the original in us, jp, eu and lrg_rev1 under the
accepted `ido53_o2` profile. No per-unit flags needed.
