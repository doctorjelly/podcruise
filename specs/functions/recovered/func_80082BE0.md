# func_80082BE0

## Behavior and canonical arithmetic

The USA function occupies ROM `0x837E0` / VRAM `0x80082BE0` for 152 bytes,
ending with the return delay slot at `0x80082C74`. It lazily copies the low
32 bits of `func_800811DC()` into the seed global, advances the state with the
linear-congruential recurrence, saves the updated state, and returns its
absolute signed value. The signed minimum maps to zero to avoid negating it.
Japan retains its separate clamp for the extreme positive results.

The USA ROM computes the recurrence with `multu`, `mflo`, and `addiu 0x3039`.
The low product word and subsequent addition therefore wrap modulo 2^32.
Signed C multiplication and addition could overflow and invoke undefined
behavior. The source now performs both operations as `u32` before converting
the result back to `s32`. That conversion is implementation-defined when the
high bit is set; it matches the intended two's-complement N64/IDO state
representation, but is not a portable signed conversion guarantee.

## Verification

The corrected USA source emits 152/152 bytes at the canonical address and
retains the same 152-byte function SHA-256 as the previous source:
`8b5f3193f8b884a408ebda29e3afaa0c228d16fc72e4c6e38aefa9ff1f26d503`. Five
instruction words still differ, at VRAM `0x80082C30`, `0x80082C34`, `0x80082C4C`,
`0x80082C60`, and `0x80082C64`; the first differing byte is `+0x52`. This
arithmetic correction does not claim an exact match.

`tests/test_rng.c` checks fixed seed/state/result vectors for seeds zero, one,
two, `0x12345678`, and predecessors that produce `INT_MIN`, `INT_MAX`, and
negative one. It also checks lazy initialization from the 64-bit timer value
`0x12345678ABCDEF01` using its low word, plus the initialized path's zero
timer-helper calls. The original source builds under UBSan but fails at seed
two with signed integer overflow. The corrected source passes the same
actual-function test under `-fsanitize=undefined
-fno-sanitize-recover=undefined`.

A six-profile IDO 5.3 sweep of the corrected source finds no exact match.
O1 emits 184/224 bytes for MIPS II/III; O2 and O3 emit 152/196 respectively.
