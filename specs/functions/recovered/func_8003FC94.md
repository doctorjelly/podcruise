# func_8003FC94 — broadcast a "Free" notice to one registry group

## Boundary

* USA VRAM `0x8003FC94` .. `0x8003FD7B` inclusive, ROM `0x40894`, size 232 (0xE8).
* The body ends with the return instruction; its delay slot performs the stack
  pointer release, so the last four bytes belong to this function.
* The next label (`func_8003FD7C`) is reached only by its own direct callers, and
  every conditional branch inside this body targets an address inside the range.
  The assigned boundary is correct.

## Callers

11 distinct direct call sites are recorded for the USA build. The call sites
observed pass a four-character identifier constant (for example the literal
formed from the characters `Elmo`) in the first argument slot and never read a
return value, so the function returns nothing.

## Callees

* `func_8003F99C` — delivers one notice record to a single element.

## Globals and access widths

* `D_800A2170` — read as a full 32-bit word; the word is a pointer to a
  null-terminated table of group-descriptor pointers.
* Group descriptor fields used, all 32-bit words: identifier at +0x00,
  element count at +0x08 (signed), element stride in bytes at +0x0C,
  first-element pointer at +0x10.
* Element field used: a signed 16-bit status halfword at +0x06, read and
  written at that width.

## Recovered behavior

The function prepares a small notice record on its own stack whose leading word
is the four-character tag `Free`, then walks the global registry table from its
first entry until it reaches the terminating null pointer.

For every group whose identifier equals the caller's identifier, it visits the
group's elements in order: the first element is the group's element pointer and
each following element sits the group's stride further along in memory. An
element whose status halfword already has bit 0x100 set is left alone. Any other
element is handed to the notice helper together with the address of the prepared
record, and afterwards has bit 0x100 set in its status halfword, so a repeated
sweep will not notify it twice.

The element count and the stride are re-read from the group descriptor on every
pass, because the notification handler may change them. The visit counter is a
signed 16-bit quantity and is compared against the signed 32-bit element count,
so a group whose count is zero or negative is skipped entirely. The walk does
not stop after the first matching group; every matching group in the table is
processed.

## Notes on shape

The stack notice record occupies two words in the reconstruction. Only its
leading tag word is ever written; the record's true declared size is not
observable beyond the frame size it produces, and two words is the size that
reproduces the original frame layout here.

## Status

Byte-exact in usa, japan, europe and lrg_rev1 under the accepted `ido53_o2`
profile. No per-unit compiler flags were required.
