# func_800183B0 — store a pointer into the second word of an object

## Boundary

- USA VRAM range: `0x800183B0` .. `0x800183B7` (inclusive), 8 bytes.
- ROM offset `0x18FB0`, translation unit `main_18B28.s`.
- The body is a return whose delay slot performs the single word store; both
  instructions belong to the function, so the 8-byte extent is the whole body.
- Boundary as assigned was correct, and it is a genuine callable entry, not a
  shared tail:
  - the preceding routine at `0x800183A8` terminates with its own return and
    its own delay-slot instruction at `0x800183AC`, so nothing falls through
    into `0x800183B0`;
  - no branch anywhere in the preceding routine targets `0x800183B0`;
  - the one direct call site targets `0x800183B0` exactly;
  - `0x800183B8` and `0x800183BC` are alignment padding before the next
    function at `0x800183C0`, not part of this body.

## Callers

One direct call site, at `0x8007F200`. It first calls the neighbouring reader
at `0x800183A8` on the same object, and only when that reader returns zero does
it call this routine with the same object in argument 1 and the address of the
global `D_800A6708` in argument 2. Argument 2 is therefore a pointer, and there
is no return value.

## Callees

None (leaf).

## Globals and access widths

None. The routine touches only memory reached through its first argument.

All four bodies were read independently and are instruction-for-instruction
identical; no data symbol is referenced, so nothing relocates.

## Recovered behaviour

The routine writes its second argument into the 32-bit field four bytes into
the object addressed by its first argument, and returns nothing. It performs no
test, reads nothing back, and touches no other memory. It is the writer half of
a reader/writer pair with the routine immediately before it, which returns the
same field.

## Status

Exact in USA, Japan, Europe and lrg_rev1.
