## Callers

Sixteen direct call sites, concentrated in the segment beginning at 0x80018B28.
The call sites pass a two-valued outer index, an inner index in the range 0..7,
a word value, a float constant, a further float on the stack and three byte
values on the stack. Several call sites are visibly a sequence of consecutive
registrations differing only in the inner index and the constants.

## Recovered behaviour

The routine fills one entry of a two-dimensional registration table, addressed
by an outer index (a slot, 0 or 1) and an inner index (a sub-entry, 0 through 7).

Both indexes are validated before anything is written. The outer index must be
non-negative and below two; the inner index must be non-negative and below
eight. Any failure returns immediately with no memory effect.

When both indexes are in range the routine stores:

1. the third argument, a word, into the word table at [outer][inner];
2. the fifth argument, a float arriving on the stack, into the first float
   table at [outer][inner];
3. the fourth argument, a float arriving in a register, into the second float
   table at [outer][inner];
4. the sixth, seventh and eighth arguments into the three consecutive bytes of
   the byte table entry at [outer][inner].

Note that the stack-resident float is stored to the numerically lower table and
the register float to the higher one, so the two floats are not written in
argument order.
