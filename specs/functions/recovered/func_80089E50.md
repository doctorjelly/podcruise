# func_80089E50

## Verified facts

- The canonical USA body spans VRAM `0x80089E50` through the `jr ra` delay
  slot at `0x80089F6C`, ROM `0x8AA50`, for 288 bytes. `func_80089F70`
  starts next; the return delay slot restores the 88-byte stack frame.
- No direct `jal` to this function appears in canonical USA CPU text, and no
  literal function pointer appears in the ROM. Its caller is therefore not
  established; it may be unused or reached through a constructed callback.
- It calls `func_80091280`, optionally calls `func_80091FD0`, and calls
  `func_80092050` once per entry. It accesses only its object argument, a
  stack-local query record, and the two output pointers; there are no globals.
- The structurally equivalent Japan and Europe entries are `0x8008AB40` and
  `0x8008F3A0`. Their complete normalized bodies confirm the same boundary,
  control flow, field offsets, and relocated helpers.

## Behavior

The routine rejects an object whose low enable bit is clear, then runs its
primary update and an optional mode update, returning the first nonzero error.
It otherwise queries each indexed entry, counts entries whose word and
halfword fields are both nonzero, and publishes that count together with the
object's total entry count. A query error returns immediately without
publishing the final totals.

## Recovery notes

The query record is 0x20 bytes, not the earlier guessed 0x30. Declaring it
between the two scalar loop locals makes IDO place it at stack offset `0x30`;
the corrected size then restores the canonical 0x58-byte frame. Those facts
are independently visible in the helper argument and the later loads from
record offsets zero and four. With that layout correction, the existing
control flow and all register assignments compile unchanged to the original.

## Status

Byte-matching C for canonical USA. IDO 5.3 with the recorded `ido53_o2`
profile reproduces all 288 bytes exactly, including the branch-likely delay
slots, three call delay slots, and the nonempty return delay slot. Japan and
Europe were used only to confirm structure and relocation.
