# func_80012BF0

## Boundary and interface

The canonical USA body occupies ROM `0x137F0` / VRAM `0x80012BF0` through
the stack-restoring return delay slot at `0x80013DBC`, exactly `0x11D0`
(4,560) bytes. `func_80013DC0` begins at `0x80013DC0`. The return is the
`jr $ra` at `0x80013DB8`; its delay slot restores the `0x100`-byte frame.

The recovered caller passes a byte string, the selected font descriptor, and
a signed texture-page index. It invokes this routine once per font texture.
The Europe build has a relocated structural counterpart at `0x80013080`; no
Japan address is asserted because the available mapping is not unique enough.

The body directly calls `func_800125E4` to load the requested font texture,
`func_800129E4` to measure centered or right-aligned text, `func_80011F04` to
change the current color, and `func_80011F38` to emit glyph rectangles. It
reads the current font, palette, glyph-remapping tables and text cursor globals
and publishes the ending cursor through `D_800A1CD4`.

## Behavior

Load one texture page, then scan a zero-terminated formatted string. Ordinary
characters are normalized for uppercase-only fonts and resolved through a
16-byte glyph record. A glyph is drawn only on its assigned texture pass, but
its advance is applied on every pass so each pass reaches identical positions.
High character codes can resolve through the extended-glyph remapping table and
optionally fall back to a normal character.

Formatting sequences begin with byte `0x7E`. They can center or right-align
the remaining line, start a new line, select one of ten RGB palette entries,
toggle outline, shadow, or four-direction edge passes, clear those effects,
select a numbered text block, or produce a literal `0x7E`. Effect passes draw
in black while retaining the current alpha, then restore the current RGBA
color before the main glyph.

Block markers interact with `D_800D6910` and `D_800A1CA4` so callers can draw
only one numbered portion of a compound string. On exit, store the final x/y
cursor and append an `E7000000 00000000` display-list synchronization command.

## Status

Behavior recovered from the canonical USA body and independently expressed in
C. IDO 5.3 `-O2 -mips2` emits 4,364 bytes for the 4,560-byte target and first
differs at byte `0x5`; the 28 glyph-draw call sites and all four other direct
calls retain the canonical order and counts, but the compiler allocates a
different frame and control-flow layout. This is not byte-matching and is not
eligible for hybrid-build substitution.
