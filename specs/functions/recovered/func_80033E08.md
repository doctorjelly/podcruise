# func_80033E08

## Globals and access widths

- `D_800A3CC4` - a single 32-bit signed counter, addressed once and then read
  once and written up to twice.
- `D_800E2C50` - the base of an array. The returned address is the base plus the
  counter scaled by 64, so the array elements are 64 bytes wide. The base itself
  is never dereferenced here.

## Recovered behavior

The same round-robin slot dispenser as its immediate predecessor, but for a
second and much larger pool: 3072 records of 64 bytes each.

Each call advances a persistent counter by one, resets it to zero once it
reaches 3072, and returns the address of the pool entry that the counter now
selects. The counter and the pool are entirely separate from the neighbouring
function's, and the two counters live in adjacent words, which suggests one
table of ring-buffer cursors.

As with the neighbour, the comparison is signed, the slot contents are left
untouched, and there is no notion of a slot being busy - after 3072 calls the
oldest slot is silently handed out again.

## Status
