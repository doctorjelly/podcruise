# func_80009744

## Boundary

- USA VRAM `0x80009744` .. `0x8000981F`, ROM `0xA344`, size 220 bytes (55
  instructions). Terminates with the return instruction at `0x80009818` and an
  empty delay slot at `0x8000981C`.
- Boundary confirmed: label/endlabel bracket the range, all sixteen direct call
  sites target `0x80009744`, and every internal branch stays inside the range.
  Not corrected.

## Callers

Sixteen direct call sites. Several pass a literal 1 as the first argument with
a second argument taken from an object field, and at least one passes 1 with a
second argument of zero, which confirms both arguments are word-sized and that
the second is only consulted on one of the paths.

## Callees

- `func_8003F7B8` (`0x8003F7B8`) — walks a linked list looking for a node whose
  first word equals the supplied key and returns a word from the match, or zero
  when the list is empty.

## Recovered behavior

This is a small mode switch that records which of four presentation modes is
active and sets up the one tuning value that mode needs. The first argument
selects the mode; the second is a rotation counter that only mode 1 uses.

Mode 0 records the mode and clears the tuning word to -1, meaning "no value
selected".

Mode 1 records the mode and picks a tuning value out of a five-entry table of
signed 16-bit values, cycling through the table by taking the rotation counter
modulo five as an unsigned quantity. It then asks `func_8003F7B8` whether a
particular named resource is registered, identifying it by the four-character
tag "Test" packed into a word. If that lookup does not report a positive
result, the table value is discarded and a fixed fallback of 143 is stored
instead.

Mode 2 records the mode and copies a globally configured float into the tuning
float.

Mode 3 records the mode and stores the constant -2 into the tuning float.

Any other value of the first argument is ignored entirely — no global is
touched. Nothing is returned.

Note on the mode store: the recorded value is the argument itself, not a
literal per branch; the compiler keeps one copy of it in a scratch register
across all four branches, including the branch where it is provably zero.

## Status

Exact in USA, Japan, Europe and lrg_rev1.
