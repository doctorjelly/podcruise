# func_8000A330 — refresh every registered display item for one screen mode

## Boundary

* USA VRAM `0x8000A330` .. `0x8000A417` inclusive, ROM `0xAF30`, size 232 (0xE8).
* The body ends with the return instruction; its delay slot releases the stack
  frame.
* The two recorded direct call sites both target `0x8000A330`, the address of the
  prologue, and no executed instruction precedes it. The assigned boundary is
  correct.

## Callers

One distinct caller (recorded twice because two split listings overlap). The
caller reloads its own copy of the argument immediately after the call and never
reads a return value, so the function returns nothing.

## Callees

* `func_80009FA0` — takes an item pointer, a 32-bit selector mask and two 32-bit
  floating point scale factors.

## Globals and access widths

* `D_8009B774` — signed 32-bit count, read as a word and also cleared to zero.
* `D_800D3A90` — array of 32-bit pointers, indexed by the loop counter.

## Regional addresses

| version | vram | rom |

| usa | 0x8000A330 | 0xAF30 |
| japan | 0x8000A330 | 0xAF30 |
| europe | 0x8000A330 | 0xAF30 |
| lrg_rev1 | 0x8000A330 | 0xAF30 |

The function keeps its address in every build. Japan renames the count to
`D_8009C464` and the pointer array to `D_800D6CE0`; Europe renames them to
`D_800A0CC4` and `D_800DC730`. `func_80009FA0` keeps its address everywhere.

## Recovered behavior

The caller names one of three screen modes. The function first turns that mode
number into a selector mask: mode 2 selects bit 0, mode 1 selects bit 1, and
mode 3 selects bit 11. The tests are made in that order and stop at the first
match.

It then walks the registered display items from index zero while the index is
below the current registered count, handing each item pointer to the display
helper together with the selector mask and a horizontal and vertical scale of
one. The count is re-read from memory on every pass, so items removed or added
by the helper take effect immediately; a count of zero or below skips the walk.

Finally, if the caller asked for mode 3, the registered count is reset to zero,
emptying the list.

## Notes on shape

The selector mask is left unwritten when the mode is not 1, 2 or 3, and the
original build reads it in that state as well. The reconstruction reproduces
that faithfully rather than inventing an initial value, because any initialiser
would add a store the original does not contain. The mask must be declared after
the loop counter: the two occupy adjacent stack words and their order decides
which word the mask lands in.

## Status

Byte-exact in usa, japan, europe and lrg_rev1 under the accepted `ido53_o2`
profile. No per-unit compiler flags were required.
