## Recovered behavior

The routine raises a flag word and then counts a second word down by one, but
never below zero.

1. Store the value one into the flag word `D_800A3FF4`. This happens
   unconditionally and before the counter is examined.
2. Read the counter `D_800A3FF0` as a signed value. If it is greater than zero,
   write back the value one smaller. If it is zero or negative, leave it alone.

Nothing is returned. The clamping test is a signed "greater than zero" test, so
a counter that has somehow gone negative is not driven further down.
