# func_8000C5F0

## Boundary

- USA VRAM range `0x8000C5F0` .. `0x8000C657` (last instruction word begins at
  `0x8000C654`), ROM `0xD1F0` .. `0xD257`, size 104 bytes.
- Ends with the return at `0x8000C650` and its delay slot at `0x8000C654`, which
  performs the final store.
- Assigned boundary confirmed correct: straight-line code, no branches at all,
  nothing branches into the label, both callers target the entry.

## Recovered behaviour

This is the "push" half of a slot-switching pair. Given a new slot number it:

1. saves the live value back into the save-area entry belonging to the slot that
   is currently active, so that slot can be resumed later;
2. increases the stack depth by one and records the new slot number at that
   depth, so the switch can be unwound;
3. makes the new slot the current one;
4. loads the new slot's saved value into the live copy.

The stack depth is incremented before the push, so the entry at index zero is
never written by this routine. Neither the slot number nor the stack depth is
range checked, and nothing is returned.

## Status

Exact. USA, Japan, Europe and lrg_rev1 all verify byte-identical.
