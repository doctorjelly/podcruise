# func_8008CA80

## Boundary

- USA VRAM range: 0x8008CA80 .. 0x8008CA9C inclusive (0x20 = 32 bytes, 8
  instructions).
- USA ROM offset: 0x8D680.
- Terminates with a return whose delay slot is a no-operation; a second
  no-operation sits before the return as a hazard delay.
- Assigned size 32 was correct; no boundary correction.

## Callers and callees

- Twenty-three direct call sites in the USA build.
- Leaf: no callees.
- Takes no arguments; returns a 32-bit value.

## Globals and access widths

- None in memory. The routine reads and writes a processor control register
  (the system status register), not addressable storage.

## Regional addresses

| version  | VRAM       | ROM     |

Each regional body was read independently and is identical to the USA body.

## Recovered behavior

Masks interrupts and reports whether they had been enabled. It reads the
processor status register, clears the global interrupt-enable bit, writes the
register back, and returns the old value of that bit: non-zero if interrupts
had been on, zero if they had already been off. The caller keeps the returned
value and hands it back to the companion restore routine
(func_8008CAA0) to reopen the critical section it just closed.

## Status

Skipped. The body manipulates a coprocessor 0 control register. Those transfer
instructions have no C spelling, and the project rules forbid inline assembly,
so this function cannot be produced from C source and must stay in assembly.
The generated disassembly independently flags both transfer instructions as
handwritten.
