# func_80064034

## Boundary and interface

The canonical USA routine spans ROM `0x64C34` / VRAM `0x80064034` through
the `nop` return delay slot at VRAM `0x80064A44`, for `0xA14` (2,580) bytes.
The three instructions before the former `func_80064040` label load
`D_8011A244`; both that value and the address in `v0` remain live across the
label. Consequently `func_80064040` is an interior false split and the next
function begins at `0x80064A48`. The single direct caller, `func_8004A880`,
passes a signed selection word.

## Calls and data contracts

The routine uses the recovered vector, matrix, object-transform, recursive
node-update, texture-scroll, random-number and resource lookup helpers. Its
primary `Elmo` resource has a node table at offset `0x30`; the routine uses
entries 0, 2, 4, 5, 6, 7 and 8. A second `Elmo` resource, index 28, has the
same table field and a scale at offset `0x94`.

The four consecutive words at `D_8011A240` are a floating transition value,
two enable words and another floating transition value. `D_800A5B3C` caches
the caller's initial selection, `D_800A5B40` holds a wrapped angle, and
`D_80120BF8` is the per-frame increment. Four vectors at `D_8011C800` through
`D_8011C830` supply node positions. The remaining addressed globals are three
lighting vectors and three effect constants.

## Recovered behavior

Construct three lighting vectors from fixed endpoint values, the difference
between two global positions, and the first transition value, then publish
them as the current light. Look up the primary resource. On first use, cache
the supplied selection and capture four node positions. Advance its rotation
by nine times the frame increment, wrapping at 360 degrees and forcing zero
while the transition is zero.

For node-table entries 2 and 8, build a rotating transform whose scale changes
over the two halves of the transition, place the node at its captured position,
and apply it. Give each active node a small random recursive effect value,
advance the first texture-like leaf by its corresponding scroll constant, and
toggle its visibility bits according to whether the transition is positive.

When the second enable word is set, move entry 5 into place along a 117-unit
path and apply the same effect/visibility treatment to entry 6. Use entries 5
and 0 to derive a world-space transform for resource 28, then position, scale
and rotate that resource. Independently move entry 4 along the same path using
the fourth global transition value and apply the effect treatment to entry 7.

## Regional evidence

The merged prefix/body shape relocates to Japan `0x80064BA4` and Europe
`0x80069514`. Those builds support the boundary and shared structure only;
USA remains the canonical compiler target.

## Status

Behavior-recovered C. Exact IDO 5.3 `-O2 -mips2` comparison places the source
at the canonical address and emits 2,476 bytes versus the original 2,580; the
first instruction differs. It is not eligible for hybrid-build substitution
and no byte match is claimed.
