# func_800636D0

## Boundary
USA VRAM 0x800636D0-0x8006373B (0x6C = 108 bytes), ROM 0x642D0.
Standard 0x18-byte frame; the return link is saved and restored, the epilogue is
a return whose delay slot is empty. The preceding function ends with its own
return at 0x800636C8 and none of its branches reach past it, so the label is a
real entry. Five direct call sites.

## Callers / callees
Called from five sites. Calls `func_80015470` (the recovered three-component
distance helper) once.

## Object layout touched
The single parameter is a pointer to a record with:

| offset | width | use |
| ------ | ----- | --- |
| 0x08   | s32   | a mode/kind tag compared against 2 |
| 0x44   | 3 x f32 | reference point (third component read at 0x4C) |
| 0x50   | 3 x f32 | probe point (third component written at 0x58) |
| 0xA0   | s32   | result flag written on every call |

## Globals
None.

## Regional addresses
- JP 0x80064240, ROM 0x64E40; helper relocated to 0x800155A0.
- EU 0x80068BB0, ROM 0x697B0; helper relocated to 0x80015900.
- lrg_rev1 shares the USA addresses.
All three regional bodies were read and are instruction-for-instruction the same
shape as USA apart from the relocated call target.

## Recovered behavior
When the record's mode tag equals 2 the probe point's third component is forced
to equal the reference point's third component, which makes the following
measurement effectively planar for that mode. The straight-line distance between
the probe point and the reference point is then measured. A flag is set to one
when that distance is at most ten units and to zero otherwise; the flag is
stored back into the record at offset 0xA0 and also returned.

## Notes on shape
The zero initialisation of the flag has to happen *after* the distance call. If
the flag is initialised at its declaration it becomes live across the call, IDO
spills it and the frame grows by eight bytes. Naming the distance in a local and
then assigning the flag reproduces the original exactly.
