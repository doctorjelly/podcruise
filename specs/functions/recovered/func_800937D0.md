# func_800937D0

## Boundary
VRAM 0x800937D0, 80 bytes, ROM 0x943D0. Ends with the standard return and an
empty delay slot. 2 callers, both targeting the entry. Boundary as assigned is
correct.

## Callers / callees
2 callers. Calls func_800880E0 then func_8008C930.

## Globals
- D_800A7FB0 - word, written with the value 1.
- D_8014C4D0 - a data block whose address is taken.
- D_8014C4D8 - a data block whose address is taken.

## Regional addresses
None assigned for Japan or Europe. lrg_rev1 shares the USA addresses and the
body is identical there.

## Behavior
A parameterless initialiser for one subsystem. It raises the subsystem's
enabled flag to one, then asks the setup routine to prepare the first data
block from the second, with its mode selector set to one. Immediately after, it
resets the first block through the reset routine with both of that routine's
remaining parameters at zero. Nothing is returned.

## Status
exact (USA and lrg_rev1), default -O2 profile.
