# func_8008A360

## Boundary
VRAM 0x8008A360-0x8008A3B0 (80 bytes), ROM 0x8AF60. Ends with the standard
return and an empty delay slot; the next label begins a separate body.
2 callers, both targeting the entry. Boundary as assigned is correct.

## Callers / callees
2 callers. Calls func_8008CA80 (returns a value) and func_8008CAA0 (consumes it).

## Globals
D_800A7F54 - a word-wide pointer to a record. Field at offset 0 is accessed as
an unsigned halfword; field at offset 4 is written as a word.

## Regional addresses
- jp: 0x8008B050 (ROM 0x8BC50), global D_800AADA4, callees func_8008D770 / func_8008D790
- eu: 0x8008F8B0 (ROM 0x904B0), global D_800AD254, callees func_80091FD0 / func_80091FF0
- lrg_rev1: identical to USA

## Behavior
Takes one pointer argument. It first opens a scoped section by calling the
acquire routine and keeping the token it returns. While that section is open it
publishes the argument into the record referenced by the module pointer, storing
it in the record's second word, and then sets a flag bit (value 0x10) in the
record's leading halfword, leaving the other bits of that halfword alone. The
module pointer is re-read for each of those two accesses. Finally it closes the
section by passing the saved token to the release routine. Nothing is returned.

## Status
exact (USA, Japan, Europe, lrg_rev1). This translation unit is built at -O1:
every value lives in a stack slot and is reloaded rather than forwarded, and
the module pointer is not common-subexpressioned. Under -O2 the body is four
bytes short and diverges from the third instruction.
