# func_80004670

## Boundary
VRAM 0x80004670-0x80004704, ROM 0x5270, 148 bytes. Ends with the return
instruction followed by an empty delay slot. Two direct callers target the
entry; no branch from the preceding body enters this range.

## Callers / callees
2 callers. Calls func_80004000, func_80003E4C, func_80004160.

## Globals
None.

## Regional addresses
jp 0x80004670 (ROM 0x5270), eu 0x80004670 (ROM 0x5270), lrg_rev1 0x80004670.
All three bodies are instruction-for-instruction the same as USA and use the
same callee addresses.

## Arguments
Nine parameters: a pointer, a second pointer, three integers, one 32-bit float
in the sixth position, and three further integers. All nine arrive through the
standard argument registers and the caller's outgoing area; the first four are
written back into their home slots on entry and reloaded for each call, which
is why the float argument is read from the caller's frame each time it is used.

## Recovered behavior
If the first pointer is null the routine does nothing and reports zero.
Otherwise it performs three steps in order:

1. a five-argument setup call taking the second pointer, the three following
   integers and the float;
2. a three-argument call taking both pointers and a zero;
3. a final eight-argument call taking the second pointer, the same three
   integers, the float and the last three integers.

The value produced by the final call is the routine's own result.

## Status
exact (USA, Japan, Europe, lrg_rev1).
