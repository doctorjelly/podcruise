# func_80015538 — cross product of two 3-component vectors

## Boundary

- USA VRAM range: `0x80015538` .. `0x800155BC` inclusive, 136 bytes
  (34 instructions).
- ROM offset `0x16138`.
- Ends with a return whose delay slot holds the store of the third output
  component, so the last write to the destination happens as the function
  returns.
- The preceding function ends with its own return plus delay slot immediately
  before this entry and the direct call sites target `0x80015538`. Assigned
  boundary confirmed correct.

## Callers and callees

- 114 direct call sites — one of the most heavily used maths helpers in the
  build.
- No callees; leaf function with a 16-byte frame.

## Globals and access widths

- None. Three pointer arguments: destination, left operand, right operand. All
  vector components are 32-bit floats read and written with 32-bit float
  accesses.
- One 12-byte local (three floats) at the top of the frame holds the result
  before it is copied out, which is what makes the routine safe when the
  destination aliases either input. As with the distance routine, the local has
  to be an array so that the compiler keeps it in memory.

## Regional addresses

- Japan: `0x80015668`, ROM `0x016268`, 136 bytes, body identical word for word.
- Europe: `0x800159C8`, ROM `0x0165C8`, 136 bytes, body identical word for word.
- Both read independently from the regional disassembly before probing.

## Recovered behaviour

Computes the vector cross product of the second and third arguments and stores
it through the first.

Each output component is the usual difference of two products, evaluated with
the left operand's component first in every product: the first component is the
left vector's y times the right vector's z minus the right vector's y times the
left vector's z, and the other two components follow by cyclic rotation
(z·x − x·z, then x·y − y·x). All three components are computed into the local
first and only then copied to the destination, so the destination may safely be
the same object as either input.

## Status

Exact. USA, Japan and Europe all verified byte-identical at their canonical
addresses.
