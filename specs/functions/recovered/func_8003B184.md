# func_8003B184

## Boundary
* USA VRAM 0x8003B184 - 0x8003B1EF (108 bytes, 27 instructions), ROM 0x3BD84.
* Frame of 0x48 bytes; the return address is saved at the usual slot and the
  function ends with a return followed by an empty delay slot.
* Twenty-two direct callers target 0x8003B184; three of them were read and all
  pass a pointer, a second pointer, and a float constant. Boundary confirmed,
  not corrected.

## Callers / callees
* Callers: 22.
* Callees: `func_8003B02C`, called once with the address of the local copy and
  the second argument passed straight through.

## Parameters
1. pointer to a 48-byte descriptor (three 16-byte rows, copied as one object);
2. pointer, forwarded unchanged to the callee;
3. single-precision float (it arrives in the third integer argument register and
   is moved into the floating-point unit, the usual signature of an `f32` in
   slot three).

Fields of the descriptor that are modified in the copy:

| offset | width | use |
| ------ | ----- | --- |
| 0x04   | f32   | cleared to 0.0 |
| 0x08   | f32   | increased by argument 3 |

The remaining 40 bytes are copied verbatim. No file-scope globals are used.

All four bodies were read independently and are the same instruction sequence

## Recovered behaviour
The function is a thin wrapper that runs the heavy worker on a modified copy of
a caller-owned descriptor, leaving the caller's descriptor untouched. It takes a
whole-object copy of the 48-byte descriptor into a local, zeroes the second
scalar of the copy, adds the caller-supplied offset to the third scalar, and then
hands the adjusted copy plus the caller's second argument to the worker. Nothing
is returned.

Note on shape: the copy is a single structure assignment, not an element loop.
The original expansion moves three words per pass through the assembler-reserved
temporary, which is the compiler's block-move idiom.

Note on statement order: the increment of the third scalar must be written
before the clearing of the second. Both orders produce the same instructions but
the reverse order permutes three floating-point temporaries, which is a
four-instruction mismatch.

## Status
Exact. USA, Japan, Europe and lrg_rev1 all verified byte-identical under the
accepted `ido53_o2` profile.
