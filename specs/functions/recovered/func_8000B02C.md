# func_8000B02C

## Boundary

- USA VRAM range `0x8000B02C` .. `0x8000B06B` (last instruction word begins at
  `0x8000B068`), ROM `0xBC2C` .. `0xBC6B`, size 64 bytes.
- The routine ends with the return at `0x8000B064` followed by its delay slot at
  `0x8000B068`, which performs the second of the two stores.
- Assigned boundary confirmed correct: no external branch enters the label and
  no internal branch leaves the range.

## Callers

Four distinct direct call sites: `0x8003129C`, `0x8004DAC4`, `0x8005E5A4` and
`0x8005E600` (the inventory counts six because two of them appear in overlapping
generated section files). All target the entry address.

## Callees

None; leaf routine, no stack frame.

## Globals and access widths

- `D_8009B790` — the same 32-bit pointer slot to an array of 124-byte records
  used by `func_8000AF4C`. It is re-read before the second store for the same
  aliasing reason.
- Record fields written: a 16-bit value at record offset `0x0C`, and a 32-bit
  value at record offset `0x10`.

## Recovered behaviour

The routine takes a signed 16-bit record selector, a 32-bit word, and a signed
16-bit value. It writes the 16-bit value into the halfword field 0x0C bytes into
the selected record, then writes the 32-bit word into the word field 0x10 bytes
into the same record. The two fields are written in that order, the record index
is not validated, and nothing is returned.

## Status

Exact. USA, Japan, Europe and lrg_rev1 all verify byte-identical.
