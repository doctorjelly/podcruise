# func_80010040 — clear the single-word state flag

## Boundary

- USA VRAM range `0x80010040` .. `0x8001004B` inclusive; size 12 bytes
  (3 instructions).
- The body is an address materialisation followed by the standard return
  instruction whose delay slot performs the store; the store is therefore part
  of this function and not a stray tail.
- `func_80010014` returns before this label and the single direct call site
  targets `0x80010040`, so the assigned boundary is correct.

## Callers

One direct call site in the USA build, at `0x80086614`, immediately after a
call to `func_8000FEF0`. No arguments, no return value.

## Callees

None; leaf function, no stack frame.

## Globals and access widths

| symbol | role | width |
| --- | --- | --- |
| `D_8009B86C` | single word of module state | 32-bit store |

## Regional addresses

| version | entry | ROM |
| --- | --- | --- |
| USA | `0x80010040` | `0x10C40` |
| Japan | `0x80010040` | `0x10C40` |
| Europe | `0x800104A0` | `0x110A0` |
| `lrg_rev1` | `0x80010040` | `0x10C40` |

Regional data symbol (USA / Japan / Europe): `D_8009B86C` / `D_8009C55C` /
`D_800A0DBC`. The Europe entry point was not listed in the assignment; it was
located and confirmed by reading the Europe body at `0x800104A0`, which is the
same three-instruction shape with the Europe data address.

## Recovered behaviour

Writes zero to one word of module state and returns. Because the call site
pairs it with the table reset, this is the "count/index back to empty" half of
that reset.

## Status

Exact. Byte-identical in USA, Japan, Europe and `lrg_rev1`.
