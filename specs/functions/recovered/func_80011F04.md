# func_80011F04 — set the four-channel colour and invalidate its cache

## Boundary
- USA VRAM `0x80011F04` .. `0x80011F37` inclusive; ROM `0x12B04`; size 52 bytes
  (13 instructions).
- Terminates with a return whose delay slot clears the cache flag.
- The entry is the first instruction of its generated section, so nothing
  precedes it; all 21 direct call sites target `0x80011F04`. No branch enters
  the range. Boundary confirmed as assigned.

## Callers
Twenty-one direct call sites across several modules. The sampled sites show
three distinct argument sources: bytes loaded zero-extended out of a table, an
immediate constant 255, and floating-point results converted to integer and
then narrowed to signed 16 bits. Because the sites that start from a full-width
integer emit an explicit signed 16-bit narrowing while the byte-sourced site
emits none, the four parameters are signed 16-bit integers, not bytes and not
unsigned.

## Callees
None. Leaf function, no stack frame; each of the four argument home slots is
written once on entry, the compiler's normal handling of narrower-than-word
parameters, and none is read back.

## Recovered behaviour
The routine stores four supplied component values into a four-byte colour
record, one component per byte in argument order, truncating each signed 16-bit
argument to its low byte. It then clears a word-sized companion flag, which
marks any value derived from the previous colour as stale so that it will be
recomputed on next use. It takes no other input and returns nothing.
