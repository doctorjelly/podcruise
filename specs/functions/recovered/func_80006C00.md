# func_80006C00

## Verified facts

- The USA body spans VRAM `0x80006C00` through `0x80006D5B`, ROM `0x7800`,
  348 bytes. `jr ra` is at `0x80006D54`; its delay slot restores the 0x30-byte
  stack frame.
- `func_8002F750` calls it directly. It reads the current count
  `D_8009A2A0` and pointer table `D_800AF4C0`, and calls `func_80006848`,
  `func_8000646C`, `func_8000651C`, `func_8000630C`, `func_80006120`, and
  `func_80006200`.
- The jump table maps low-nibble values 2, 8, 9, 10, 11, and 12 to those
  handlers respectively; all other values have no type-specific call.
- Japan and Europe contain structurally identical equivalents at
  `0x80006C00`.

## Behavior

Walk the current global entry table. For each non-null entry that is active and
not suppressed according to its word at offset `0x100`, advance its shared
state and dispatch its low-nibble type. Types 11 and 12 use the same handler
with mode zero and one respectively. Re-read the global count as the loop runs,
so changes made by handlers affect the stopping point.

## Status

Behavior recovered from the USA binary and independently expressed in C; not
byte-matching. IDO 5.3 `-O2` emits 324 bytes for the 348-byte target and first
differs at byte `0x3`.
