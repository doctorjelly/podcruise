# func_800896D0 — post a "kind 4" request carrying one float

## Boundary

* USA VRAM `0x800896D0`–`0x80089723`, ROM `0x8A2D0`, 84 bytes.
* Frame is 0x30 bytes: 0x10 of outgoing argument space, the saved return
  address, an eight-byte slot for the pointer local, and the 16-byte request
  record at the top of the frame. Ends with the standard return sequence and an
  empty delay slot.
* Two padding words separate the previous function's return from this entry,
  and both direct callers target this entry. Boundary as assigned is correct.

## Callers

Two direct call sites in USA, in the same routine near `0x8000838x` and
`0x8000844x`. Both move a computed single-precision value into the second
argument register and load the owner pointer from a table entry, which
confirms that the second parameter is a float, not an integer.

## Callees

* `func_8008FC3C` — the request poster. It masks interrupts, takes a free node
  from the owner's queue, copies exactly 16 bytes from the request record into
  the node, records a deadline, links the node and wakes the consumer.

## Globals

None referenced directly.

## Access widths

* Owner offset 0x14: the start of the queue structure, passed by address.
* Owner offset 0x3C: 32-bit signed index.
* Owner offset 0x40: 32-bit pointer to an array of 48-byte entries.
* Request record offset 0x00: 16-bit request kind (the constant 4).
* Request record offset 0x04: 32-bit entry pointer.
* Request record offset 0x08: 32-bit float payload.
* Request record offsets 0x02 and 0x0C are not written here; the record is
  copied wholesale by the callee, so they carry whatever the stack held.

## Recovered behavior

The routine is a thin front end that turns "do operation 4 on the owner's
currently selected entry, with this float parameter" into a queued request. It
reads the owner's entry array base and its selected index, forms a pointer to
that entry, and fills a small request record on the stack with the request kind
4, that entry pointer, and the caller's float. It then posts the record to the
owner's request queue with a zero deadline and returns nothing. Two sibling
routines in the same file build the identical record with kinds 1, 3 and 8 and
differently typed payloads, which is what pins the record layout.

## Status

Exact in USA, Japan, Europe and lrg_rev1 under the accepted IDO 5.3 -O2
profile.
