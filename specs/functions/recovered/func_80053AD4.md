# func_80053AD4

## Verified facts

- The canonical USA body spans ROM `0x546D4` / VRAM `0x80053AD4` through
  `0x80053C07`, for `0x134` (308) bytes. The `jr ra` at `0x80053C00` restores
  the `0x280`-byte stack frame in its delay slot; `func_80053C08` begins next.
- `func_80054048` calls it directly with a race/state pointer and one racer-like
  record. The four callees are `func_8003B184`, `func_80017BA8`,
  `func_800181BC`, and `func_8000EA4C`.
- The routine reads three float constants at `D_800ACE94`, `D_800ACE98`, and
  `D_800ACE9C`. It reads a pointer at second-argument offset `0x84`, then uses
  the pointed record at offset `0xAC`; it uses first-argument pointer slots
  four through nine.
- The LRG USA revision has the same body and addresses. The structurally
  equivalent Japan body is at `0x8005475C` and the Europe body at `0x80058784`;
  both have the same `0x134`-byte boundary and stack-restore delay slot, with
  relocated constants and callees.

## Behavior

The function builds seven temporary 4-by-4 float matrices from a shared source
record. It starts at one global angle, advances by the first step for the first
two iterations, and by the second step thereafter. It applies the first six
matrices to pointer slots four through nine of the destination record. For each
non-null slot it calls one helper with fixed parameters `(2, 3, 0x10, 2)`, then
calls a second helper for every slot with `(-1, -1, 0, 0xFF, 0, -1)`.

## Status

Independently expressed C is byte-matching for canonical USA and the LRG USA
revision. IDO 5.3 `-O2`, MIPS II, with `-Wab,-r4300_mul` emits all 308 bytes
exactly in each build. Japan and Europe are structural evidence only and are
not claimed as C matches here.
