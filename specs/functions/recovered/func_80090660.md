# func_80090660

## Boundary
USA VRAM 0x80090660-0x800906E3 (132 bytes), ROM 0x91260. Ends with a return
whose delay slot carries the final addition of the result's high word. One
direct caller. Boundary as assigned is correct.

## Callees
func_8008CA80 (no arguments, returns a token), func_8008C550 (no arguments,
returns a 32-bit counter), func_8008CAA0 (one argument, the token).

## Globals
- D_8014C510: a 64-bit accumulator (high word at 0x8014C510, low word at
  0x8014C514).
- D_8014C518: a 32-bit reference counter value.

## Regional addresses
Japan 0x80091350 (ROM 0x091F50); Europe 0x80095BB0 (ROM 0x0967B0). Not probed
for integration. LRG rev1 uses the USA address and is byte-identical for this
body.

## Behavior
The routine reports a 64-bit running time. It enters a critical section by
taking a token from one routine and releasing it with the matching routine at
the end.

Inside the section it samples a free-running 32-bit counter and subtracts the
stored reference sample, giving the number of counter units elapsed since the
accumulator was last folded. It reads the 64-bit accumulator, leaves the
critical section, and returns the accumulator plus the zero-extended elapsed
count. The 32-bit difference wraps naturally, and the addition carries into the
high word.

## Status
Behavior recovered and byte-matching. The independently expressed C compiles
with IDO 5.3 `-O1` to the exact 132 USA bytes and also matches LRG rev1. A
32-bit register-qualified critical-section token, a 32-bit elapsed delta, and
the recovered local ordering reproduce the original frame, saved register,
call sequence, and final carry in the return delay slot.
