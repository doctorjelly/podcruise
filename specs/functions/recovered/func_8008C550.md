# func_8008C550

## Boundary

- USA VRAM `0x8008C550` .. `0x8008C55B` (12 bytes, 3 instructions), ROM `0x8D150`.
- Terminates with `jr $ra` and an empty delay slot.
- Six direct `jal` sites target the entry; the label is a genuine boundary.
  Boundary as assigned is correct.

## Recovered behavior

Takes no arguments and returns the current value of the processor's free-running
cycle counter as a 32-bit unsigned quantity. The counter is a system coprocessor
register that increments continuously at half the CPU clock rate and wraps
around; the routine simply samples it and returns, touching no memory and no
other state. Callers use it as a monotonic timestamp source for elapsed-time
measurement.

## Access widths

No memory is accessed. The single value read is a 32-bit system control
register.

## Status

Skipped - not expressible in C.

The body is a move-from-system-control-register instruction followed by the
return. No C construct compiles to a coprocessor-0 register read, and the
project forbids inline assembly, so this routine has to stay as an assembly unit
(it is the standard hand-written cycle-counter accessor). No `.c` file was
produced. The three instructions are identical in all four builds.
