# func_800884E8

## Boundary

- USA VRAM range: 0x800884E8 .. 0x800884FF inclusive (0x18 = 24 bytes, 6 instructions).
- USA ROM offset: 0x890E8.
- Terminates with a return whose delay slot performs the second of the two
  stores, so that store belongs to the function.
- No frame is allocated; leaf function.
- Assigned size 24 was correct; no boundary correction.

## Callers and callees

- One direct call site in the USA build, at 0x8008F8B8, on the path that
  finishes with a queued audio-buffer descriptor and hands it back.
- No callees (leaf function).

## Globals and access widths

- `D_800A6990` — a 32-bit pointer word holding the address of the audio
  manager block. It is read once, as a word.
- Offset 0x2C of that block is a 32-bit pointer: the head of a singly linked
  free list.
- Offset 0x00 of the passed-in node is the 32-bit link field of that list.

## Regional addresses

The body is instruction-for-instruction identical in every version; only the
manager pointer relocates.

| version  | VRAM       | ROM     | manager pointer |
|----------|------------|---------|-----------------|
| us       | 0x800884E8 | 0x890E8 | D_800A6990      |
| jp       | 0x800891D8 | 0x89DD8 | D_800A97E0      |
| eu       | 0x8008DA38 | 0x8E638 | D_800ABC90      |
| lrg_rev1 | 0x800884E8 | 0x890E8 | D_800A6990      |

## Recovered behavior

Returns one node to the manager's free list. The node's link field is set to
whatever the list head currently holds, and the list head is then set to the
node, so the node becomes the new head and the previous chain hangs off it.
This is an unconditional push; the caller is responsible for not passing a null
node. Nothing is returned.

The manager pointer is fetched into a local before either access. This matters:
storing through the caller's node could in principle change the pointer word
itself, so reading the global twice in the source makes the compiler compute
the address once and issue two separate loads, adding two instructions. Caching
the pointer first reproduces the single fused load the original uses.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
