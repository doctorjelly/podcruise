## Behavior

The routine builds a display list for every node in a scene. It derives and
emits geometry modes from item flags, allocates auxiliary render slots when
needed, resolves material parameters and texture bindings, calls each node's
display list, terminates the generated list, and restores the caller's display
list cursor.
