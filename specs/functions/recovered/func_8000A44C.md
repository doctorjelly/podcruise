## Globals and access widths

- `D_8009B770` — a single 32-bit signed counter. Read as a word and, on one
  path, written back as a word. Its address is materialised once and reused for
  both the read and the write.
- `D_800D2190` — base of an array of 32-byte records. The record reached is
  selected by scaling the first parameter by 32. Fields touched by this
  function: two 16-bit fields at record offsets `0x00` and `0x02`, three 32-bit
  floating point fields at `0x08`, `0x0C` and `0x10`, one 32-bit integer field
  at `0x14`, four independent byte fields at `0x18`, `0x19`, `0x1A` and `0x1B`,
  and one 32-bit word at `0x1C`.

## Recovered behaviour

The routine resets one record of a fixed-capacity table to its default state and
attaches a caller-supplied 32-bit value to it.

Parameters: a 16-bit signed record index, and a 32-bit value stored verbatim.

1. If the index is 200 or greater the routine does nothing at all and returns.
   The table therefore has a hard capacity of 200 records. Negative indices are
   not rejected here, unlike the sibling setters in this group.
2. A high-water mark held in the shared counter is advanced: if the index is not
   below the current mark, the mark becomes the index plus one. The counter thus
   tracks "one past the highest record index ever initialised", and is only ever
   raised, never lowered.
3. The selected record is then initialised:
   - the two 16-bit fields at the start of the record are cleared to zero;
   - the first two floating point fields become 1.0 and the third becomes 0.0
     (a unit scale pair plus a zero angle or offset);
   - the 32-bit integer field at offset `0x14` becomes 1, which is the flag word
     the neighbouring routines in this file set and clear individual bits in;
   - the four bytes at offsets `0x18`..`0x1B` are each set to 255, i.e. a fully
     opaque white colour quadruple;
   - the 32-bit word at offset `0x1C` receives the second parameter unchanged.

The routine returns nothing.
