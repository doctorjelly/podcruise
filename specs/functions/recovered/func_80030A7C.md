# func_80030A7C

instructions). The body ends with the return instruction at 0x80030B60 and an
empty delay slot at 0x80030B64; the next label begins a new function. Five
direct call sites target 0x80030A7C, so the entry is confirmed. No branch from
the preceding function reaches into this range. Boundary as assigned: correct.

No caller consumes a return value, so the function returns nothing.

## Recovered behavior

The function walks two parallel word streams in step: a destination stream
supplied as the first argument, and an override stream supplied as the second.

1. Overlay pass. While the destination word is not the all-ones sentinel, a
   non-zero override word replaces the destination word; a zero override word
   leaves the destination alone. Both cursors advance one word per step. When
   the sentinel is reached, both cursors step past it.
2. Optional bulk-data block. If the destination word now spells the four
   characters "Data", the following word is a signed element count; the cursor
   skips the tag word, the count word, and then that many further words. A
   count of zero or less skips only the tag and count.
3. Optional variable-length block. If the destination word now spells "Anim",
   the cursor advances until it has passed a zero terminator word.
4. Pointer patch pass. If both streams now spell "AltN" at their current
   position, both cursors step past that tag and the routine then treats each
   remaining destination word as an address: for every non-zero destination
   word it stores the corresponding override word at that address, advancing
   both cursors, and stops at the first zero destination word.

Any of steps 2 through 4 that does not see its tag is skipped, and step 4 is
also skipped when the override stream does not carry the matching tag.

Exact on USA, Japan, Europe and lrg_rev1 with the accepted ido53_o2 profile.
