# func_80034650

## Boundary

USA VRAM 0x80034650..0x800347D7 (392 bytes, ROM 0x35250). The body ends with the
return whose delay slot releases the 0x38-byte frame, after restoring the two
saved floating-point registers. Nine direct call sites target 0x80034650 and the
preceding function ends with its own return, so the assigned boundary is
correct. The function is a leaf.

## Callers

Nine direct call sites. In each of them the first argument is the pointer just
returned by the scratch allocator `func_80033E08` and the second is a pointer to
a block of floats belonging to the object being drawn, so the function fills a
freshly allocated buffer from a float matrix.

## Callees

None.

## Globals and access widths

- `D_800AAAD8` - one 32-bit float, read only. A small negative threshold.
- `D_800AAADC` - one 32-bit float, read only. A small positive threshold.
- `D_800D6960` - a block whose base address is materialised once and read with a
  fixed displacement of 0x1C, i.e. the eighth 32-bit word. Only bit 0x4000 of it
  is tested.

## Recovered behaviour

Convert a four-row by three-column matrix of floats into the console's
fixed-point four by four matrix format, which stores the sixteen integer halves
of the entries first and the sixteen fractional halves immediately afterwards.

The output is produced entry by entry, walking the four rows and, within each
row, four columns.

For the first three columns the corresponding source float is taken. The first
column of every row is additionally negated when a particular flag bit is set in
the shared state block - this is the mirrored-view case. The value is then
clamped: anything above thirty-two thousand becomes exactly thirty-two thousand,
anything below minus thirty-two thousand becomes exactly minus thirty-two
thousand, and anything inside the small dead band described by the two threshold
globals collapses to zero, so that near-zero noise does not survive the
conversion. The clamped value is scaled by sixty-five thousand five hundred
thirty-six and truncated toward zero, giving a sixteen-dot-sixteen fixed-point
word.

The fourth column is not read from the source at all: it is the homogeneous
column, so it is zero for the first three rows and exactly one (in fixed point)
for the last row.

Each resulting fixed-point word is then split, its upper half being appended to
the integer part of the output and its lower half to the fractional part.

## Status

Byte-matching C. IDO 5.3 with the recorded `-O2` profile reproduces all 392
text bytes exactly for USA retail and the USA LRG revision when the unit's
constant pool begins at `0x800AAAD0`. The first eight bytes model the adjacent
literal pair in the original translation unit, placing this function's two
thresholds at `0x800AAAD8` and `0x800AAADC`. Existing targeted comparisons also
reproduce the relocated Japan and Europe bodies exactly.
