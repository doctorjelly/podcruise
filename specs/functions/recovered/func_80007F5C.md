# func_80007F5C

## Boundary
USA VRAM 0x80007F5C-0x80007FC7 (0x6C = 108 bytes), ROM 0x8B5C.
0x18-byte frame; the body ends with a return whose delay slot restores the stack
pointer. The preceding function returns at 0x80007F54 and does not branch past
it. One direct call site.

## Callers / callees
One caller. Calls `func_80007CE4` once, passing the incoming handle unchanged.

## Object layout touched
`func_80007CE4` yields a pointer (its own recovered body returns what is really a
pointer-valued table entry). From it the chain is:

| step | offset | width |
| ---- | ------ | ----- |
| owner            | 0x0C | pointer to slot table |
| slot table       | 0x10 + 4*index | pointer to slot |
| slot             | 0x08 | pointer to sample |
| sample           | 0x04 | s32 count |

## Globals
`D_800A81C8` - f32, read once as the scale factor.

## Regional addresses
- JP 0x80007F5C, ROM 0x8B5C; the scale factor moves to 0x800AB018.
- EU 0x80007F5C, ROM 0x8B5C; the scale factor moves to 0x800AD4C8.
- lrg_rev1 shares the USA addresses and the USA global address.
Both regional bodies were read and differ from USA only in the global's address.

## Recovered behavior
The handle is resolved to its owning record. The low fifteen bits of the handle
select an entry inside the owner's slot table; that entry leads to a sample
record holding a signed count. The count is converted to floating point and
scaled by the global factor, and the product is returned. When the handle does
not resolve to a record the function returns zero.

## Notes on shape
Two shape facts were needed. First, the masking of the handle has to be written
as an assignment back to the parameter; written into a fresh local, IDO sinks the
mask into the non-null arm and the body loses four bytes. Second, the signed
count must be pulled into a named local before the conversion, which is what puts
it in the register the original uses.

## Status
exact - USA, JP, EU and lrg_rev1 all verified byte-identical.
