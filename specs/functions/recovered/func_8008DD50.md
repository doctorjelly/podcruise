# func_8008DD50

## Boundary and references

- USA VRAM `0x8008DD50` through `0x8008DD7F`, ROM `0x8E950`, 48 bytes.
- The return at `0x8008DD78` places the constant zero in its delay slot. The
  next prologue begins at `0x8008DD80`.
- Direct USA calls occur at `0x80088930` and `0x8008DD20`. Its address is also
  registered as a three-argument callback by `func_8008D554`.
- It is a leaf, accesses no globals, and reads or writes only its first
  argument. LRG retains the USA body; regional relocations were not needed.

## Behavior

The first argument owns a current index at offset `0x14` and a pointer table at
offset `0x1C`. When the mode is two, the function stores the third argument in
the table's current slot and increments the index. Other modes make no change.
It always returns zero.

Loading the table pointer before testing the mode is behaviorally redundant,
but independently expresses the source lifetime needed to reproduce the
original branch delay slot.

## Status

Byte-matching C. IDO 5.3 with `ido53_o2` reproduces all 48 bytes exactly for
USA retail and the LRG USA revision.
