## Verified facts

USA occupies VRAM `0x8007C818` through `0x8007CC47`, ROM `0x07D418`
through `0x07D847`, for 1,072 bytes. The return is at `0x8007CC40`; its
delay slot restores the 184-byte stack frame. The next established entry is
`0x8007CC48`, so the return delay slot belongs to this function.

Four direct callers target the entry, at `0x8007CE20`, `0x8007CEB0`,
`0x8007D034`, and `0x8007D0B0`. Each supplies the second pointer in the call
delay slot. The body directly calls `func_80008BC4`, `func_80017520`,
`func_80017B7C`, `func_80017BA8`, `func_800181BC`, `func_8003F99C`,
`func_8007B430`, `func_8007B6CC`, `func_80081700`, and `func_80082BE0`; it
contains no indirect call.

The only address-based globals are the pointer table `D_8011C910` and the
double constant `D_80120BF0`. Two file-local double literals are addressed at
`0x800ADB68` and `0x800ADB70`. The object pool begins eight bytes earlier at
`0x800ADB60`, accounting for the preceding file-local constant represented by

Japan has the corresponding 1,072-byte body at VRAM `0x8007D4B8`, ROM

the return and stack-restore delay slot occur at the same relative offsets and

## Behavioral specification

Configure an effect record from an actor and a type code. Selected type codes
scale one actor field and send a tagged notice with a type-specific magnitude.
The routine enables the record, creates or positions the indexed effect object,
emits an auxiliary effect request, derives a three-component displacement from
the actor's current and reference positions, and stores the effect position,
velocity, attachment, handle, and zeroed timer back into the record. Type
`0x66` with actor flag `0x80` uses a matrix placement and suppresses the normal
attachment; other paths use direct position placement.

The subsystem descriptions above are inferences from the data flow and call
patterns. The field offsets, constants, branches, calls, and writes are facts
from the binary.
