# func_8000D818

## Boundary
USA VRAM 0x8000D818-0x8000D89C, ROM 0xE418, size 132 bytes. Ends with the
return instruction followed by an empty delay slot. Boundary confirmed correct.

## Callers / callees
One caller. Calls func_8002F144 (no arguments) and func_8000C5F0 (one integer
argument).

## Globals
D_8009B7E4 — 32-bit word, written only.

## Regional addresses
- jp 0x8000D818 (ROM 0x00E418), globals/callees relocated
  (D_8009C4D4, func_8002FBA4)
- eu 0x8000D8AC (ROM 0x00E4AC), (D_800A0D34, func_800326E4)
- lrg_rev1 shares the USA addresses.

## Behavior
Takes one integer selector. For selector 0 it records mode 0 in the global word
and runs the shared reconfiguration routine. For selector 2 it records mode 1
and runs the same routine; for selector 1 it records mode 2 and runs it again.
The three tests are independent `if` statements evaluated in that order, so at
most one fires for a given selector. Separately, selector 3 invokes a different
routine with a zero argument and does not touch the global. Any other selector
does nothing. Returns nothing.

## Status
exact in USA, Japan, Europe and lrg_rev1.
