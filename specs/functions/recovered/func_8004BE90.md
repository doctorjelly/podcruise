# func_8004BE90

## Boundary and behavior

The USA body spans ROM `0x4CA90`, VRAM `0x8004BE90` through the return delay
slot at `0x8004CA4C`, 3008 bytes. The canonical body is
`analysis/generated/us/asm/main_4CA90.s:13–804`. It selects a display phase
from the race-state kind, initializes the corresponding menu resources and
racer slots, then performs the common final update. Its configured pool is
at `0x800AB13C`, alignment four.

## Low-19-bit predicate correction

At `0x8004BFA8–0x8004BFB0`, `$s0` becomes `D_80113680`. The load at
`0x8004C1F4` reads its word at offset `0x10`; `sll ..., 13` at `0x8004C1F8`
discards original bits 19–31. The following zero test at `0x8004C1FC` selects
the fallback racer search when all original low 19 bits are clear. Otherwise
the call at `0x8004C20C` is `func_800517D8(0x6D, 0x39, 1, -1.0f)`.

The C condition now directly tests `(D_80113680.unk10 & 0x7FFFF) != 0`.
The former signed left shift was undefined for negative words or positive
words whose shifted result was not representable. For example, bit 18 alone
produces machine word `0x80000000` and takes the nonzero path, while bit 19
alone is discarded and takes the fallback. The mask defines both cases and
preserves the canonical predicate for every 32-bit input word.

An independent isolated audit of the clean mask variant reproduces the entire
3008-byte compiled text and all 160 emitted pool bytes at unchanged addresses.
The comparison is recorded in `/tmp/us21-4be90-mask/review-sections.json`.
This is a definedness correction, not a new exact match.

## Regression evidence

`tests/test_racer_selection.c` calls the actual function with six phase-three
fixtures under shift sanitization. Masks 2, 0x40002, and 0x80000002 select
the special resource with RNG zero. Singleton bit 18 also selects that
resource; singleton bits 19 and 20 exercise the fallback and select record
zero. Each fixture verifies RNG consumption and the slot-0x39 resource call.
The original signed-shift source fails the sanitizer on mask 0x40002; the
corrected source passes all six fixtures. The Makefile runs this regression
as part of the host test suite.

## Bounded allocator search

Before the correction, a canonical-target preflight scored 440: 88 register
penalties and no stack, branch, reordering, insertion, or deletion penalties.
The actual compiler flags and pool alignment were preserved. One 60-second,
16-worker search reached 250 by splitting the signed shift by 13 into shifts
by 8 and 5. Its independent audit emits 3008/3008 bytes, 34 differing words,
first difference `0x365`. That artificial nonexact spelling was rejected.
Another candidate used repeated 64-bit masks and an unnecessary double cast;
it was also rejected. No second search or seeded continuation was run.

Artifacts are under `/tmp/us21-permute-4be90`, including `target.o`,
`output-250-1`, `candidate-config.json`, and baseline/candidate audit builds.
The terminal run log is `/tmp/us21-permute-4be90-run.log` (the prescribed
60-second timeout exited 124). Only the separately proven direct mask was
retained in production source.

## Status

address, with 72 differing words, no missing or extra words, and first
