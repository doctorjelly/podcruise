## Globals and access widths

None. The routine works purely through its first argument.

Fields of the record addressed by the first argument: `+0x14` 32-bit signed
entry count, `+0x18` pointer to an array of 32-bit pointer-sized entries.

## Recovered behavior

The routine substitutes one entry value for another throughout a record's
entry array.

If any of the three arguments is null the routine does nothing. Otherwise it
walks the array from the front for as many entries as the record's count field
says, and wherever an entry equals the second argument it overwrites that entry
with the third argument. Every position is examined; the routine does not stop
after the first substitution and returns nothing.

The count and the array base are both re-read from the record as the walk
proceeds, because a store into the array could in principle change them. That
is a direct consequence of writing the walk against the record's own fields
rather than caching them in locals.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
