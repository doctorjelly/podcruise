# func_80097990

## Boundary
VRAM 0x80097990-0x800979E8 (88 bytes), ROM 0x98590. Frame 0x28, saves the
return address and one callee-saved register; return sequence with an empty
delay slot. One direct caller.

## Callers / callees
1 caller. Calls func_8008CA80 on entry and func_8008CAA0 on exit.

## Globals
D_800A7B50, read and written as a 32-bit word.

## Regional addresses
- jp: 0x80098680 (ROM 0x99280); callees func_8008D770, func_8008D790; global D_800AA9A0
- eu: 0x8009CEE0 (ROM 0x9DAE0); callees func_80091FD0, func_80091FF0; global D_800ACE50
- lrg_rev1: identical to USA

## Behavior
Clears a caller-supplied set of flag bits from a global flag word, under
mutual exclusion. It first enters the critical section by calling the lock
routine and keeps the token that routine returns. It then removes from the
global word every bit that is set in the argument, except that two bits —
value 1 and value 0x400 — are protected and are never cleared no matter what
the argument requests. Finally it leaves the critical section by handing the
saved token back to the unlock routine. Nothing is returned.

## Compilation note
This translation unit is built at -O1, consistent with the other confirmed
-O1 bodies near 0x80097950. The token held across the flag update is a
`register`-qualified local; without that qualifier -O1 spills it to the stack
instead of keeping it in a callee-saved register.

## Status
exact in usa, jp, eu and lrg_rev1.
