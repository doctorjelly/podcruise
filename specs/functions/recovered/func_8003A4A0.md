Layout facts established from the code:

- Argument one is a pointer to a structure holding a pointer at byte offset
  0x0C.
- That pointer addresses an array of 84-byte (0x54) records. The neighbouring

because the stores through argument three could alias it.

## Recovered behavior

The function copies a three-component floating point vector out of an indexed
record and into a caller-supplied destination.

Argument one is the owning object. Argument two is a record index. Argument
three is the destination.

The function follows the array pointer stored at offset 0x0C of the owning
object, steps to the record selected by the index, and copies the three
floating point values found at record offsets 0x10, 0x14 and 0x18 into the
first, second and third slots of the destination, in that order.

The index is not range checked. Nothing is returned.
