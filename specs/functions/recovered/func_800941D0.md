# func_800941D0

## Boundary

USA VRAM 0x800941D0-0x800941DC, ROM 0x94DD0, size 12 bytes (3 instructions).
The body ends with a return whose delay slot holds the load that produces the
result. Both direct call sites target 0x800941D0, and the preceding function
ends with its own return before this address, so the boundary is correct.

## Callers / callees

Two callers. No callees; leaf function.

## Globals

- D_800A7F50: read as one 32-bit word.

## Regional addresses

- Japan: 0x80094EC0, ROM 0x095AC0, 12 bytes; the global moves to 0x800AADA0.
- Europe: 0x80099720, ROM 0x09A320, 12 bytes; the global moves to 0x800AD250.
- lrg_rev1: shares the USA addresses and symbols.

## Recovered behaviour

The function takes no arguments and simply returns the current value of one
32-bit global. It is a read accessor for that variable.

## Status

exact in USA, Japan, Europe and lrg_rev1.
