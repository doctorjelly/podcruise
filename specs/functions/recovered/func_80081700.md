# func_80081700

## Boundary

- USA VRAM range: 0x80081700 .. 0x80081723 inclusive (0x24 = 36 bytes,
  9 instructions).
- USA ROM offset: 0x82300.
- Ends with a return whose delay slot computes the returned float, so the final
  subtraction is part of the function.
- Assigned size 36 was correct; no boundary correction.

## Callers and callees

- 24 direct call sites in the USA build. Every inspected site converts a
  double-precision constant to single precision into the second float argument
  register right at the call, and supplies the first float argument from a
  float constant or a field of the object in the first pointer register.
- No callees (leaf function).

## Arguments and return

- Two arguments, both 32-bit floats: the first arrives in the first float
  argument register, the second in the second float argument register.
- Returns a 32-bit float.

## Globals and access widths

- `D_800ADCB0` — one 32-bit float, read once, used as a divisor.

## Regional addresses

The body is instruction-for-instruction identical in every version; only the
global address moves.

| version  | VRAM       | ROM     | global      |
|----------|------------|---------|-------------|
| us       | 0x80081700 | 0x82300 | D_800ADCB0  |
| jp       | 0x800823A0 | 0x82FA0 | D_800B0F00  |
| eu       | 0x80086BE0 | 0x877E0 | D_800B6910  |
| lrg_rev1 | 0x80081700 | 0x82300 | D_800ADCB0  |

## Recovered behavior

Computes a normalised blend weight. The second argument is first divided by a
module-wide reference value, giving a scaled quantity. The routine then returns
one minus the ratio of that scaled quantity to the sum of the scaled quantity
and the first argument.

With both inputs positive this yields a value in the open interval between zero
and one that approaches one as the first argument grows relative to the scaled
second argument, and approaches zero as the scaled second argument dominates —
the classic "fraction remaining" form used for exponential-style smoothing
where the second argument is an elapsed interval and the first a time constant.

The constant one is materialised before the divisions, which is what the
compiler produces for an ordinary `1.0f - expression` written as a single
return statement.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
