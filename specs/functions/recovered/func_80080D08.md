# func_80080D08

## Verified facts

- The canonical USA body and compiler-emitted tail occupy VRAM `0x80080D08`
  through `0x80080DB3`, ROM `0x81908`, 172 bytes.
- When `D_800A6704` is nonnegative, the function returns at `0x80080D9C` and
  performs the last floating-point store in its delay slot at `0x80080DA4`.
- The negative path branches to the shared return at `0x80080DAC`, whose delay
  slot at `0x80080DB0` is a `nop`. The duplicate zero-result instruction at
  `0x80080DA8` is unreachable, but IDO emits it from the recovered C.
- The only direct caller is `func_8005FA38`. There are no callees. The function
  reads the signed global `D_800A6704` and the 64-byte float block
  `D_8011DCB8`.
- The full Japan (`0x800819A8`, ROM `0x825A8`) and Europe (`0x800861E8`, ROM
  `0x86DE8`) bodies have the same normalized instruction structure; their
  differing bytes are relocations.

## Behavior

If the signed global is negative, the function returns zero without changing
the caller's output. Otherwise it copies all sixteen consecutive floats from
`D_8011DCB8` to the supplied 64-byte block and returns one.
