# func_80085EB0

## Boundary

- USA VRAM range `0x80085EB0` .. `0x80085F77` inclusive, 200 bytes (0xC8).
- Ends with a return whose delay slot releases the 0x30-byte frame.
- The single early-exit path and the normal path share that epilogue; no branch
  from the preceding function lands inside the range. The assigned boundary is
  correct.

## Callers

- One caller, reached from two overlapping section views of the same code. The
  caller sets up a pointer argument well before the call and consumes the
  floating-point result immediately afterwards, so the signature is
  `f32 func_80085EB0(f32 *point)`.

## Callees

- `func_800153EC(f32 *a, f32 *b)` — returns the squared distance between two
  three-component vectors.
- The square root is emitted inline by the compiler from the `sqrtf` intrinsic;
  it produces no relocation and therefore no linked symbol.

## Globals and access widths

- `D_800A694C` — signed 32-bit count of candidate points. Re-read as a full word
  before the first candidate and again after every distance evaluation.
- `D_801489C8` — array of three-component single-precision vectors, 12 bytes per
  entry. The disassembly also labels the second entry (`D_801489D4`); that is the
  same array indexed by one, and one array symbol reproduces both references.

## Recovered behaviour

The routine reports how far the supplied point lies from the nearest entry of a
global point set.

If the global count of entries is zero or negative there is nothing to measure
and the routine returns minus one as a sentinel, without touching the array.

Otherwise it measures the squared distance from the supplied point to the first
entry and keeps that as the running best. It then walks the remaining entries in
order, measuring each one and lowering the running best whenever an entry is
strictly closer than the best so far. The loop bound is the global count read
fresh on each pass, so a count changed underneath the loop takes effect at once.

Finally it returns the square root of the smallest squared distance found, i.e.
the true distance to the nearest entry.

## Status

Byte-exact against the USA ROM, and against the Japan, Europe and lrg_rev1 ROMs
after remapping the moved symbols. No per-unit compiler flags were needed.
