# func_80051994

## Boundary

- USA VRAM range: 0x80051994 .. 0x800519BC inclusive (0x2C = 44 bytes, 11 instructions).
- USA ROM offset: 0x52594.
- Ends with a return whose delay slot performs the second of the two stores,
  so that store is part of the function.
- Assigned size 44 was correct; no boundary correction.

## Callers and callees

- One distinct call site in the USA build (it appears in both overlay
  listings). Two integer arguments, no result used.
- No callees (leaf function).

## Globals and access widths

- `D_8011A508` — a table of 32-bit words, indexed by both arguments; both
  elements are read and written as full words.

## Recovered behavior

Exchanges two entries of a shared 32-bit table. The entry named by the first
argument and the entry named by the second argument trade values; nothing else
is touched and no result is returned. Neither index is validated, so the caller
is responsible for keeping both in range. This is the elementary swap step of a
shuffle over the table that the neighbouring routines initialise to the
identity ordering.

## Recovery notes

The straightforward three-statement swap through one saved local reproduces the
original exactly, including the order in which the two element addresses are
formed.

## Status

Exact. Byte-identical in USA, Japan, Europe and the large-cartridge revision.
