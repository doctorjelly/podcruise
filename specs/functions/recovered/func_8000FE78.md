# func_8000FE78

## Boundary

- USA VRAM range: 0x8000FE78 .. 0x8000FEAB inclusive (52 bytes, 13 instructions).
- USA ROM offset 0x10A78.
- The body ends with the return jump at 0x8000FEA4; its delay slot is empty.
- The single internal backward branch stays inside the range; all four direct
  call sites target 0x8000FE78.
- Boundary correction: none.

## Callers

Four direct call sites, each immediately following a call to func_8000FE1C, so
the two routines form one reset step.

## Callees

None. Leaf routine, no stack frame, no arguments, no return value.

The table sits 0x3250 higher in Japan and 0x8CA0 higher in Europe; the
instruction stream is identical in all four versions.

## Recovered behaviour

A parameterless reset that fills all twenty entries of one word table with the
sentinel -9999.

The same -9999 constant appears at call sites of func_8000FEAC as the value
handed in for the corresponding entry, which confirms it is the table's
"unset" marker rather than a meaningful number.

The compiler expanded the twenty-iteration loop into five passes of four
stores, advancing the write pointer at the top of each pass and addressing the
four words behind it.

## Status

Byte-exact against USA, Japan, Europe and lrg_rev1. Matched on the first
attempt with no iteration.
