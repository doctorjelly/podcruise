# func_8002E8E8

## Verified boundary and references

The USA entry is VRAM `0x8002E8E8`, ROM `0x2F4E8`, and the complete body is
320 bytes. It returns at `0x8002EA20`; the `nop` at `0x8002EA24` is the delay
slot, and the next function begins at `0x8002EA28`.

Recovered caller `func_8002F750` invokes it during a larger subsystem update.
It calls `func_8002E770` before scanning, reads enable bits from `D_800A26D0`
and per-channel status bytes spaced four bytes apart from `D_800D74B3`, writes
four availability words at `D_800D7498`, selects a channel in `D_800D7490`,
and clears `D_800A26D4` when no channel is available.

The normalized regional search uniquely maps the body to `0x8002F348` in
Japan and `0x80031E88` in Europe, with the surrounding functions carrying the
same relocation deltas. The LRG revision retains the USA address and bytes.

## Behavior

Refresh four channel states, then scan the enabled channels in index order.
Mark a channel available only when its enable bit is set and its status byte
does not contain bit 3. Publish the first available index, or `-1` when none is
available; in the latter case also clear the secondary availability byte.

## Compiler status

**Byte-matching C.** IDO 5.3 with the accepted `ido53_o2` flags reproduces all
320 USA bytes exactly. The exact source stores the selected index in
`D_800D7490` and tests that non-volatile global for the no-channel case; IDO
reuses the prior flag register for its address and common-subexpression-
eliminates the just-stored value.
