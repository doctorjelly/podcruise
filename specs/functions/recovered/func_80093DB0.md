# func_80093DB0

## Boundary

USA VRAM 0x80093DB0-0x80093E3C, ROM 0x949B0, size 140 bytes (35 instructions).
The body ends with a return whose delay slot holds the last store. The single
direct call site targets 0x80093DB0, the preceding function returns before this
address, and no branch enters the range from outside, so the boundary is
correct. The two-instruction label immediately after the range (0x80093E3C) is
a stranded copy of the following function's first global load and is not a
separate entry point.

## Callers / callees

One caller, inside the one-shot system bring-up path at 0x8008BAD4. No callees;
leaf function.

- D_8014C518: written as one 32-bit word.
- D_8014C51C: written as one 32-bit word.

## Regional addresses

- Japan: 0x80094AA0, ROM 0x0956A0, 140 bytes. Globals move to D_8014F780 (the
  64-bit counter), D_8014F788, D_8014F78C and D_800AAE10.
- Europe: 0x80099300, ROM 0x099F00, 140 bytes. Globals move to D_801551B0,

- lrg_rev1: shares the USA addresses and symbols.

Both regional bodies were read independently; they are instruction-for-
instruction identical to the USA body with only the relocated addresses
differing.

## Recovered behaviour

This is the one-time reset of the timed-event service. It clears the running
64-bit time counter and the two 32-bit bookkeeping counters that go with it,
then puts the service's list head back into its empty state: the head record's
backward link is pointed at the head itself, its forward link is then taken from
that backward link, its remaining-time field is cleared, its reload interval is
copied from the freshly cleared remaining-time field, and finally its notify
queue handle and notify message are both cleared. Afterwards the list contains
only the sentinel and nothing is scheduled.

## Implementation notes for the matching build

Two facts carry the match and are worth recording:

1. This translation unit was compiled at optimization level 1, like its
   neighbours func_80093990 and func_80093A60. At level 2 the compiler hoists
   the global handle's address into a base register and the body comes out 128
   bytes instead of 140.
2. The 64-bit counter must be written as a definition owned by this unit rather
   than an `extern`. The original assembler only folds the two halves of a
   64-bit store onto one shared address register when it can resolve the symbol
   while assembling; with an `extern` it emits a second address setup and the
   body is four bytes longer. Declaring it as a tentative definition keeps the
   linker script's absolute address authoritative and reproduces the original
   pairing exactly.

## Status

exact in USA, Japan, Europe and lrg_rev1, with the per-unit optimization-level-1
flag override recorded in the result.
