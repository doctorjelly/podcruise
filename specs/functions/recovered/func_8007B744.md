# func_8007B744

## Boundary
VRAM 0x8007B744-0x8007B7BC (120 bytes, ROM 0x7C344). Ends with a return whose
delay slot restores the stack pointer. Confirmed as a real entry: 15 direct
callers target 0x8007B744 and no earlier branch falls into it.

## Callers / callees
15 direct callers. Calls func_80006E60 and func_80006E74.

## Globals and access widths
D_8011C8F0: array of pointers, indexed by the argument with a word load.
Each pointer addresses a null-terminated array of word-sized handles.

## Regional addresses
- jp 0x8007C3E4 (ROM 0x7CFE4), global relocated to D_8011FB60
- eu 0x80080C24 (ROM 0x81824), global relocated to D_80125590
- lrg_rev1 0x8007B744, identical to USA

## Behavior
Selects one entry from a table of handle lists using the caller-supplied index,
then walks that list until it reaches the terminating zero. For every handle in
the list it performs two operations: the first applies a fixed mask value of
0x10000000 to the handle, the second applies a floating-point value of zero to
the handle re-read from the list. Nothing is returned.

## Status
exact in USA, Japan, Europe and lrg_rev1.
