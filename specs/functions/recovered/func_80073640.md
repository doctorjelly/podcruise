# func_80073640

## Boundary
VRAM 0x80073640-0x800736AB (108 bytes). Ends with `jr $ra` whose delay slot
restores the stack pointer. Two direct callers target the entry; boundary
confirmed, no correction needed.

## Callers / callees
2 callers. Calls func_80006E60 and func_80006E74.

## Globals
None.

## Regional addresses
- jp 0x80074270 (rom 0x74E70), eu 0x80078B20 (rom 0x79720), lrg_rev1 shares the
  USA address. The callees keep the USA addresses in every version.

## Behavior
The single argument is a pointer to a null-terminated list of handles stored one
word apart. For every handle in the list, in order, the routine first performs
the first operation with a fixed selector constant of 0x10000000, then performs
the second operation with a floating-point value of zero. The walk stops at the
first null entry; an immediately null list does nothing at all.

## Status
exact in USA, Japan, Europe and lrg_rev1 with the accepted -O2 profile.
