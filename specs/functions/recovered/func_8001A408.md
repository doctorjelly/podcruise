# func_8001A408

## Boundary and interface

The USA routine spans ROM `0x1B008` / VRAM `0x8001A408` through VRAM
`0x8001ADD4`, for `0x9CC` (2,508) bytes. Its return at `0x8001ADCC` restores
the `0xB0`-byte stack frame in the delay slot. The entry's two loads feed the
counter update after the prologue, so `func_8001A410` is an interior false
split. `func_8004A880` is the single direct caller and passes its menu state.

## Calls and data contracts

The routine calls `func_8004CA50`, `func_80033DC4`, `func_8002E8D4`,
`func_80009744`, four `func_8000A*` display controls, `func_8003ECB0`,
`func_8008A6B4`, `func_8002BBA4`, `func_8002D4C4`, and `func_800280D8`.
Proven menu fields are the byte at `0x51`, the word at `0x64`, and output bytes
at `0x6C`, `0x6D`, and `0x70`.

Shared state includes a modulo-31 frame counter at `D_800A2394`, initialization
and completion flags at `D_800A2388`, `D_800A4BBC`, and `D_800A4BDC`, three
animation timers at `D_800D7278`, a signed current choice at `D_800A238C`, a
byte count at `D_800A2390`, and its twelve-byte type list at `D_800D7390`.
`D_800A497C` is a modulo-three subchoice, while the two controller words begin
at `D_800A4BA4`.

## Recovered behavior

Advance the frame counter and perform one-time menu initialization. Initialization
sets three nested animation timers, clears the twelve-entry type list, installs
the three base entries, and conditionally appends a fourth. Each frame counts
the first timer down; only once it expires does the second count down. The third
counts down five times faster whenever the second is at or below one half.

Update the associated display controls and draw the expanded timing prompts
unless the menu requests the compact form. The visible coordinates are derived
from `18 - 100 * firstTimer` and `12 - 320 * thirdTimer`; the second timer
controls one prompt's alpha. Format and draw every active list entry, selecting
the final entry's text from the modulo-three subchoice.

Finally scan exactly two controller words. Confirm/cancel input selects one of
four output byte combinations or advances the final entry's subchoice. Vertical
input wraps the current list position, and horizontal input wraps the
modulo-three subchoice only while that final entry is selected. Accepted input
sets the shared completion state and returns. A separate global button chord
invokes the final callback.

## Regional evidence

The caller relocates the same entry-prefix shape to Japan `0x8001A61C` / ROM
`0x1B21C` and Europe `0x8001AC20` / ROM `0x1B820`. Both begin with the same
counter load followed by their region-specific prologue. They are structural
evidence only; this source is measured against canonical USA.

## Status

bytes versus the original 2,508 and differs in the first instruction. It is
not eligible for substitution and no byte match is claimed.
