# func_80060030

## Boundary
- USA VRAM 0x80060030 .. 0x8006009F (112 bytes), ROM 0x60C30.
- Terminates with the return jump at 0x80060098 and an empty delay slot at
  0x8006009C. Assigned boundary confirmed correct; no correction needed.
- Single direct caller, which targets 0x80060030 exactly; nothing executes
  before the frame adjustment at the entry.

## Callers
- One call site (USA 0x80060B34, inside the routine that begins at 0x800609xx),
  which passes its own first argument straight through.

## Callees
- func_80086A20 (USA 0x80086A20). Four parameters: a selector-style integer and
  three pointers to three-element float vectors. Independently confirmed by
  reading that routine's prologue, which homes four register arguments and later
  dereferences the third and fourth as float triples.

## Globals
- None. The routine touches only its own frame.

## Recovered behaviour
Builds three constant three-component float vectors in local storage and hands
them to the shared routine func_80086A20 together with the constant -1.

- The first vector is a uniform 64.0 in all three components.
- The second vector is a uniform 255.0 in all three components.
- The third vector is (0.0, 0.0, -100.0).

Given the callee's shape (it normalises the fourth argument and converts the
components of the second to 16-bit integers), these read as an intensity or
colour triple, a full-scale colour triple and a direction pointing 100 units
along the negative third axis, i.e. a fixed light or camera setup applied with
identifier -1.

The routine's own single argument is accepted and never read. IDO still spills
it to its incoming home slot, which is what makes the parameter observable, so
the recovered signature keeps it.

## Source shape notes
The three vectors occupy descending frame offsets in declaration order, so the
64.0 vector is declared first, the 255.0 vector second and the direction third.
Writing the nine component assignments in that order reproduces the original
schedule exactly.

## Status
Exact in USA on the first attempt, and exact in Japan, Europe and lrg_rev1.
