# func_80057ED4

## Boundary
VRAM 0x80057ED4-0x80057F47, 116 bytes, frame 0x20, empty return delay slot.
Single caller targets the entry.

## Callers / callees
One direct caller. Calls func_8000A920, func_8000AA04, func_8000AAC0,
func_8000AB24, func_80087814 in that order.

## Globals
None.

## Regional addresses
- jp 0x80058A98 (rom 0x59698); only func_80087814 moved, to 0x80088508.
- eu 0x8005CE60 (rom 0x5DA60); func_80087814 moved to 0x8008CD5C.
- lrg_rev1 identical to USA.

## Behavior
Takes no parameters and returns nothing. It configures entity/channel 0x17 with
a fixed sequence of settings: enables it, assigns mode 0 with parameter 0x76,
sets two floating-point properties to 320.0 and 4.0, and sets a four-component
value of (0, 0, 0, 255) — the last component arriving as a fifth argument on the
stack. It then issues one unrelated request for entity 0x14 with the constants
0x75, 300 and 123.

## Status
exact (USA, JP, EU and lrg_rev1 all byte-identical).
