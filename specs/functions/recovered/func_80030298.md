# func_80030298

## Boundary
USA VRAM 0x80030298-0x80030303, ROM 0x30E98, size 108 bytes (27 instructions).
Ends with a return with an empty delay slot. Nine direct callers. Boundary
confirmed, not corrected.

## Callers / callees
Nine callers. Calls, in order, func_8002FAFC (a free-running counter read),
func_8003FB78, func_8003F300, func_8002FAC4 and func_8003FA24.

## Globals and access widths
None. One 32-bit local holds a four-character tag whose value is the
characters L, o, a, d packed into a word; its address is passed to the last
callee.

## Regional addresses
- Japan: 0x80030CF8 / ROM 0x0318F8, callees func_8003055C, func_80040508,
  func_8003FC90, func_80030524, func_800403B4.
- Europe: 0x80033858 / ROM 0x034458, callees func_800330BC, func_80044518,
  func_80043CA0, func_80033084, func_800443C4.
- lrg_rev1: identical to USA addresses.

## Behavior
The routine takes two 32-bit arguments. It samples the counter, then calls
func_8003FB78 with both arguments plus that sample, which returns a count. It
then calls func_8003F300 with the first argument. It calls func_8002FAC4 with
the sum of the returned count and the original sample — that is, with the
absolute point at which the work is expected to finish rather than a duration.
Finally it builds the four-character tag "Load" in a local word and calls
func_8003FA24 with the first argument and the address of that word, which
labels the operation for whatever bookkeeping that callee performs. No value is
returned.

## Compilation notes
Another optimisation-level-1 region. The three locals occupy consecutive stack
words; the declaration order that reproduces the original layout puts the count
first, the counter sample second and the tag word last.

## Status
Exact in USA, Japan, Europe and lrg_rev1.
