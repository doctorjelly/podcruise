## Recovered behavior

Advances a triangle-wave oscillator by a whole number of steps and returns its
current amplitude.

1. The record's phase (offset 0x14) is advanced by its per-step increment
   (offset 0x10) multiplied by the integer step count, and the new phase is
   stored back.
2. The phase is then wrapped: if it now exceeds 2, 4 is subtracted from it,
   otherwise it is left alone. Either way the wrapped value is stored back into
   the record, so the phase stays in the half-open range that the amplitude
   formula expects. The comparison and the subtraction are performed in double
   precision because both literals are written as plain (double) constants,
   and the result is narrowed again on the way back into the record.
3. The stored phase is read back, folded to its absolute value, reduced by 1,
   and multiplied by the record's scale factor (offset 0x1C); that product is
   the return value. With the phase wrapped into [-2, 2] this traces a triangle
   that runs from +scale to -scale and back.

Two details drive the instruction shape. The wrap is written as a conditional
expression whose value is assigned to the phase, so both arms end in a store.
The final subtraction is assigned back to the same local that held the folded
phase before the multiply, which is what places the narrowed result in the
register the folded value occupied; computing the multiply directly from the
subtraction expression instead swaps two registers and does not match.
