# func_80011E54 — select a descriptor by clamped index

## Boundary
- USA VRAM `0x80011E54` .. `0x80011EA3` inclusive; ROM `0x12A54`; size **80**
  bytes (20 instructions).
- Terminates with a return whose delay slot stores the selected pointer.
- The preceding function ends with its own return immediately before this
  entry; all three direct call sites target `0x80011E54`. The two internal
  branch targets are both inside the range and both branch forward, so no
  shared-tail or mid-function-entry problem exists.
- **Size correction:** the assignment sheet and the generated inventory both
  report 160 bytes / 40 instructions. The real span is 80 bytes / 20
  instructions; the inventory's instruction count is doubled. Size 80 verifies
  byte-exact.

## Callers
Three direct call sites. Two of them narrow their value to a signed 16-bit
quantity immediately before the call, and the third passes the constant zero.
The narrowing in the callers, together with the sign-extension the callee
performs on entry, establishes that the single argument is a signed 16-bit
integer.

## Callees
None. Leaf function, no stack frame; the argument's caller-provided home slot
is written once on entry, which is the compiler's usual handling of a
narrower-than-word parameter, and is never read back.

## Globals and access widths
| symbol | width | access |
| --- | --- | --- |
| `D_800A1D88` | 32-bit signed word | read once: the entry count |
| `D_800D6940` | array of 32-bit pointers | one indexed word read |
| `D_800A1D8C` | 32-bit pointer | stored: the selected pointer |

`D_800A1D88` and `D_800D6940` are exactly the count and table that
`func_80011DF0` fills in, and `D_800A1D8C` is the same "current selection"
pointer that routine seeds.

| Japan | `0x80011E8C` | `0x12A8C` | **structurally different — excluded** |

Europe data mapping: `D_800A1D88`→`D_800A72D8`, `D_800A1D8C`→`D_800A72DC`,
`D_800D6940`→`D_800DF5E0`.

The Japanese counterpart is 96 bytes and reads **two** parallel tables at the
same clamped index, publishing one result into each of two selection globals.
It is a different function, not a relocation, so it is left unmatched here.

## Recovered behaviour
Given a signed 16-bit index, the routine clamps it into the valid range of the
descriptor table and publishes the chosen descriptor pointer as the current
selection. The clamp is applied high end first: any index that is not below the
recorded entry count is replaced by the last valid index (count minus one),
with the replacement itself narrowed back to signed 16 bits. The low end is
applied second: a negative index becomes zero. Note the ordering means that if
the recorded count is zero or negative, the high clamp produces a negative
value which the low clamp then turns into zero, so the routine always ends up
reading slot 0 rather than reading out of bounds. The clamped index selects one
pointer from the table and that pointer is stored into the current-selection
global. Nothing is returned.

## Status
Exact. USA, Europe and `lrg_rev1` all verified byte-identical from
`src/functions/func_80011E54.c`. Japan excluded (different body).
