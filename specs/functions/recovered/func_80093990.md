# func_80093990

## Boundary

VRAM 0x80093990..0x800939C3 (52 bytes, USA ROM 0x94590). The body ends with a
return whose delay slot releases the frame; three padding words follow before
the next function at 0x800939D0. The two interior labels are the arms of the
single conditional inside the function, not separate functions: neither is the
target of any call. Boundary as assigned; no correction.

## Callers

Two direct call sites in USA, at 0x8008B058 and 0x8008B070.

## Callees

None. Leaf function.

## Globals and access widths

- 32-bit read of the signal-processor status register at physical 0x04040010
  (uncached 0xA4040010).
- 32-bit write to the signal-processor program-counter register at physical
  0x04080000 (uncached 0xA4080000).

Both addresses are literals in the source, not named externs, so that their low
halves fold into the load and store displacements.

## Regional addresses

- Japan: 0x80094680, ROM 0x095280
- Europe: 0x80098EE0, ROM 0x099AE0
- lrg_rev1: 0x80093990, ROM 0x94590 (same as USA)

All regional bodies were read independently and are word-for-word identical to
the USA body; nothing relocates.

## Recovered behavior

Arms the signal processor at a caller-supplied start address, but only while
the processor is stopped. It reads the status word and inspects the halted bit
(the lowest bit). If that bit is clear the processor is running, so the request
is refused and negative one is returned without touching anything. If the bit
is set, the supplied address is written to the processor's program counter and
zero is returned to report success. Observed callers pass the start of the
processor's instruction memory.

## Compiler notes

This translation unit was built at optimization level 1, not level 2. Two
observable consequences appear here and in func_80093A60: the function reserves
an eight-byte stack frame it never stores into, and the status word is held in
an argument register rather than a code-generator temporary. Both follow from
the status word being a register-class local at level 1; the same shape at
level 2 loses the frame, merges the two exits into two separate returns and
comes out four bytes short. The frame is also what forces the single shared
epilogue that the original uses.

## Status

Exact in USA, Japan, Europe and lrg_rev1 with the unit compiled at optimization
level 1 (flags: -G 0 -O1 -mips2 -non_shared -Xcpluscomm -signed
-Wab,-r4300_mul). Recorded as a per-unit flag override so it verifies under the
accepted profile without a new profile being defined.
