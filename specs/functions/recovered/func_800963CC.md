# func_800963CC

## Boundary and evidence

The canonical USA function starts at ROM `0x96FCC` / VRAM `0x800963CC` and
ends after the `jr $ra` delay-slot stack restore at `0x80096708`, for `0x340`
(832) bytes. The zero word at `0x8009670C` is alignment before the next
function at `0x80096710`, not part of this body. The scanner's 836-byte size
therefore includes one non-function word.

`func_8008D870` stores this address as a callback in the sequence object. Its
USA body calls `func_80095B68`, `func_80095C20`, `func_80095DA8`, and
`func_80095F34`, plus the indirect callback at offset four of the object reached
through sequence offset zero. It references no globals. The unique structural
counterparts are Japan `0x800970BC` and Europe `0x8009B91C`; those mappings are
relocation evidence only.

## Behavior

Ask the sequence's output source for a command-list cursor, forwarding all four
remaining arguments. Emit three fixed setup commands, copy the current ring
buffer into workspace `0x6C0`, and emit the command that describes the copied
sample count.

Then process each 40-byte voice record. Derive two positions behind the current
ring cursor from the voice's start and end distances. Ordinarily, load the
first position and render the voice. If that position equals the boundary saved
from the preceding voice, swap the two workspace offsets instead of loading it
again. Three optional halfwords emit routing commands. Depending on the voice's
channel and envelope pointers, also emit channel setup and one or two ring-copy
operations. Save the forward end boundary for the next iteration.

Finally advance the ring cursor by the requested sample count and subtract one
ring length only when it passes the end. Append the terminating command and
return the following command-list position.

## Bounded allocator search

The US21 preflight verified the complete 832-byte target against the canonical
ROM. Scoring the current linked object gave 375: 75 register penalties and no
stack, branch, reordering, insertion, or deletion penalties. The permuter's
initial formatting split the eight existing single-line `CMD` expansions and
changed this to 1000 with additional instruction/reordering penalties. Private
`PERM_FORCE_SAMELINE` wrappers around those eight blocks restored the original
375-point preflight; the wrappers preserve existing formatting and were not
production source changes.

One 60-second, 32-worker search with stack and branch-target scoring reached
305. Its best candidate adds XOR-zero and six repeated 64-bit all-ones masks.
The independent project audit confirms 832/832 bytes and 45 differing words,
still first differing at `0x12A`. These artificial nonexact constructs were
rejected; no source or configuration change was retained and no seeded
continuation was run. The current source is a recorded bounded-search stop.
