## Behavior
Reads a free-running 32-bit counter. If the new reading is below the previously
stored reading, the counter has wrapped, so a wrap tally is incremented. The new
reading then replaces the stored one. The function returns a widened value: the
wrap tally scaled by 32 in 64-bit arithmetic, plus the current reading.
