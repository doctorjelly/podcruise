# func_80008BC4

## Boundary
USA VRAM 0x80008BC4-0x80008C57 (0x94 = 148 bytes), ROM 0x97C4.
0x30-byte frame; the body ends with a return whose delay slot performs the last
of the two global restores. The next function starts immediately at 0x80008C58
with its own prologue and is the only callee. Thirty-five direct call sites all
target 0x80008BC4.

## Callers / callees
Thirty-five direct callers. Every inspected site writes two extra words into the
outgoing argument area beyond the seven the callee needs, which confirms the
nine-argument signature.

Calls `func_80008C58` exactly once, forwarding its own first seven arguments.

## Argument shape
| position | width | evidence |
| -------- | ----- | -------- |
| 1 | pointer/word | passed straight through, never homed |
| 2 | s16 | homed, then sign-extended through a 16-bit shift pair |
| 3 | f32 | arrives in an integer register and is round-tripped through the FPU |
| 4 | f32 | same round trip |
| 5 | word | read from the incoming stack area, re-stored for the call |
| 6 | word | same |
| 7 | word | same |
| 8 | f32 | read from the incoming stack area as a float |
| 9 | f32 | same |

## Globals
`D_8009AD08` and `D_8009AD0C`, both f32, both read and written twice: read into
two frame slots before the call and written back from them after it, with the
eighth and ninth arguments installed in between.

## Regional addresses
- JP 0x80008BC4, ROM 0x97C4; the two globals move to 0x8009B9F8 and 0x8009B9FC.
- EU 0x80008BC4, ROM 0x97C4; the two globals move to 0x800A0258 and 0x800A025C.
- lrg_rev1 shares the USA addresses and the USA global addresses.
Both regional bodies were read instruction by instruction; the callee address is
unchanged in every version and only the two global addresses differ.

## Recovered behavior
This is a scoped-override wrapper. It saves the current values of a pair of
global floating point parameters, replaces them with the eighth and ninth
arguments, performs the real operation by handing its first seven arguments to
the worker routine, and then puts the two saved values back. Callers therefore
get the worker's behaviour under a temporary pair of settings without having to
save and restore them at every site.

## Notes on shape
The two saved values must be separate locals declared in the order
(first global, second global): IDO gives the first declaration the higher frame
slot, which is what the original uses. No other shape experiment was needed; the
first attempt matched.

## Status
exact - USA, JP, EU and lrg_rev1 all verified byte-identical.
