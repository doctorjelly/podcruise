# func_800941B0

## Boundary

USA VRAM 0x800941B0-0x800941C8, ROM 0x94DB0, size 24 bytes (6 instructions).
The body ends with a return whose delay slot holds the load that produces the
result. Both direct call sites target 0x800941B0. The internal forward branch
target sits inside the range and is not an entry point, so the boundary is
correct.

## Callers / callees

Two callers. No callees; leaf function.

## Globals

- D_800A7BC0: read as a 32-bit pointer-sized word.

## Regional addresses

- Japan: 0x80094EA0, ROM 0x095AA0, 24 bytes; the global moves to 0x800AAA10.
- Europe: 0x80099700, ROM 0x09A300, 24 bytes; the global moves to 0x800ACEC0.
- lrg_rev1: shares the USA addresses and symbols.

## Recovered behaviour

The function takes one pointer argument to a small record. When that argument is
null it substitutes the record named by the global handle instead. It then reads
the second word of the selected record (four bytes into it) and returns that
value. Nothing is written.

## Status

exact in USA, Japan, Europe and lrg_rev1.
