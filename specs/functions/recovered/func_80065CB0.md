# func_80065CB0

## Boundary

- USA VRAM range `0x80065CB0` .. `0x80065CC3` inclusive (20 bytes, 5 words),
  USA ROM offset `0x668B0`.
- Ends with `jr $ra` and an empty delay slot; the single conditional branch
  targets that return. A padding word follows, then the next section.
- Two direct call sites all target `0x80065CB0`.
- No boundary correction was required.

## Callers / callees

- Callers: 2 direct call sites. Both follow the same idiom: a constructor-like
  routine is called, its returned pointer is stored into a parent object's
  field at offset `0x314`, that pointer becomes argument 1, and the *address*
  of that same field becomes argument 2.
- Callees: none. This is a leaf.

## Globals and access widths

- None.
- Argument 1 is a pointer to an object with a 32-bit pointer slot at offset
  `0xF0`.
- Argument 2 is a pointer value, stored verbatim.

## Recovered behavior

A null-tolerant back-pointer setter. If the object pointer is null the routine
returns immediately. Otherwise the supplied pointer is written into the
object's slot at offset `0xF0` and nothing else happens. Given the call sites,
the effect is to hand a freshly created object the address of the field that
owns it, so the object can later clear that field itself.

## Status

Exact. USA, Japan, Europe and lrg_rev1 all verified byte-identical.
