## Recovered behavior

The function appends the same three eight-byte command packets as func_80034DA8
to the buffer addressed by D_80112C90, advancing the cursor once per packet:
0xDA380003 with the current value of D_801134D0, then 0xDC38000E with the
current value of D_801134D4, then 0xDB0C0000 with the constant 0x00010000.

It differs from func_80034DA8 only in that it does not clear the flag word
D_800A3FF8; the two are otherwise the same routine. Nothing is returned.

## Source shape notes

from a post-increment of the cursor, block statements on one source line.
