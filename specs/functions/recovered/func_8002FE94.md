## Behavior

For the expected nonnegative size domain, scans downward from bit 30 to find
the highest set bit, then returns that power of two when the input is already
exact or the next power of two otherwise. Results below 16 are raised to 16.
The comparisons and shifts are signed 32-bit operations, so values outside the
ordinary size domain retain the original wraparound behavior.
