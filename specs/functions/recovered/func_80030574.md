# func_80030574

## Boundary

- VRAM 0x80030574 .. 0x800305E8 (exclusive), ROM 0x31174, size 116 bytes.
- The body ends with the return instruction and an empty delay slot.
- Assigned size 116 is correct; the next label (func_800305E8) is a large
  routine with 60 callers and nothing branches past the return.

## Callers and callees

- One direct call site (present in two overlapping split files). No calls out.
- The caller passes a single 32-bit value that it has just read out of a
  neighbouring table, i.e. a timestamp-like magnitude compared unsigned.

## Globals and access widths

- `D_800D9E00` — a flat table of 1700 unsigned 32-bit words spanning
  0x800D9E00 .. 0x800DB890. Each word is read once and conditionally
  overwritten with zero, both as 32-bit accesses.
- `D_800DB890` in the label scan is not a separate object: it is the
  one-past-the-end address of that table, which the compiler materialises as
  the loop's stop pointer. The recovered source references only
  `D_800D9E00`.

| --- | --- | --- | --- | --- |
| usa | 0x80030574 | 0x31174 | D_800D9E00 | 0x800DB890 |
| japan | 0x80030FD4 | 0x31BD4 | D_800DD070 | 0x800DEB00 |
| europe | 0x80033B34 | 0x34734 | D_800E2AA0 | 0x800E4530 |
| lrg_rev1 | 0x80030574 | 0x31174 | D_800D9E00 | 0x800DB890 |

Each regional body was read directly; the span between base and end is
0x1A90 bytes (1700 words) in every version, and the code is otherwise
identical.

## Recovered behavior

Invalidates every table slot that is "newer" than a supplied reference value.

For each of the 1700 words in the table, if the reference value passed in is
numerically smaller than the stored word (compared as unsigned quantities),
that word is reset to zero. Words less than or equal to the reference are left
untouched. The routine returns nothing and never exits early: the whole table
is always scanned.

## Compiler note

The literal trip count 1700 makes the optimiser unroll the loop four ways and
convert the index into a walking pointer tested against the table's end
address; that is exactly the original shape, so the plain indexed loop over
`u32 D_800D9E00[1700]` reproduces it without help.

## Status

Exact. Byte-identical in USA, Japan, Europe and lrg_rev1.
