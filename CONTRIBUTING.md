# Contributing

All contributions must comply with [`docs/IP_POLICY.md`](docs/IP_POLICY.md).

Before committing:

```sh
make test
make safety
git diff --check
git diff --cached
```

Do not add ROMs, extracted assets, generated disassembly, proprietary SDK or
compiler material, leaked source, or code copied from unlicensed prior art.
Describe the provenance of any new dependency and the independent evidence used
for recovered source.

Source-decompilation changes should include:

- the autogenerated function address, until a semantic name is justified;
- a short behavioral specification written in the contributor's own words;
- the compiler/toolchain and flags used for comparison;
- proof of a byte match, or an explicit non-matching status;
- confirmation that no generated decompiler/disassembler output was pasted.
