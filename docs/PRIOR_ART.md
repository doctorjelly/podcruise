# Prior art and provenance

## N64 static recompilation of Racer

- Repository: <https://github.com/sp00nznet/racer>
- Observed public milestone: USA ROM analysis, a large symbol set, native boot,
  and display-list submission to RT64.
- Relevance: validates the approximate USA executable range and identifies
  runtime/library areas worth prioritizing.
- Boundary: static recompilation translates instructions; it does not recover
  matching source. The repository currently presents no explicit software
  license, so no code or symbol file has been copied into `podcruise`.

## Matching-decomp toolchain

- `splat`: <https://github.com/ethteck/splat>
- `asm-differ`: <https://github.com/simonlindholm/asm-differ>
- `m2c`: <https://github.com/matt-kempster/m2c>
- `decomp-permuter`: <https://github.com/simonlindholm/decomp-permuter>

These tools serve different roles: splitting and disassembly, instruction-aware
comparison, initial C recovery, and last-mile source permutation. Tool versions
will be pinned before matching percentages are reported.

`splat` 0.50.0 is pinned for the bootstrap. Its automatic ROM-config generator
labels these builds KMC because the tiny entry stub contains zero qualifying
branches and zero jumps; that is a fallback, not affirmative evidence. The
broader independently selected interval strongly favors an IDO-family compiler.

## Clean-room note

Current committed function candidates are derived by `tools/analyze_mips.py`
from direct-call targets and conventional MIPS stack-frame prologues. Regional
mappings are regenerated by `tools/cross_version_map.py` from normalized
instruction windows. This keeps the first-pass evidence independently
reproducible from user-supplied ROMs.
